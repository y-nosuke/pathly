# 地図タップの挙動（画面 × モード × 登録済み表示）

複数のマップ画面（記録・経路詳細・場所詳細・場所追加）と、モード（通常／手動追加）、
「登録済みの場所」表示トグル（ON/OFF）で、地図タップの意味が変わる。分岐が増えて分かりにくいので、
**画面ごとに「何をタップしたら何が起きるか」を一枚に整理**する。決定の背景は [ADR-0009](../adr/0009-map-tap-behavior.md)。

## 画面の構成（地図を持つ画面）

- **記録画面（`TrackingScreen`・記録タブ）**: **平常時**（アクティブな記録なし）／**記録中**。
- **経路詳細（`TrackDetailScreen`・履歴から開く）**: **記録中**（履歴一覧の“記録中”カードから開く）／**記録済み**。
  - 記録画面と経路詳細は**別コンポーネント**だが、地図描画は共通（`RouteMapContent`）。同じ記録中トラックを
    両方から開ける（入口違い）。当面は**別画面のまま・タップ挙動だけ共通化**する（統合は将来）。
- **場所詳細（`PlaceDetailContent`）**: 1 つの場所の閲覧・編集。
- **場所追加「地図で選ぶ」（`AddPlaceContent`）**: 登録する地点を地図で選ぶ。トグル無し。

## 基本原則

- **登録済み表示 ON**: 近くの場所が**見えている**ので、そこであえて登録・追加するのは**意図的**とみなし、
  確認を出さず**そのまま新規**にする（座標30m同定はしない＝別 place として作る）。
- **登録済み表示 OFF**: 近くに場所があることに**気づけない**ので、`ID` 無しの登録・追加の確定時に
  **近接確認**（半径 50m ＝検出半径）を行い、既存があれば「**紐付け／新規**」を選ばせる。
- **POI（`googlePlaceId` あり）** は施設の同一性で同定するので、近接確認は出さない（[ADR-0006](../adr/0006-place-identity-by-googleplaceid.md)）。
- 半径は**50m に統一**（近接確認・立ち寄り検出と同じ。旧・場所登録の 30m 同定は廃止）。

## 経路マップ（記録画面・経路詳細で共通）

### 通常モード

| タップ対象       | 表示 ON                                | 表示 OFF                                    |
| ---------------- | -------------------------------------- | ------------------------------------------- |
| POI              | 場所登録                               | 場所登録                                    |
| 空き             | 場所登録（そのまま新規）               | 近接確認 → 紐付け／新規（無ければ新規登録） |
| 登録済みマーカー | 場所シートでその場編集（詳細も開ける） | （非表示＝無し）                            |
| 立ち寄りピン     | 選び直し ＋ 一覧で強調                 | 選び直し ＋ 一覧で強調                      |

### 手動追加モード（「立ち寄りを追加」ボタンで入る）

| タップ対象       | 表示 ON                            | 表示 OFF                                |
| ---------------- | ---------------------------------- | --------------------------------------- |
| POI              | 立ち寄り追加（POI を名前候補に）   | 立ち寄り追加（POI）                     |
| 空き             | 立ち寄り追加（そのまま新規 place） | 立ち寄り追加（近接確認 → 紐付け／新規） |
| 登録済みマーカー | 既存 place へこの立ち寄りを紐付け  | （無し）                                |
| 立ち寄りピン     | 選び直し ＋ 一覧で強調             | 選び直し ＋ 一覧で強調                  |

- 記録画面・経路詳細とも**記録中でも手動追加モードを使える**（記録中は末尾が伸び続けるので、到着/出発の推定はその時点の軌跡で行う）。
- 記録画面（平常時＝アクティブな記録なし）は**手動追加モードを持たない**（立ち寄りを足すトラックが無い）。通常モードのみ。

## 場所詳細画面（トグルあり）

| タップ対象                   | 表示 ON                          | 表示 OFF                |
| ---------------------------- | -------------------------------- | ----------------------- |
| POI                          | 場所登録（別の場所を追加）       | 場所登録                |
| 空き                         | 場所登録（そのまま新規）         | 近接確認 → 紐付け／新規 |
| 登録済みマーカー（自身以外） | 場所シートで編集（詳細も開ける） | （無し）                |
| 立ち寄りピン                 | （無し）                         | （無し）                |

## 場所追加「地図で選ぶ」（トグル無し＝OFF 相当）

| タップ対象   | 動作                                                                      |
| ------------ | ------------------------------------------------------------------------- |
| POI          | 地点を POI として選択（名前・`placeId`・カテゴリ）                        |
| 空き         | 地点を空欄で選択                                                          |
| 現在地ボタン | 現在地へ地図を寄せる                                                      |
| 登録の確定時 | `ID` 無しなら**近接確認** → 紐付け／新規（OFF 相当）。`ID` ありは施設同定 |

## タップ時の UI（統一の「場所シート」）

地図上の1点をタップしたときのダイアログは、対象（未登録の空き地点 / 未登録 POI / 登録済みの場所）で
バラバラだったものを、**1つの ModalBottomSheet（`PlaceActionSheet`）に統一**する。本体は追加・検索・編集と
同じ `PlaceFormBody` を共有し、対象に応じて中身と操作だけを出し分ける。

| 対象      | 本体                                                    | 主な操作                                           |
| --------- | ------------------------------------------------------- | -------------------------------------------------- |
| 空き地点  | 名前(任意)・メモ・行きたい・優先度                      | 登録（表示ON=新規／OFF=近接確認）                  |
| 未登録POI | ＋カテゴリ/住所・マップで開く                           | 登録                                               |
| 登録済み  | 現在値を入れて編集（訪問済みトグルは立ち寄り0件のとき） | 保存・**立ち寄りに追加**（記録中のみ）・詳細を開く |

- **登録済みマーカーの通常タップ**は、画面遷移ではなく**この場所シートでその場編集**（記録画面のまま編集できる）。
  full 遷移が要るときはシートの「詳細を開く」から。
- **「立ち寄りに追加」はアクティブな track がある記録中のみ**表示（平常時は track が無いので出さない）。
- 適用済み: 記録画面・場所詳細。**経路詳細は当面 従来の手動追加オーバーレイ（到着/出発の調整あり）を維持**し、
  シートには寄せない（滞在時間の編集が必要なため）。

## 補足

- **登録済みマーカーのタップ**はモードで意味が変わる: **通常＝場所シートでその場編集（詳細も開ける）**、**手動追加＝この立ち寄りを紐付け**。
- **「新規」を選んだとき**は座標30m同定をバイパスして必ず新しい place を作る（`forceNewPlace` 相当）。近接確認の
  「紐付け」は既存 place を使う。
- ボタン名は**「立ち寄りを追加」**に統一（旧「手動で追加」）。
