# 画面仕様（UI/UX仕様）

Jetpack Compose による Android アプリの画面仕様。**マップを主役にした map-first 構成**を基本方針とする。

> 対応する要望: [requirements.md](../requirements.md) の「地図で確認したい」「リアルタイムに記録したい」「操作をシンプルにしたい」。

## 設計方針

- **map-first**: 記録画面・詳細画面はどちらも全画面マップを土台にし、操作や情報はその上に重ねる（オーバーレイ／ボトムシート）。マップを小さなカードに埋めない。
- **ワンタップ記録**: 記録の開始/停止は大きな丸い FAB 一つ。
- **将来の拡張を地図とシートに載せる**: 写真・評価・タグはマップ上のピンとボトムシートの行として足せる形にしておく。
- **画面の型**: 地図の画面・一覧の画面の「どこに何を置くか」は [designs/ui-direction.md](../designs/ui-direction.md) の型に合わせる。この文書は今の姿で、型に移していない画面は型と食い違う（画面ごとの見直しで移す）。

## ナビゲーション構成

ボトムナビの4タブ（記録・履歴・場所・設定）。詳細画面（経路詳細）は全画面で開き、その間はボトムナビを隠す。「場所」タブの配下（一覧・追加・検索・詳細）は行き来しても入力途中の状態を保つ。

**一覧の絞り込み（名前の検索語を含む）・並べ替え・スクロール位置は、アプリを使っている間は保つ。** タブを押して移ったときも、記録タブ以外のタブで戻るキーを押して記録タブへ戻ったときも（戻るキーはタブを押したのと同じ扱い）、詳細へ進んで戻ったときも、入り直すと元のまま。アプリが裏で落とされてから戻ったときも、絞り込みと並べ替えは戻る。**アプリを自分で閉じて（記録タブで戻る・タスクから消す）開き直したときだけ初期状態**に戻る（開いたときに絞り込み中だと気づかない、を避けるため）。

**画面に出す日付には曜日を添える**（例: `2026/11/08(日)`・`2026年11月08日(日)`）。平日か休日か、何曜日のお出掛けかをすぐ分かるようにするため。曜日はアプリの文言に合わせて日本語で出す（端末の言語には依らない）。時刻だけの表示とファイル名の日時には付けない。

```text
┌─────────────────────────────┐
│                             │
│      各画面（全画面）         │
│                             │
├─────────────────────────────┤
│ [記録] [履歴] [場所] [設定]  │ ← BottomNavigationBar（詳細表示中は非表示）
└─────────────────────────────┘
```

| タブ | 機能                               | アイコン         |
| ---- | ---------------------------------- | ---------------- |
| 記録 | 全画面マップ＋GPS記録              | `ic_location_on` |
| 履歴 | 過去記録の一覧・統計               | `ic_list`        |
| 場所 | 登録済みの場所一覧・登録・行きたい | `ic_place`       |
| 設定 | GPS記録間隔などの設定              | `ic_settings`    |

> 「場所」はマイルストーンを前倒しして追加。全ての場所（places）を一覧し、各場所に「行きたい」を付け外しできる。将来の計画タブ（Phase 3）の前身。

## 画面設計詳細

### 1. 記録画面（ホーム / map-first）

全画面のライブマップ。自分の現在地（青ドット）を表示し、記録中は経路（補正後）をリアルタイムに描画する。
置き方は地図の画面の型（[designs/ui-direction.md](../designs/ui-direction.md)）に沿う。

```text
┌─────────────────────────────┐
│ (🔍 店名・場所名で検索 │🌐) [≋] │ ← 上: 検索の入口（窓＝検索して登録・地球＝地域へ移動）／レイヤー
│ (● 記録中 00:42)(🌐 鎌倉市 ×)  │ ← 上の下: 記録中のピル・取得中・地域の目印のチップ・登録の確認
│ [🔋 電池の最適化で…        ›] │ ← 上の下: 1 行の帯（出ているときだけ）
│         [全画面 Google Map]  │ ← 現在地追従・青ドット・経路polyline
│         ～～～ 経路 ～～～      │
│            ( ■ )        (◎) │ ← 主役の開始・停止の丸（シートの上）／右下: 現在地
│ ┌─────────────────────────┐ │
│ │ ───────────────     ▼ │ │ ← つまみ（▼で畳む）
│ │ 1.82km  412  ●立ち寄り中 │ │ ← 記録中: 距離・地点数・立ち寄り中
│ │ [今ここを立ち寄り][地図で指して追加]│ │ ← 記録中: 脇役の操作（停止中は「記録していません」）
├─────────────────────────────┤
│ [記録] [履歴] [場所] [設定]  │
└─────────────────────────────┘
```

- **開始・停止の丸**（下中央）: 停止中は ▶（`ic_play_arrow`・primary色）、記録中は ■（`ic_stop`・error色）。停止は確認ダイアログあり。下の記録のシートのすぐ上に置き、シートと一緒に動く。
- **記録のシート**（下）: 記録中は距離・地点数と、立ち寄りを検出中は「● 立ち寄り中」（場所名）、その下に脇役の操作（「今ここを立ち寄り」「地図で指して追加」）。停止中は「記録していません」だけの小さなシート。▼ で畳むと**丸も一緒に隠れ**、下に戻すボタン（記録中は「▲ 記録中・1.82km」、停止中は「▲ 記録していません」）だけが残る（→ [ADR 0042](../adr/0042-primary-action-moves-with-sheet.md)）。開いたとき・記録を始めたときはシートが出ている。場所シート・立ち寄りシート・この範囲の経路が出ている間は下がる（閉じれば戻る）。
- **現在地ボタン**（右下・`ic_my_location`）: 追従中は塗り、手動で地図を動かすと白（固定）。タップで現在地へ再センター＆追従再開。シートの上端に沿って上下する（畳んだシートは戻すボタンの上）。取得中は上の下に「現在地を取得中…」。
- **記録中の表示**: 上の下に経過時間のピル（藍の淡い地に緑の点「記録中」）。距離・地点数・立ち寄り中は記録のシート。
- **1 行の帯**（上の下。出ているときだけ）:
  - **電池の最適化**: 電池の最適化が有効なままだとバックグラウンド記録が止まりやすいため「電池の最適化で記録が止まることがあります ›」を出す。押すと設定タブの「電池の最適化」へ（説明と無効にするボタンはそこ）。
  - **位置情報 OFF**: 端末の位置情報が OFF で記録を開始できなかったとき「端末の位置情報がオフです ›」。押すと端末の位置情報の設定を開く。
  - **エラー**: 記録のエラーを 1 行で出す（押せない）。
- **権限がない場合**: マップ中央に権限リクエストのカードをオーバーレイ表示（「位置情報を許可」ボタン）。
- **中断記録の復帰**: アプリ更新などで前回記録が中断されていた場合、起動時に「再開する／完了にする」ダイアログを表示。
- **場所の登録（POIタップ）**: マップ上の施設アイコン（POI）をタップすると**場所シート**（自分で付ける名前・メモ・行きたいトグル・優先度）を表示。シートはモーダルでないので、出したまま地図を動かせる。登録した場所は「場所」タブに現れる。登録直後は上部に確認ピルを一時表示。何もない地点のタップでも同じシートで登録できる（挙動の一覧は「地図タップの意味」）。
- **登録済みの場所の編集・削除（マーカータップ）**: 「登録済みの場所」を表示中にマーカーをタップすると、**場所タブの詳細とまったく同じ編集画面**が出る（名前・メモ・行きたい・優先度・訪問済み・Google 施設の紐付け・訪問履歴・ほかの場所とまとめる・削除）。記録中はこれに「立ち寄りに追加」が加わる。入口が地図か一覧かでできることが変わらないようにするため、実体は1つを共有している。削除は即時で、下部のスナックバー「取り消す」で戻せる。
- **立ち寄りを追加（記録中のみ）**: 記録のシートの「地図で指して追加」で**追加モード**に入る（押すと「地図をタップ（やめる）」に変わる）。ON の間は地図タップが立ち寄り追加、OFF なら場所登録。同じくシートの**「今ここを立ち寄り」**は現在地をそのまま立ち寄りにするショートカット。滞在区間の調整は下部の立ち寄りシートで行う。
- **登録済みの場所の表示**: 上のレイヤー［≋］の「登録済みの場所」のスイッチで既存の場所をマーカー表示できる（訪問済み/未訪問で色、業種でアイコン、行きたいは右上の旗。いま行きたい＝橙、行きたいで行った＝緑の丸いチェック → [places.md](places.md)）。業種が分からない場所は場所ピンのまま。ON/OFF は画面ごとに独立して保存される。表示中はスイッチの下の**チップ**で、行きたい・訪問・業種で絞れる（条件は画面ごとに独立し、場所一覧とも別。アプリを閉じても残る → [map.md](map.md)）。表示中・この範囲の経路を出している間はレイヤーのボタンを塗りつぶし、登録済みの場所を絞り込んでいる間は右上に点を付ける（どちらもパネルを開いたまま切り替えても、すぐボタンに出る）。
- **立ち寄りマーカーのタップ**: 誤検知だったとき、その訪問だけ正しい場所へ**選び直せる**。
- **この範囲の経路**: レイヤー［≋］の「この範囲の経路」で（出している間にもう一度押すと閉じる）、**押した時点で地図に映っている範囲**に入る過去の経路を探し、下から一覧を出す（→ [map.md](map.md) の「この範囲の経路」）。
- **検索して登録**: 上の検索の入口の窓の部分（「店名・場所名で検索」）で、場所タブへ移らずにキーワードで場所を探して登録できる。**地図はそのまま**に、上端に検索窓を重ねる（開いている間は、窓と重なる上の区画と上の下を隠す）。店名などを入れると窓の下のカード（画面の半分ほどまで。その下は地図のまま）に候補（Autocomplete）が出る。候補は**窓を開いたときに地図に映っていた範囲の中を優先**する（範囲の外も出る。料金は変わらない）。候補を選ぶと窓を閉じて地図をその場所へ寄せ（現在地の追従は止まる。現在地ボタンで戻せる）、青いピンで示して**場所シート**を出す（POI タップと同じシートで、名前・行きたい・優先度・メモ）。登録すると上部に確認ピルを出す。候補の一覧は場所タブの「検索して追加」と同じもので、オンライン限定・要 Places API なのも同じ。窓は ×・戻る・地図のタップで閉じる（開いている間の地図のタップは、場所の登録ではなく窓を閉じるだけ）。候補の座標は選ぶまで分からないので、候補の段階では地図に印を出さない（全部の座標を引くと候補ごとに料金がかかるため）。立ち寄りの追加中は押せない。記録中・停止中のどちらでも使える。
- **地域へ移動**: 上の検索の入口の右端の地球のボタン（`ic_public`）で、地名を入れて探し、その地域へ地図を移す（旅行先・行ったことのない地域にも移れる）。「検索して登録」と同じ検索窓（地図はそのまま・候補は窓の下のカード・×・戻る・地図のタップで閉じる・開いている間は上の区画を隠す）で、候補は**地域だけ**（国・都道府県・市区町村・郵便番号など。施設は出ない）に絞る。候補は窓を開いたときに地図に映っていた範囲の中を優先する。選ぶとその地域の範囲が収まるように地図を移し、地域の中心に地名つきの目印（藍色のピン）を出す。目印がある間は上の下に**地名のチップ**（地球・地名・×）を出し、× で目印を消す（地図は動かさない）、地名でその地域の範囲へ寄せ直す。目印は別の地域を選ぶ（置き換わる）・目印のタップ・現在地ボタンでも消え、記録画面を離れても消える（→ [map.md](map.md) の「地域へ移動」）。現在地の追従は止まる（現在地ボタンで戻せる）。移すだけで、場所の登録はしない。オンライン限定・要 Places API（オフラインや取得の失敗は「地域の取得に失敗しました」）。施設を探して登録する「検索して登録」とは入口を分ける（→ [ADR 0032](../adr/0032-jump-to-region-by-places-autocomplete.md)）。記録中・停止中のどちらでも、立ち寄りの追加中でも使える。

### 2. 履歴画面

日付順の記録一覧。置き方は一覧の画面の型（見出し＋ツール行 → [designs/ui-direction.md](../designs/ui-direction.md)）に沿う。
項目タップで詳細画面へ。見出しの右のボタンで**一覧と地図を切り替え**られる（→「地図表示」）。

```text
┌─────────────────────────────┐
│ 外出履歴             [🔍][🗺] │ ← 見出し: 検索（押すと見出しの位置に窓）・地図への切り替え
│ [絞り込み 1]    [日付 ・ 新しい順 ▾]│ ← ツール行: 絞り込み（欄を開く）・表示のメニュー（並べ替えの軸と向き）
│ (初期状態に戻す)(お気に入り ×) │ ← 効いている条件のチップ（× で外す）
│ [12 / 38 回 ・ 148.3 km ・ 41 時間 20 分]│ ← 統計の帯（1 行）
│ [● 記録中 ・ 10:02 から ・ 3.2 km ›]│ ← 記録中があれば先頭に
│─────────────────────────────│
│ 秋の鎌倉さんぽ          ♥  ⋮ │ ← 名前（無ければ日付）／お気に入り／メニュー（名前を付ける）
│ 2026/07/19(日) 10:00–15:20 ・ 1.8 km ・ 立ち寄り 3│
│─────────────────────────────│
├─────────────────────────────┤
│ [記録] [履歴] [場所] [設定]  │
└─────────────────────────────┘
```

- **見出し**: 「外出履歴」・検索のアイコン・一覧／地図の切り替え。
- **名前の検索**: 見出しの検索のアイコンを押すと、見出しの位置が検索の窓になる。見出し（名前、未命名なら日付）に入れた文字を
  含む経路だけを残す。入力のたびに絞る。ほかの絞り込みとは AND。窓の × で語だけ消し、← で窓を閉じる（語も消える）。
  語が入っている間は窓のまま（語が効いていることが見えるように。アプリが裏で落とされて戻ったときも）。
- **絞り込み**（5軸独立・AND）: お気に入り／命名／立ち寄りの有無／業種（立ち寄った場所の業種・複数選べて OR・件数つき）／地域（立ち寄った場所の都道府県 → 市区町村、海外は国 → 都市の 2 段・複数選べて OR・件数つき。立ち寄りの無い経路は地域不明 → [places.md](places.md)）。ツール行の左の絞り込みのボタンで開く欄（一覧の先頭）で選び、効いている条件はチップで出す（→「絞り込みの欄」）。
- **表示のメニュー**（ツール行の右）: ボタンに今の並べ方（「日付 ・ 新しい順」）を出し、押すと**並べ替えの軸**（日付・立ち寄り数・距離・時間・名前）と
  **向き**を選ぶメニューが開く。向きは軸に合わせた文言（日付＝新しい順／古い順、立ち寄り数＝多い順／少ない順、距離・時間＝長い順／短い順、
  名前＝あ → ん／ん → あ）で、軸の既定の向きを先に出す。軸を選ぶと向きは軸の既定に戻る。
- **統計の帯**: 記録数・総距離・総時間を 1 行で（「12 回 ・ 148.3 km ・ 41 時間 20 分」）。数字を大きく太く、単位と区切りは小さく出す。総距離は 100 km 以上なら小数を落として 3 桁区切り（「3,815 km」）。**絞り込みに合わせて**、一覧に出ている経路だけで数える。
  絞り込み中は「12 / 38 回」のように全体の件数を添える。3 つの数字で全部なので、押して開く詳しい統計は無い。
- **記録中**: 記録中のお出掛けがあれば、統計の帯の下に 1 行の帯（記録中・開始の時刻・距離）で出す。押すと経路詳細へ。
- **記録項目**: 影の無い平らな行（下に区切り線）。見出しは**名前があれば名前**（無ければ日付）。2 行目に、名前ありのときは日付、
  開始–終了の時刻・移動距離・**立ち寄り件数**。右に**お気に入りハート**（その場で切り替え）と**メニュー**（名前を付ける／名前を編集）。
  **削除は経路詳細の ⋮ にある**（一覧の行には出さない）。
- 記録が無いときは「記録がありません」。絞り込みで 0 件なら「条件に合う記録がありません」。
- **先頭へ戻るボタン**: 先頭の項目（統計の帯）が画面から外れるまでスクロールすると、右下に「↑」のボタンが出る。押すと一覧の先頭まで滑らかに戻る。先頭にいるときは隠す。
- 一覧に載るのは**完了済み**だけ。記録中は先頭に別枠で出す。
- 経路詳細で消した経路は、取り消しを待っている間（スナックバーが出ている間）も一覧から隠す（→ 詳細画面の「この記録を削除」）。

#### 地図表示

見出しの右のボタン（`ic_map`／`ic_list`）で一覧と地図を切り替える。絞り込んだ経路のうち、**選んだものだけ**を地図に重ねて見比べる
（線は重ねると見分けがつかないので、全部は出さない）。置き方は地図の画面の型（上に一覧の見出しとツール行を重ねる・右下に地図の操作・下にシート）。

```text
┌─────────────────────────────┐
│ 外出履歴          [🔍][📋][⌃] │ ← 一覧と同じ見出し（一覧へ戻る）／たたむ
│ [絞り込み 1]              [≋] │ ← ツール行: 右は表示のメニューの代わりにレイヤー
│ (お気に入り ×)               │
│         [全画面 Google Map]  │
│   ～～ 青の線 ～～ ①②       │ ← 選んだ経路（色分け）と立ち寄り（同じ色の番号）
│                        (⛶) │ ← 右下: 選んだ経路をすべて見る（選んでいるときだけ）
│                        (◎) │ ← 右下: 現在地へ移動（位置情報の許可があるときだけ）
│ ┌─────────────────────────┐ │
│ │ 絞り込んだ経路 12 件  [すべて外す]│
│ │ 地図に重ねる経路を選ぶ（2 / 8 本）│
│ │ ☑● 秋の鎌倉さんぽ        ⛶ │ │ ← チェックで選ぶ・行のタップで経路詳細
│ │ ☐  2026/08/02 ・ 3.4km    ⛶ │ │
│ └─────────────────────────┘ │
├─────────────────────────────┤
│ [記録] [履歴] [場所] [設定]  │
└─────────────────────────────┘
```

- 地図はタブいっぱいに広げ、一覧と同じ見出し（検索・切り替え）とツール行（絞り込み）を地図の上に重ねる。重ねたものは**たためて**、たたむと
  切り替えと「絞り込み 1・3 / 12 件」のような帯とレイヤー［≋］だけになる（場所タブの地図表示と同じ）。絞り込み・名前の検索は一覧表示と**共有**する。
  絞り込みの欄は重ねたものの中に出す（高さを抑えて中でスクロール）。統計の帯と表示のメニュー（並べ替え）は出さない。
- **レイヤー［≋］**（ツール行の右）: 地図に重ねる**登録済みの場所**の表示と絞り込み（行きたい・訪問・業種）。記録画面・経路詳細と同じパネルで、
  ON/OFF と絞り込みは履歴の地図だけのもの（経路詳細とも別。アプリを閉じても残る → [designs/ui.md](../designs/ui.md) の「表示トグルの保存先」）。
  マーカーは経路より奥に描き、タップは吹き出しだけ（→ [map.md](map.md)）。
- 下のシート（畳みきれない）に**絞り込んだ経路の一覧**を出す。並びは一覧表示の並べ替えのまま。**チェックで選ぶ**と地図に重なり、
  **行のタップで経路詳細**へ。行の見た目・選び方・色・上限は記録画面の「この範囲の経路」と同じ（→ [map.md](map.md)）。見出しの「すべて外す」で選んだ経路をすべて外す。
- 選んだ経路は、絞り込みを変えて一覧から外れても**外すまで残る**（シートの下に「絞り込みの外（重ねている経路）」として出し、そこから外せる）。
  経路詳細へ行って戻っても、タブを切り替えても残る。アプリを閉じると消える。消された経路は外れる。
- **右下の地図の操作**（シートの上端に沿って動く。シートをいっぱいに広げている間は出さない）: 選んだ経路が入るまで寄せる（選んでいるときだけ）と、
  現在地へ移す（位置情報の許可があるときだけ。今の縮尺より引いているときだけ寄せる）。許可があれば地図に現在地の点も出す。
- 地図の範囲: 初めて開いたときは現在地あたり。経路を選んでも**地図は勝手に動かない**（見比べている最中に動くと分かりにくい）。
  各行の全体を見るボタンでその経路へ、右下の全体を見るボタンで選んだ経路すべてが入るまで寄せる。
  一覧表示に切り替えても、経路詳細から戻っても、見ていた範囲のまま。
- 線・立ち寄りのバッジのタップは吹き出しだけ（経路詳細へはシートの行から）。
- システムバックで一覧表示へ戻る（絞り込みの欄が開いていれば先に欄を閉じる）。一覧か地図かは、アプリが裏で落とされても戻る。

### 3. 詳細画面（map-first）

全画面マップに軌跡と立ち寄りを表示し、情報はドラッグ可能なボトムシートに畳む。
置き方は地図の画面の型（[designs/ui-direction.md](../designs/ui-direction.md)）に沿う。

```text
┌─────────────────────────────┐
│ ((←) 鎌倉さんぽ           ) [≋][⋮] │ ← 上: 戻る＋見出し（名前。無ければ日付）／レイヤー／その他
│ (● 記録中 00:42)              │ ← 上の下: 記録中の経路だけ
│         [全画面 Google Map]  │
│      ～～ 軌跡 ～～  📍立ち寄り │ ← 開始(緑)・終了/現在地(赤/青)・立ち寄り(紫)
│                        (⛶) │ ← 右下: 経路の全体を見る
│                        (◎) │ ← 右下: 現在地（位置情報の許可があるとき）
│ ┌─────────────────────────┐ │
│ │ ───────────────     ▼ │ │ ← つまみ（▼で畳む）
│ │ 14:30 – 15:50　1時間20分   │ │
│ │ 3.2km ・ 128点 ・ 立ち寄り2件 │ │
│ │ [場所を取得（未取得 1件）   ›]│ │ ← やることの帯（出ているときだけ）
│ │ (＋ 立ち寄りを追加)          │ │ ← 脇役の操作
│ │ ① ◯◯店  14:40–15:10 滞在30分 [旗][⋮]│
│ │ ② △△公園 …               [旗][⋮]│
│ └─────────────────────────┘ │ ← ボトムシート（引き上げで詳細）
└─────────────────────────────┘
```

- **上の区画**: 左は戻る＋見出しの窓（名前があれば名前と、その下に日付。無ければ日付だけ）。**見出しを押すと名前の編集**（一覧のカードのメニューと同じダイアログ）。右端はレイヤー［≋］（「登録済みの場所」の表示と絞り込み → [map.md](map.md)）と ⋮。記録中の経路は、その下に経過時間のピル（記録画面と同じ「● 記録中」）を出す。
- **⋮ の中**（経路への操作）: 「名前を編集」（未命名なら「名前を付ける」）・「お気に入りに入れる／お気に入りから外す」（履歴の一覧のハートと同じ）・「再解析」（点が 2 つ以上の経路。各モードの途中は押せない）・「この記録を削除」（記録中の経路には出さない。下の「経路の削除」）。開発版だけ、区切り線の下に「補正を調整」（調整中は「補正の調整をやめる」）と「GPS詳細（デバッグ）」。
- **右下の地図の操作**: 「経路の全体を見る」（`ic_fit`）と「現在地へ移動」（`ic_my_location`。位置情報の許可があるときだけ。一度だけ現在地を取って寄せる。追従はしない）。許可があるときは地図に現在地の点も出す（この画面からは許可を求めない）。シートの上端に沿って上下し、畳んだシートでは戻すボタンの上。GPS の点が無い経路と、各モード（再解析の候補・手動追加・期間の編集・補正の調整・場所シート）の間は出さない。
- **マーカー**: 形が「確定か、これから決めるものか」を表す。**丸**＝確定（開始＝緑、終了＝赤、記録中の現在地＝青、立ち寄り＝紫の番号、立ち寄り中＝ティール、登録済みの場所＝訪問状態の色＋業種アイコン）。**ピン**＝これから決めるもの（再解析の候補＝橙、手動追加で指した地点・登録前に選んだ地点＝青）。軌跡は橙色の線（補正後）。**各立ち寄りの滞在区間（到着〜出発の軌跡）を、濃い青の帯で軌跡の下に常時ハイライト**し、経路のどこで滞在したかが分かる（補正調整・候補選択・手動追加中は干渉を避けて非表示）。手動追加中は選んだ滞在区間を青い太線でハイライトする。
- **ボトムシート**: 先頭に時刻の範囲と所要時間（記録中は「14:30 – 記録中」）、距離・地点数・立ち寄り件数の 1 行、途切れた区間の注記。その下に、出ているときだけの**やることの帯**と、脇役の「＋ 立ち寄りを追加」。**3段階**で使う：既定は**ハーフ**（ピーク＝画面の約45%、地図が上・一覧が下で同時に見え、立ち寄りを連続タップして地図で確認できる）、上までドラッグかつまみの行のタップで**全画面一覧**（Expanded。もう一度タップでハーフへ）、下スワイプかつまみの右端の ▼ で**全画面地図**（Hidden、「▲ 詳細を表示」で復帰）。スナップ式なので途中位置では止まらない。**背後が暗くならず、シートを出したまま地図を操作できる**（モーダルではない）。
- **立ち寄り一覧**: 各行に場所名（未命名は座標）・到着–出発・滞在時間、**メモがあれば本文をインライン表示**（最大2行・省略）。行タップで地図をその場所へフォーカス（シートは畳まず地図だけが動くので、続けてタップして確認できる）。右の**行きたいの旗**（場所タブの一覧と同じ見た目・いま行きたい=塗り・行きたいで行ったことがある=緑の輪郭の旗に丸いチェック・それ以外=輪郭 → [places.md](places.md) の「かつて行きたいだったことを見せる」）を押すと、その場所を**ワンタップで行きたいに入れる／外す**（入れるときの優先度は「中」。旗は場所単位なので、同じ場所への立ち寄りの行はそろって変わる。選択モード中は出さない）。「メモ」で**訪問メモの編集ダイアログ**（stop 単位・複数行・空で保存すると消える。場所名 place 単位とは別物）。「編集」で名前編集ダイアログ。「削除」で1件、**行を長押しすると複数選択して一括削除**（記録中に拾った誤検知の掃除を想定。誤って消しても**再解析**で戻せる）。削除は単体・複数とも「訪問を消す」動作で、消した結果どこからも参照されなくなった場所だけ自動で場所ごと消える。**他の履歴や行きたいリストで使われている場所は残る**（その履歴の訪問だけ消える）。場所ごと明示的に消したいときは場所タブから。
- **削除の取り消し**: 削除は確認ダイアログを出さず**即時実行**し、**スナックバーの「取り消す」**でしばらくの間だけ元に戻せる（消した訪問と回収された場所を元のまま復元）。画面を離れると削除は確定する。
- **操作**（再解析は ⋮ の中、立ち寄りを追加はシートの脇役、場所を取得・同じ施設の確認待ちはシートのやることの帯）:
  - 「再解析」: 検出し直して**一覧に無い立ち寄り候補**を**地図に橙のピン**で出し（確定済みは紫の丸なので、色と形の両方で見分けられる）、**地図の下の固定オーバーレイ**（地図は常に表示・リストはその中で独立スクロール）で選ぶ（**非破壊・opt-in**）。各候補には**場所名**を添える（近くの命名済み place を再利用＝無料、無ければオンライン時のみ Places で1回）。行タップで地図がその候補へ寄るので、**名前と位置で「本当に立ち寄ったか」を確かめてから**チェックして**追加**できる。記録中の取りこぼしや、**誤って削除した立ち寄りの復旧**に使う。候補ゼロなら「見つかりませんでした」。既存の立ち寄りには触れない。
  - 「立ち寄りを追加」: 検出に頼らず**手で立ち寄りを足す**（完全手動・非破壊）。**記録中も使える**。押すと**追加モード**に入り、地図を**通常タップ**で地点を指す（**POI はタップで施設名も入る**）。指した地点は**青いピン**で示し、最寄り軌跡点から到着/出発を仮置き。下部の立ち寄りシートで滞在区間（到着〜出発）を調整でき、その区間は**地図に青くハイライト**されて経路のどこに当たるかが見える。調整は**スライダー（粗）＋ ＋/−（到着・出発を1点ずつ微調整）**の2段構えで、経路が長くても精密に合わせられる。名前は任意（POI 名で初期化）。地点確定後のキャンセル/バックは地点選択（マップ）に戻すだけ・地点選択中のキャンセル/バックで追加モードを抜ける（2段階）。検出しきい値に満たない短い滞在など、**再解析でも救えない立ち寄り**を足すのに使う。
  - 「場所を取得（未取得 N 件）」（やることの帯。`googlePlaceId` が無い場所を Google で命名する。オフラインで解決できなかった分の手動再実行・非破壊）。未取得が無ければ非表示。同じ施設の場所が既にあったら、その場でまとめるか別のまま残すかを聞く。
  - 「同じ施設の確認待ち N 件」（やることの帯。同じ施設の場所があって、まだ決めていない場所。押すと 1 件ずつ聞く → [places.md](places.md) の「同じ施設の場所が 2 つになったとき」）。無ければ非表示。
- **経路の全体を見る**: 右下の `ic_fit` ボタンで、経路の線と立ち寄りが全部入る範囲に地図を合わせ直す（立ち寄りの行をタップして寄ったあとや、地図を動かしたあとに、開いたときの見え方へ戻す）。シートに隠れる分は除いて、見えている部分に収める。記録中の経路では、押した時点までの線と立ち寄り（立ち寄り中を含む）で合わせる。GPS の点が無い経路では出さない。
- **経路の削除**: ⋮ の「この記録を削除」。**確認ダイアログは出さず**、画面を戻ってスナックバー「「秋の鎌倉さんぽ」を削除しました」と「**取り消す**」を出す（戻った先がどの画面でも。アプリ全体で 1 つのスナックバー）。点列・立ち寄りまで消えるので、すぐには消さず、**スナックバーが「取り消す」を押されずに閉じたら消す**。それまでは履歴の一覧から隠す。取り消すと一覧に戻る。続けて別の経路を消すと、前の経路はその時点で消す。待っている途中でアプリが落ちたときは消えずに残る。
- **補正の調整（デバッグビルドのみ）**: ⋮ の「補正を調整」で調整モードに入り、生データ（紫）を重ねつつスライダー（速度上限・平滑窓）で補正を試せる。⋮ の「補正の調整をやめる」かシステムバックで抜ける。
- **場所の登録（POIタップ）**: 地図の施設アイコン（POI）をタップすると**場所シート**（名前・メモ・行きたい）。振り返り中に見かけた場所を保存できる（記録画面・場所詳細と共通のシート）。登録済みのマーカーをタップしたときは、場所タブの詳細と同じ編集画面（削除・訪問履歴つき）が出る。タップした地点がシートに隠れないよう、地図はシートの高さぶん寄る。
- **将来**: このシートに写真・評価・コメント・タグの枠を追加（Phase 2）。

```text
└─────────────────────────────┘
```

重ねたものをたたむと、上端は `([≡] 絞り込み 1・3 / 12 件 [⌄])` の小さな帯（一覧への切り替え・絞り込みの様子・ひろげる）だけになる。

詳細（シートはハーフ）:

```text
┌─────────────────────────────┐
│ (← 喫茶ひなた / カフェ) [≋][⋮]│ ← 上: 戻る＋見出し・レイヤー・⋮（施設を選び直す・まとめる・削除）
│          [喫茶ひなた]         │ ← 吹き出し（開いた時点で出す）
│              ●              │
│                        (◉) │ ← 右下: この場所へ戻す・現在地
│ ┌─────────────────────────┐ │
│ │ 行きたいに登録      [ON] │ │ ← 主役: 行きたい・優先度・訪問済み・メモ
│ │ 優先度 ★★☆ / 訪問済み    │ │
│ │ [メモ               ]   │ │
│ │ ── 名前・業種・住所 …     │ │ ← 脇役・この場所を含むお出掛け（スクロール）
│ ├─────────────────────────┤ │
│ │                  [保存] │ │ ← 下端に固定（変更があるときだけ押せる）
├─────────────────────────────┤
│ [記録] [履歴] [場所] [設定]  │
└─────────────────────────────┘
```

- **見出し**: 「場所」・検索のアイコン・一覧／地図の切り替え。
- **名前の検索**: 見出しの検索のアイコンを押すと、見出しの位置が検索の窓になる（履歴と同じ部品）。表示名に含む場所だけを残す。
  入力のたびに絞り、検索語を変えたら先頭までスクロール。ほかの絞り込みとは AND。窓の × で語だけ消し、← で窓を閉じる（語も消える）。
  語が入っている間は窓のまま。
- **絞り込み**（4 軸独立・AND）: **行きたい**（指定なし/行きたい/行きたい以外）と**訪問**（指定なし/訪問済み/未訪問）と**業種**（複数選べて OR・件数つき）と
  **地域**（都道府県 → 市区町村、海外は国 → 都市の 2 段・複数選べて OR・件数つき → [places.md](places.md)）。ツール行の左の絞り込みのボタンで開く欄
  （一覧の先頭）で選び、効いている条件はチップで出す（→「絞り込みの欄」）。
- **表示のメニュー**（ツール行の右。一覧表示のときだけ）: ボタンに今の見せ方（「登録順 ・ 新しい順」、分けているときは「… ・ 地域」）を出し、
  押すと**並べ替えの軸**（登録順・訪問順・訪問回数順・行きたいで行った回数順・優先度順・名前順・更新順）・**向き**・**分け方**を選ぶメニューが開く。
  向きは軸に合わせた文言（登録順・訪問順・更新順＝新しい順／古い順、回数の軸＝多い順／少ない順、優先度順＝高い順／低い順、名前順＝あ → ん／ん → あ）で、
  軸の既定の向きを先に出す。軸を選ぶと向きは軸の既定に戻る。
- **一覧**: 既定は登録の新しい順（安定・トグルで並びが動かない）。**絞り込み・並べ替えを変えたときは先頭までスクロール**（変化を分かりやすく）。
  詳細から戻ったときは前に見ていた位置のまま。各行は影の無い平らな行（下に区切り線。履歴と同じ形）で、**名前 → 業種 → バッジ（行きたい優先度／訪問回数／
  行きたいで行った回数）→ 住所1行 → 並べ替えの軸の日付**の階層で表示（詰め込みすぎない。行きたいで行った回数は 1 回以上のときだけ）。
  右は**行きたいの旗**だけ（タップで付け外し／いま行きたい=塗り・行きたいで行ったことがある=緑の輪郭の旗に丸いチェック・それ以外=輪郭で判別。
  行きたいの場所に立ち寄りが記録されると自動で外れる → [places.md](places.md)）。**削除は場所詳細の ⋮ にある**（一覧の行には出さない）。
  **立ち寄り検出で自動生成された場所も含む**。場所が無いときは「場所がありません／右下の ＋ から登録できます」、絞り込みで 0 件なら「条件に合う場所がありません」。
  場所が 1 件も無いときはツール行を出さない。
- **先頭へ戻るボタン**: 先頭の行が画面から外れるまでスクロールすると、右下の追加の上に「↑」のボタンが出る（履歴タブと同じ）。
- **まとまりで分ける**: 表示のメニューの「分け方」で **分けない／地域で分ける／業種で分ける** を選ぶ。分けると一覧は**まとまりの見出し**（開閉の印・名前・件数）の並びになり、見出しを押すと開閉する。統計の帯はまとまりの上。地図表示では分けない。
  - **地域**: 都道府県 → 市区町村（海外は国 → 都市）の **2 段**。区分は絞り込みの地域と同じ（→ [places.md](places.md)）。市区町村が分からない場所は都道府県の直下（市区町村の見出しの後ろ）、地域が分からない場所は「地域不明」。**業種**: 絞り込みの業種と同じ区分の 1 段。
  - **並び**: まとまり同士は決まった順（場所を足しても位置が動かない）。都道府県は北から（全国地方公共団体コード順）→ 海外の国（名前順）→ 地域不明、市区町村・都市は名前順。業種は絞り込みの欄の並び（その他・未分類が最後）。まとまりの中は今の並べ替え（軸と向き）に従う。
  - **件数**: 絞り込み・名前の検索の後に残った場所で数え、0 件のまとまりは出さない（絞り込みとは独立で、絞り込んだ結果を分ける）。
  - **開閉**: はじめはすべて閉じて見出しだけを並べる。開いたまとまりと分け方は**アプリを閉じても残す**（開閉は分け方ごとに覚える。設定 `pathly_settings` に保存するので書き出しにも入る）。「初期状態に戻す」は分け方・開閉を変えない（並べ替えではなく見せ方の設定）。分け方を変えたときは先頭までスクロールし、開閉ではスクロールしない。
  - **名前の検索中**は、当たった場所が入っているまとまり（＝出ているまとまりすべて）を開いて見せる（閉じていると結果が見えないため）。この間は見出しを押しても開閉しない。覚えている開閉は変えず、検索語を消すと元に戻る。
- **統計の帯**: 一覧の先頭に、履歴画面と同じ形の 1 行の帯を置く（「42 か所 ・ 訪問 30 ・ 行きたいで行けた 2 / 7（28%）」。数字を大きく太く出す）。**場所の数**・**訪問済み**の数（判定は一覧と同じ: 立ち寄りの記録がある、または手で訪問済みにした）・**行きたいで行けた**。行きたいは行くと自動で外れて履歴に移るので（→ [adr/0036](../adr/0036-wishlist-ends-on-visit-and-keeps-history.md)）、達成は**行きたいにした場所**（いま行きたい、または行きたいで行ったことがある）のうち、**行きたいで行ったことがある**場所の数で数える（行った後に入れ直した場所は両方に入る。割合は切り捨てで、まだ残っているうちは 100% と出さない。行きたいにした場所が無ければ割合は出さない）。数える範囲は一覧と同じ（絞り込み・名前の検索の後に残った場所）で、絞り込み中は「42 / 176 か所」と全体の数を添える。3 つの数字で全部なので、押して開く詳しい統計は無い。**地図表示・絞り込みの欄を開いている間・場所が 1 件も無いときは出さない**。
- **地図表示**: 見出しの切り替え（一覧表示中は地図のアイコン、地図表示中は一覧のアイコン）で切り替える。置き方は地図の画面の型（上に一覧の見出しとツール行を重ねる・右下に地図の操作）。
  - 地図はタブいっぱいに広げ、一覧と同じ見出し（検索・切り替え）とツール行（絞り込み）・効いている条件のチップを地図の上に重ねる。絞り込みと名前の検索は一覧と共有し、切り替えてもそのまま。
    絞り込みの欄は重ねたものの中に出す（高さを抑えて中でスクロール）。統計の帯と表示のメニュー（並べ替え・分け方）は出さない。マーカーが場所そのものなので、レイヤー［≋］（登録済みの場所の表示）も置かない。
  - 見出しの右端の「たたむ」（`ic_expand_less`）で重ねたものをたたみ、上端の小さな帯（一覧への切り替え・「場所 12 件」／「絞り込み 2・3 / 12 件」・「ひろげる」（`ic_expand_more`））だけにする。帯の文言を押してもひろがる。
  - 地図には絞り込んだ後の場所だけを、ほかの地図と同じマーカー（まとまり・名前のラベルつき）で出し、範囲は全部が入るように合わせる（開いたときと絞り込みの結果が変わったとき。1 件ならその場所に寄る。0 件なら「条件に合う場所がありません」を重ねる）。範囲合わせと 0 件の文言は重ねたものの下に収める。マーカーのタップで場所の詳細へ。詳細から戻ったときや一覧表示を挟んで戻ったときは前に見ていた範囲のまま（その間に絞り込みの結果が変わっていれば合わせ直す）。
  - **右下**: 現在地へ移す（位置情報の許可があるときだけ。今の縮尺より引いているときだけ寄せる。許可があれば地図に現在地の点も出す）。その下に一覧と同じ追加の丸。
  - 地図表示でシステムバックを押すと一覧表示に戻る（吹き出しが出ていれば先に閉じる）。どちらで見ているか・たたんでいるかはアプリを使っている間は保つ（→ [places.md](places.md)）。
- **訪問済みの判定**: その場所に**立ち寄り（stops）記録が1件以上あれば訪問済み**（回数も表示）。立ち寄り記録が無い場所は**手動トグル**でも設定できる（記録がある場合は記録が優先で、トグルは出さない）。**行きたいとは独立した別の軸**なので、行きたいに入れずに訪問済みにでき、行きたいを外しても訪問済みは残る。
- **追加（右下の ＋）**: 一覧表示・地図表示とも右下の丸（同じ位置）。押すとメニューで「検索して追加」「地図で選ぶ」を選ぶ。
  - **検索して追加**: 店名などを入力 → 候補（Autocomplete）から選ぶ → 名前・住所・座標を取得して登録（行きたいトグル・優先度・メモ）。**オンライン限定・要 Places API(New)＋課金**。
  - **地図で選ぶ**: 全画面マップ（地図の画面の型）。上に戻る＋「地図で選んで追加」とレイヤー［≋］（登録済みの場所の表示・絞り込み。もう登録してある場所を見ながら選べる。マーカーのタップは名前の吹き出しだけ。画面別に覚える）。選ぶまでは上の下に「地図をタップして場所を選ぶ」の 1 行の帯。右下に現在地（位置情報の許可があるときだけ）。やめるときは戻る（左下のキャンセルは無くした）。**マップをタップして初めて場所シートを出す**（マップを広く使う）。**アイコン(POI)をタップすると施設名が見出しに出る**（名前欄には入れない＝名前欄は自分で付ける名前専用）。シートの「キャンセル」「登録」は**下端に固定**し、本文をスクロールしても隠れない。保存＝**まず場所を登録**し、「行きたい」トグルがONのときだけ wishlist にも入れる（優先度はON時に表示・メモは常時）。**「訪問済み」も登録と同時に付けられる**（このアプリを使う前に行った場所を登録するため）。
- **詳細**: map-first。地図の画面の型（四隅 → [designs/ui-direction.md](../designs/ui-direction.md)）に載せる（上の図）。**上**に戻る＋見出し（表示名。下に業種）と、右端にレイヤー［≋］（登録済みの場所の表示・絞り込み）・⋮（しまうもの: Google で情報を取得／Google 施設を選び直す・ほかの場所とまとめる・この場所を削除）。**右下**に「この場所へ戻す」と現在地（位置情報の許可があるときだけ。地図に現在地の点も出す）。シートの上端に沿い、フルに広げている間は出さない。**下**は他の地図画面と同じ**非モーダルのシート**で、その高さぶんマップに余白を入れ、ピンが隠れないようにする（畳めば全画面地図・「▲ 詳細に戻る」で復帰）。シートの並びは、同じ施設の確認待ち（出ているときだけ）→ 主役（行きたい・優先度・訪問済み・メモ）→ 脇役（自分で付ける名前・業種・住所・Google マップで開く）→ この場所を含むお出掛け。**保存はシートの下端に固定**し、スクロールしなくても押せる（**変更があるときのみ活性**）。**開いた時点でマーカーの吹き出し（名前・状態）も出す**（他の画面でマーカーをタップしたときと同じ見え方）。これは画面の一部なので**バックは常に画面を戻る**（吹き出しでバックを消費しない）。地図の他所や別のマーカーをタップすると一旦消えるが、そこで開いたシートを閉じてこの場所に戻れば出し直す。名前欄は**自分で付ける名前**専用（空で未命名に戻る。空のときだけ「この名前から書き換える」で Google 名を流し込める）。行きたいの付け外し、ON時は優先度を編集。行きたいで行ったことがあれば、切り替えの下に「行きたいで 3 回行った（最後は 2026/10/02）」と出す。訪問済みは行きたいと独立に付け外しできる（メモも行きたいに関わらず編集可）。訪問済みは回数も表示。**この場所を含むお出掛け（N件）**を一覧（日付＋その場所の滞在、**その訪問のメモがあれば表示**）、タップで経路詳細（振り返り）を開く。訪問メモの**編集は履歴詳細**で（ここは表示のみ）。**ほかの場所とまとめる**（⋮ から。200m 以内のほかの場所から選び、この場所をそちらへまとめる。一覧へ戻って取り消し可能 → [places.md](places.md) の「手で場所をまとめる」）。**削除**（⋮ から。即時・一覧へ戻って取り消し可能）。マップの別のPOIをタップすると、その場所も登録できる（共通の場所シート。開いている間はこの場所のシートと入れ替わる）。**この編集画面の中身は、記録画面・経路詳細の地図でマーカーをタップして出るものと同一**（実体は 1つ。マーカーのシートでは名前と ⋮ をシートの見出しの行に出し、下端に「閉じる」も並ぶ）。
- **削除**: 場所の編集画面の ⋮（一覧から開く詳細は上のバー、地図のマーカーから開くシートは見出しの行）から（一覧の行には出さない）。**立ち寄り記録（stops）がある場所は削除不可＝押せない**（記録を残すため。⋮ では理由を添える）。行きたい・座標だけが紐づく場所のみ削除でき、place・wishlist・解決ログを消す（stops は消さない）。**確認ダイアログは出さず即時削除**し、**一覧のスナックバー「取り消す」**でしばらくの間だけ元に戻せる（place・wishlist・解決ログを元のまま復元）。詳細から消した場合も一覧へ戻って取り消せる。記録画面・経路詳細の地図から消した場合は、その画面のスナックバーで取り消す。
- **後段（未実装）**: タグ（複数）。

### 絞り込みの欄（場所・履歴の一覧）

場所一覧と履歴（経路一覧）の絞り込みは、同じ形にする（→ [ADR-0031](../adr/0031-list-filters-in-a-panel.md)）。

```text
│ [🔍 名前で検索            ]│
│ [⚙ 絞り込み 2 ▴][登録順 ▾][↓]│ ← 絞り込みのボタン（効いている数・開閉）・並べ替え（ここは動かない）
│┌────────────────────────┐│
││ 4 件  初期状態に戻す すべて外す││ ← 絞り込みの欄（一覧の先頭に入り、一覧と一緒にスクロール）
││ 行きたい [指定なし|行きたい|以外]││
││ 業種  カフェ 他1        ▾ ││ ← 業種・地域はふだんたたむ
│└────────────────────────┘│
│ 場所8 …                   │ ← 結果
│      (▴ 絞り込みを閉じる)     │ ← 欄を開いている間だけ浮かぶ（戻るでも閉じる）
```

欄を閉じているときは、ボタンの下に効いている条件のチップが出る（`(初期状態に戻す)(行きたい ×)`）。

- **絞り込みのボタン**を押すたびに、**絞り込みの欄**を開く／閉じる。効いている条件があればボタンを塗りつぶし、数を添える。
  上のボタンは片手だと親指が届きにくいので、欄を開いている間は**画面の下の中央に「絞り込みを閉じる」**を浮かべ、
  **戻る操作でも欄を閉じる**（場所タブの地図表示では、地図の吹き出し → 欄 → 一覧表示へ戻る、の順）。
- 欄は**一覧の先頭**に入り、一覧と同じスクロールで動く。選んだ時点で一覧に効くので、選んだら下へスクロールして結果を見られる。
  開いたときは欄が見えるよう一覧の先頭へ寄せる。場所タブの地図表示では、地図に重ねた部分の中に出す（高さを抑えて中でスクロール）。
  - 欄の見出しに**残る件数**（「4 件」）と「**初期状態に戻す**」「**すべて外す**」（欄の軸をまとめて外す。名前の検索語は欄の × で消すので消さない）。
    どちらも押せないときは消さずに押せなくする（隣のボタンの位置が変わらないように）。
  - 3 状態の軸（行きたい・訪問、お気に入り・命名・立ち寄り）は「指定なし／〇〇／〇〇以外」を**並べたボタンから選ぶ**。
    押すたびに状態が巡る形にはしない（押す前に何が起きるか分かるように）。
  - 業種・地域は**ふだんたたみ**、見出しに選んでいるもの（「カフェ 他1」・無ければ「指定なし」）を出す。見出しを押すと開く。
    業種は件数つきのチップ、地域は 1 段目（都道府県・国）の行に件数とチェックを付け、▼で市区町村・都市を開く。
- 欄を閉じているときは、一覧の上に**効いている条件だけ**をチップで並べ、× でその軸を外す（業種・地域は選んだものをまとめて外す）。
  **欄を開いている間はチップの行を出さない**（選んでいるものは欄に見えている。選ぶたびに行が出たり消えたりして、欄がずれないように）。
  チップ自体を押すと、3 状態の軸は「〇〇 ⇄ 〇〇以外」を切り替える（「行きたい」→「行きたい以外」）。業種・地域は切り替える先が
  1 つに決まらないので、押すと欄が開く。外すのは × だけ（うっかり押して消えないように）。
  文言は「行きたい」「未訪問」「カフェ 他1」「東京都 府中市」など。何も効いていなければチップの行は出さない。横に収まらなければ横にスクロールする。
- 絞り込み・名前の検索・並べ替え（軸と向き）のどれかが開いたときと違えば、チップの行の先頭に「**初期状態に戻す**」を出す（欄を開いている間は欄の見出しのもの）。
  押すとまとめて開いたときの状態に戻す（場所一覧の一覧／地図の切り替えはそのまま）。
- 地図のマーカーの絞り込み（記録画面などの「登録済みの場所」のパネル）は、地図の上で軽く切り替える用なので、今はチップのパネルのまま（→ [map.md](map.md)）。

## デザイントークン

値の正はコード（`ui/theme/` の `Color.kt`・`Type.kt`・`Dimens.kt`）。見本は Design System

### 余白・角丸・影

- **余白**（`PathlySpacing`）: 4dp の段 `xxs` 2・`xs` 4・`sm` 8・`md` 12・`lg` 16・`xl` 24・`xxl` 32。
  一覧・シートの左右は `screenEdge`（16）、地図に浮かべる部品と画面の縁は `mapEdge`（12）。
  今の画面の余白はまだ数値のままで、画面を型に移すとき（#193〜#197）に置き換える。
- **角丸**（`MaterialTheme.shapes`・`PathlyShapes`）: `small` 8（チップ・帯）・`medium` 12（カード・案内・入力欄）・
  `large` 20（複数行になり得る浮かぶ案内・FAB）・`extraLarge` 28（ダイアログ）・`PathlyShapes.sheetTop` 20（シートの上端）・`PathlyShapes.pill`（地図の丸ボタン・検索窓・ピル）。
- **影**（`PathlyElevation`）: 地図の上に浮かぶものだけに付ける。`low` 2dp（地図に重ねる見出し）・`floating` 4dp（検索窓・地図の操作・ピル・チップ）・`sheet` 8dp（シート）。

### アイコン

アプリのアイコンは、藍（`primary`）の地に、地図の経路と同じ橙の経路と出発の点、白い目的地のピン（`res/drawable/ic_launcher_*`）。
端末の「テーマ アイコン」が ON のときは形だけが使われ、色は壁紙から決まる。
開発版（`com.pathly.debug`）は並べて見分けられるよう、黄の地に藍の経路にする（→ [designs/release.md](../designs/release.md)）。

画面で使うアイコン（`ic_location_on` / `ic_list` / `ic_place` / `ic_flag` / `ic_flag_filled` / `ic_flag_check` / `ic_favorite` / `ic_favorite_filled` / `ic_more_vert` / `ic_settings` / `ic_play_arrow` / `ic_stop` / `ic_arrow_back` / `ic_my_location` / `ic_tune` / `ic_delete` / `ic_filter` / `ic_map` / `ic_expand_less` / `ic_expand_more` / `ic_fit` / `ic_search`）。`ic_map` と `ic_list` は場所タブの地図表示・一覧表示の切り替え、`ic_expand_less` / `ic_expand_more` は地図表示で重ねたものをたたむ・ひろげる。`ic_place` は場所タブ、行きたいフラグは **OFF=`ic_flag`（輪郭）/ ON=`ic_flag_filled`（塗り・primary色）/ 行きたいで行ったことがある=`ic_flag_check`（輪郭の旗に丸いチェック・緑）** で区別する。
