# 0018. 地図マーカーは「確定＝丸／これから決める＝ピン」を形で表す

- Status: Accepted
- Date: 2026-08-16

関連: 登録済みの場所を地図に出す判断は [0008](0008-registered-places-on-map.md)、
そのグリフを業種にしたのは [0017](0017-normalize-place-category.md)。

## Context（背景）

地図のマーカーが増えた結果、2 つの問題が出ていた。

**1. 体系の外にあるマーカーが 3 種類あった。** 再解析の候補・手動追加で指した地点・場所タブで選んだ
地点は `BitmapDescriptorFactory.defaultMarker()`＝**Google 標準の雫ピン**で、自前の丸バッジと
まったく別の見た目をしていた。場所タブに至っては色指定すらなく既定の赤だった。

**2. 区別が色だけに載っていた。** 開始・終了・現在地・立ち寄り・立ち寄り中・登録済みが**すべて同じ
34dp の丸**で、違いは緑・赤・青・紫・ティール・グレーの 6 色のみ。覚えるのに負荷が高く、色覚特性に
よっては区別できない。重なったときは前後関係でしか読めず、実際に「立ち寄りを前面に描く」
「登録済みと同じ場所の立ち寄りは二重に描かない」という回避を入れていた。

## Decision（決定）

**形で「確定しているか、これから決めるものか」を表す。**

| 形           | 意味               | 該当                                                                 |
| ------------ | ------------------ | -------------------------------------------------------------------- |
| **丸バッジ** | 確定しているもの   | 開始・終了・記録中の現在地・立ち寄り・立ち寄り中・**登録済みの場所** |
| **ピン**     | これから決めるもの | 再解析の候補・手動追加で指した地点・登録前に選んだ地点／検索結果     |

- 色は**種別ではなく「どれか・どの状態か」**を担当する（立ち寄り＝紫、登録済み＝訪問状態の緑/グレー、
  候補＝橙、指した地点＝青）。
- ピンは自前で描く（`MapPinMarker`）。**Google 標準ピンは使わない。**
- ピンの**先端**、丸バッジの**下端**が、そのままマーカーの基準点（既定で下端中央）になるように
  寸法を組む。ここを崩すと指す座標が実際の場所からずれる。
- 場所の詳細画面が主題にしている場所も、他画面と同じ登録済みマーカーで描く（以前はここだけ
  Google 標準の赤ピンだった）。

## Alternatives（検討した没案）

- **形は全部丸のままにして、標準ピンだけ自前バッジに置き換える** … 差分は最小だが、区別が色頼みの
  ままで 2 番目の問題が残る → 却下。
- **「経路上の出来事＝丸／地図上の場所＝ピン」で分ける** … 登録済みの場所もピンになる。分類としては
  筋が通るが、**登録済みの場所は確定した情報**で、操作中のものと同じ形になるのは意味が合わない。
  ピンは縦に長く、登録済みが増えると密集して重なりやすい問題もある → 却下。「確定か否か」を軸にした。
- **色を減らして形を増やす（三角・四角なども使う）** … 判別はしやすくなるが、形が増えるほど
  「何の形が何を意味するか」の暗記が要る。2 種類なら規則として覚えられる → 却下。
- **ピンにも業種のグリフを出す** … 候補・選んだ地点はまだ場所として確定していないので、業種が
  分かっているとは限らない。`?`（候補＝提案）と `＋`（自分で置いた）で操作の意味を出す方が役に立つ → 却下。

## Consequences（結果・トレードオフ）

- **色が読めなくても種別が分かる**。「確定か、いじっている最中か」は形だけで判断できる。
- Google 標準ピンが無くなり、地図上のマーカーがすべて自前の体系に載った。
- ピンは**操作している間しか出ない**ので、縦長でも密集しにくい（候補の一斉表示だけは例外）。
- 立ち寄り（丸）と登録済み（丸）は依然として同じ形で、区別は色とグリフに残る。ただしこの 2 つは
  どちらも「確定したもの」なので、形が同じであること自体は決定と矛盾しない。
- ピンを Canvas で描いているため、輪郭の式を変えると見た目が変わる。寸法（頭の直径＝丸バッジと同じ
  34dp）を変えるときは、基準点が下端に来る前提も一緒に確認すること。
