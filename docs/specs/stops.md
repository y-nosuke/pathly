# 立ち寄りの仕様

「どこに何分いたか」を残す機能。**何が起きるか**だけを書く。作り方は同名の設計書にある。

> 対応する要望: [../requirements.md](../requirements.md)（立ち寄った場所を自動で検出してほしい／
> 気になった場所をワンタップで記録したい）。用語は [glossary.md](glossary.md)。

---

## 立ち寄りとは

補正後の軌跡で **50m の範囲に 3 分以上とどまった**箇所を、1 回の**立ち寄り（訪問）**として扱う。

- 立ち寄りは「**どの経路で・どの場所に・いつからいつまで**いたか」を持つ。
- 同じ場所に別の日に行けば、**立ち寄りは 2 件・場所は 1 件**になる。
- 立ち寄りには**訪問メモ**を付けられる。メモはその訪問だけのもので、同じ場所の別の訪問には出ない。

判定は位置と時間だけなので、**信号待ち・渋滞・屋内での座標の固まり**を立ち寄りと誤検知することがある。
誤検知は手で消せる（下記「消す」）。

## いつ検出されるか

**記録中に自動で**検出される。それ以外のタイミングでは自動検出しない
（経路詳細を開いても勝手には検出しない。「立ち寄りが 0 件」なのか「取りこぼした」のか区別できないため）。

記録中の見え方は 3 段階。

| 滞在時間                       | 見え方                                               |
| ------------------------------ | ---------------------------------------------------- |
| 3 分未満                       | 何も出ない                                           |
| 3 分を超え、まだその場にいる   | 地図に「**● 立ち寄り中**」（場所名と滞在時間）が出る |
| その場を離れた／記録を終了した | 立ち寄りとして**確定**し、一覧に移る                 |

- 「立ち寄り中」の表示は、**現在地がその範囲内にある間だけ**出る。離れた時点ですぐ消える。
- 確定していない「立ち寄り中」は、まだ記録として保存されていない。

## 名前が付く条件

確定した場所には、オンラインなら**近くの施設名が自動で付く**。

- **一度名前を引いた場所は、自動では引き直さない**。施設が見つからなかった場合も引き直さない
  （見つからない場所を何度も問い合わせないため）。
- **オフラインのときは何もしない**。通信が戻ったあとで自動的に付く。
- 名前が付かなかった場所には、あとから手で名前を付けられる（→ [places.md](places.md)）。

## 手で直す

検出は完璧ではないので、3 つの操作で補える。**いずれも既存の立ち寄りには触れない**（消さない・変えない）。

| 操作               | 何をするか                                                                           | いつ使うか                                   |
| ------------------ | ------------------------------------------------------------------------------------ | -------------------------------------------- |
| **再解析**         | 検出し直して、**一覧に無い候補**だけを地図とリストに出す。チェックした分だけ追加する | 記録中に取りこぼした／誤って消したものを戻す |
| **立ち寄りを追加** | 地図をタップした地点を立ち寄りとして足す。滞在区間（到着〜出発）は軌跡の上で調整する | 3 分未満の短い滞在など、検出に出ないもの     |
| **場所を取得**     | 検出はやり直さず、名前が付いていない場所だけ Google に問い合わせる                   | オフラインで名前が付かなかった分             |

- **再解析・立ち寄りを追加は、記録中でも使える。**
- ただし記録中の再解析は、候補を**確定済みの過去だけ**に絞る（滞在中・末尾はライブ検出が受け持つため、
  二重に登録されない）。
- 再解析の候補には**場所名が添えられる**ので、位置と名前を見て「本当に立ち寄ったか」を確かめてから選べる。
  候補が無ければ「見つかりませんでした」と出る。

## 消す

- 各行から**1 件ずつ**、行を**長押しすると複数選択**してまとめて消せる。
- **確認は出さず即時に消え**、スナックバーの「取り消す」でしばらくの間だけ戻せる。画面を離れると確定する。
- 消えるのは**訪問**であって場所ではない。同じ場所が他の経路でも使われていれば、その場所は残る。
- 消した結果どこからも参照されなくなった場所は、**自動検出で作られた場所だけ**が一緒に消える。
  自分で登録した場所と、行きたいに入れている場所は残る。
- 場所そのものを消したいときは「場所」タブから（→ [places.md](places.md)）。
- **記録中に消した立ち寄りは、そのままでは復活しない。**戻したいときは再解析で選び直す。

## 現状しないこと

- **しきい値を厳しくしても、既にある立ち寄りは消えない。**追加はできるが自動では減らない（手で消す）。
- **却下した候補を覚えない。**再解析のたび同じ候補が出る（チェックしなければ何も起きない）。
- **検出の精度は位置と時間だけ**で判定している。乗り物での停車を除外する仕組みは持っていない。
