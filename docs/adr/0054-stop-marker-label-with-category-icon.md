# 0054. 立ち寄りの印の名札に業種のアイコンを付け、引いた地図では番号だけにする

- Status: Accepted
- Date: 2026-11-28

## Context（背景）

地図の立ち寄りの印（記録画面・経路詳細・計画の詳細の「実際の立ち寄り」）は番号が主で、どこに寄ったのかが分かりにくい（#287）。
記録画面・経路詳細はバッジの下に名前を添えていたが、何の場所か（業種）は出ておらず、計画の詳細の印には名前も無かった。

- 立ち寄りの番号は一覧の行の頭の丸と対応していて、バッジの中は番号で埋まっている。
- 立ち寄りは 1 本の経路の中で近い所に並びやすい。登録済みの場所と違って近いものをまとめないので、引くと名前どうしが重なる。
- 計画の詳細の印は、日の色・日ごとの番号・白地の角丸で計画の番号と見分けている（#273）。

## Decision（決定）

- 3 画面（と記録画面の「重ねた経路」）の立ち寄りの印の下に、**名札（業種のアイコン＋名前）**を添える。アイコンは名前の頭に、
  名前と同じ濃い色・白のフチ取りで小さく置く。業種が分からない場所はアイコンを付けず名前だけ。バッジ（番号・色・形）と指す位置は変えない。
- **ズーム 15 未満では名札を隠し、番号だけにする。** 切り替えは地図が止まったときだけ。
- 登録済みの場所のラベルは今までどおりズームに依らず出す（近いものはまとまりになるので重なりにくい）。

## Alternatives（検討した没案）

- **バッジの右上に業種の小さな丸を重ねる** … 登録済みの場所の「行きたい」の旗と同じ位置で、旗と見間違えやすい → **却下**。
- **バッジを横長にして番号と業種を並べる** … 印が大きくなり、一覧の行の頭の番号の丸と見た目がそろわなくなる → **却下**。
- **ズームに依らずいつも名札を出す**（登録済みの場所と同じ） … 引くと立ち寄りの名札どうしが重なって読めず、番号まで隠れる → **却下**。
- **重なる名札を間引く** … どれを残すかの決まりが要り、ズームのたびに名札が出たり消えたりして落ち着かない → **却下**。

## Consequences（結果・トレードオフ）

- 寄れば、タップしなくても何の場所に寄ったかが読める。引いたときは今までどおり番号で経路の順が読める。
- 名札の分だけマーカーの画像が広がり、そのまわりのタップもマーカーに取られる（名札の幅は登録済みの場所と同じ 120dp まで）。
- 計画の詳細で計画の場所と同じ所に寄ったときは、実際の立ち寄りの印が計画の番号の丸の奥に隠れ、名札だけが丸の下に見える。
  計画の番号の丸には名札を付けない（予定の場所の名前はシートで読む）。
