# 0031. 一覧の絞り込みは、一覧の先頭に開く欄にまとめ、効いている条件だけをチップで出す

- Status: Accepted
- Date: 2026-11-12

関連: 業種の件数の出し方は場所一覧の仕様（specs/places.md）、地域は [0029](0029-place-region-by-geocoder.md)・[0030](0030-overseas-region-by-country-and-city.md)。

## Context（背景）

場所一覧（行きたい・訪問・業種・地域）と履歴（お気に入り・命名・立ち寄り・業種・地域）は、絞り込みの軸を
チップで横に並べ、横スクロールしていた。軸が増えて（#147）、次の困りごとが出ていた。

- 画面に入りきらず、右のチップが見えない。効いている条件がスクロールの先に隠れる。
- 3 状態の軸は、押すたびに「指定なし → 〇〇 → 〇〇以外」と巡る。未選択のときも同じ文言なので、押す前に何が起きるか分からない。
- 押して巡るチップと、メニューが開くチップ（業種・地域）が混ざり、操作がまちまち。

また、絞り込みを選びながら結果の一覧も確かめたい。

## Decision（決定）

- 一覧の上は「名前の検索欄」「絞り込みのボタン（効いている数・開閉）＋並べ替え」「効いている条件のチップ（× で外す）」にする。
  チップの行は**欄を閉じているときだけ**出す。開いている間に出すと、欄で最初の条件を選んだ・最後の条件を外したときに
  行が出たり消えたりして欄がずれ、押そうとした所が指の下から逃げる（実機で触って分かった）。選んでいるものは欄に見えている。
  - 3 状態の軸のチップは、押すと「〇〇 ⇄ 〇〇以外」を切り替える。前の巡るチップで、欄を開かずに反転できるのが便利だったため。
    指定なしには戻さない（外すのは ×。押してチップが消えると、うっかり外したのと区別が付かない）。業種・地域のチップは押すと欄を開く。
- 軸はすべて、ボタンで開く**絞り込みの欄**に縦に並べる。欄は**一覧の先頭**（一覧と同じスクロールの中）に入れ、
  選んだ時点で一覧に効く。選んだら下へスクロールして結果を見られる。
  - 3 状態の軸は、選択肢を**並べたボタン**（SegmentedButton）から選ぶ。
  - 業種・地域は選択肢が多いので、ふだんはたたみ、見出しに選んでいるものを出す（欄が長くなって結果が遠くならないように）。
  - 欄の見出しに残る件数と「すべて外す」（欄の軸だけを外す。名前の検索語は欄の × で消すので消さない）。
  - 場所タブの地図表示では一覧が無いので、地図に重ねた部分の中に欄を出す（高さを抑えて中でスクロール）。
- 欄を開いている間は、画面の下の中央に「絞り込みを閉じる」を浮かべ、戻る操作でも閉じる。上の「絞り込み」ボタンは
  右手の親指だと届きにくい（実機で触って分かった）。欄の一番下に置く案は、下へスクロールして結果を見ていると
  画面の外に出てしまうので採らなかった。
- 欄の中身は場所一覧と履歴で同じ部品（`ListFilterPanel` ほか）を使い、軸の並びだけ変える。
- 絞り込み・検索・並べ替えのどれかが初期状態と違えば「初期状態に戻す」を出し、まとめて戻せるようにする
  （並べ替えは欄の外にあり、「すべて外す」では戻らないため）。欄を閉じているときはチップの行の先頭、
  開いているときは欄の見出し（「すべて外す」の隣。どちらも押せないときは消さずに押せなくし、位置を変えない）。
- 地図のマーカーの絞り込み（「登録済みの場所」のパネル）は、地図の上で軽く切り替える用なので、チップのパネルのまま残す。

## Alternatives（検討した没案）

- **チップのまま、押すとメニューが開く形に揃える** … 変更は小さいが、横スクロールと、効いている条件が隠れる点は残る。
  軸がまた増えると同じ問題になる → **却下**。
- **よく使う軸だけチップに残し、残りを別の所へ** … どれが「よく使う」かが画面ごとに違い、条件の置き場所が 2 か所に分かれる → **却下**。
- **下から開くシート（全画面）** … 一度作って実機で触った。軸を見渡せるが、選んでいる間は結果の一覧が見えない → **却下**。
- **下から開くシート（画面の半分）** … 一度作って実機で触った。上に一覧が少し見えるが、シートは開いている間は一覧に
  触れない作りなので、一覧をスクロールしようとするとシートが閉じてしまい、一覧の見え方も中途半端だった → **却下**。
- **一覧を触れるシート（背後を暗くしない）** … 閉じてはしまわないが、一覧の見える場所が上の狭いところだけなのは同じ → **却下**。
- **欄を開いている間もチップの行を出し、行の高さを常に取っておく** … ずれは無くなるが、何も効いていないときも 1 行ぶん一覧が狭くなる → **却下**。
- **チップを絞り込みのボタンと同じ行に入れる** … 行は増減しないが、並べ替えもあって幅が狭く、チップがすぐ隠れる → **却下**。
- **選んでから「適用」で効かせる** … 選び直しの途中で一覧が動かないが、残る件数・結果が分からないまま選ぶことになる → **却下**。

## Consequences（結果・トレードオフ）

- 絞り込みの欄と結果が 1 つのスクロールになり、選びながら結果を見られる。閉じてしまうこともない。
- 効いている条件が一目で分かり、× で 1 つずつ外せる。軸が増えても欄に足すだけで済む。
- 欄を開くと、そのぶん結果が下へ押される（業種・地域をたたんで抑える）。欄を閉じるのは上の固定されたボタンで 1 タップ。
- 「すべて」チップは無くなった。まとめて外すのは欄の「すべて外す」、並べ替えも含めて戻すのは「初期状態に戻す」。
