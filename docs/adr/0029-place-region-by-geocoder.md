# 0029. 場所の地域（都道府県・市区町村）は、場所の座標から Geocoder で引いて places の列に持つ

- Status: Accepted
- Date: 2026-11-11

関連: 場所の静的な情報と動的な情報を分ける考え方は [0001](0001-place-data-separation.md)、
座標のアンカーは [0023](0023-place-identity-and-coordinate-anchor.md)。Google の内容の保存の見直しは #145。

## Context（背景）

「京都で行った場所」「神奈川に行った経路」のように、地名で場所・経路を絞りたい（#138）。
今の住所は、Google の施設情報を取ったときの `google_places.address`（`formattedAddress` の文字列 1 つ）
だけで、座標だけの場所には住所が無い。端末の言語で書き方も変わる。

Google Maps Platform の規約（2026-11 時点で本文を確認）では、Places API の内容で保存してよいと
明記されているのは place ID（期限なし）と緯度・経度（30 日まで）だけで、利用規約本体には
「business names, addresses をコピーして保存しない」とある。Android Geocoder SDK の項（Service Specific
Terms 3.3.2）は、緯度・経度・formatted_address・**項目ごとの住所**を、そのアプリの利用者に直接向けた
機能のためだけに、利用者ごとに分けて、期限なく保存してよいとしている。

## Decision（決定）

- 場所の**アンカー座標**（`places.latitude/longitude`。アプリが記録・指定した座標）から、Android の
  `Geocoder`（日本語で固定）で住所を引き、**都道府県**（`adminArea`）と**市区町村**（`locality`、
  無ければ `subAdminArea`）だけを `places` の列（`prefecture` / `city`）に持つ。引き終えた日時
  （`regionResolvedAt`）も持ち、null ならまだ引いていない。海の上などで分からなかったときは日時だけ入れ、
  引き直さない。
- 場所を作るときには引かない（記録中・オフラインでも場所はすぐ作れるように）。作った後に WorkManager の
  キャッチアップ（ネットワーク接続が制約）が書き足す。まだ引いていない場所が出てきたら予約し、
  通信の失敗は再試行に任せる。1 件が引けなくても後ろの場所は続けて引き（1 件のせいで残りを止めない）、
  続けて失敗したら通信断とみてやめる。書き足すのは地域の列だけで、`updatedAt`（自分で編集した日時）は動かさない。
- 一覧の絞り込みは、都道府県 → 市区町村の 2 段（件数つき・複数選べて OR）。経路は立ち寄った場所の地域で見る。

## Alternatives（検討した没案）

- **Places の住所（`formattedAddress`）の文字列から取り出す** … DB を変えずに済むが、座標だけの場所に
  付かず、端末の言語で崩れる。何より、保存が規約と合わなそうな Places の住所に頼る（#145）→ **却下**。
- **Places の `addressComponents` を取って持つ** … 項目ごとに取れるが、Places の内容の保存になる点は同じ → **却下**。
- **名前の検索欄で住所も対象にする** … チップを増やさずに済むが、住所の文字列が要る（上と同じ）うえ、
  「東京都」で絞るような使い方に向かない → **却下**。
- **経路の地域に、通った地域も含める** … 記録の点ごとに住所を引くことになり、通信と手間が増える。
  立ち寄った場所の地域で「行った経路」は見つかる → **却下**。
- **別の表（`place_regions`）に持つ** … 0001・`place_resolutions` にならって後から付く情報を分ける案。
  ただ地域は動かないアンカーから決まる場所の性質で、場所と 1 対 1。表を分けても結合が増えるだけ → **却下**。
- **`google_places` に持つ** … Google の施設情報（Places の内容）の表で、座標だけの場所には行が無い。
  Geocoder の結果を混ぜると、Places の内容の保存の見直し（#145）に巻き込まれる → **却下**。
- **場所を作るときに引く** … 作る処理がネット接続と問い合わせ待ちに縛られ、記録中・オフラインで困る → **却下**。

## Consequences（結果・トレードオフ）

- 座標だけの場所にも地域が付く。値は Geocoder が日本語で返す名前で揃う。
- 引くのにネットワークが要るので、オフラインで作った場所は、繋がるまで「地域不明」に入る。
- 引いた結果は端末の中だけで本人だけが使う（規約の「利用者ごとに分ける」に合う）。書き出しにも含まれる。
- アンカーは動かない（0023）ので、引き直しは要らない。場所と一緒に消え、削除の取り消しでも一緒に戻る。
- Geocoder が返す市区町村の粒度に従う（政令指定都市は「横浜市」のように市の単位になる想定）。
