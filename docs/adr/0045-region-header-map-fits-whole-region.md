# 0045. 場所一覧の地域の見出しから地図で見るときは、絞り込みを変えずに地域全域へ寄せ、範囲は Places で引く

- Status: Accepted
- Date: 2026-11-25

関連: 地域の範囲を Places で引くのは [0032](0032-jump-to-region-by-places-autocomplete.md)（記録画面の地域へ移動）と同じ。
費用の考え方は [0014](0014-place-naming-cost-policy.md)、地域の区分は [0029](0029-place-region-by-geocoder.md)。仕様は specs/screens.md「5. 場所画面」・specs/places.md。

## Context（背景）

場所一覧を「地域で分ける」で見ていると、その地域の場所が地図のどこにあるかを見たくなる（#226）。
今は地図表示に切り替えても、絞り込みの「地域」を選び直さないとその地域に寄らない。

決めることは 3 つあった。入口（見出しを押すと開閉するので、それとは別）、地図に出す場所（絞り込みを変えるか）、
寄せる範囲（場所が入る大きさか、地域全域か）。

## Decision（決定）

- **入口は見出しの右端（件数の右）の地図のボタン**。都道府県・市区町村（国・都市）の見出しに出し、「地域不明」には出さない
  （地名が無く、寄せる範囲を決められない）。見出しを押したときの開閉はそのまま。
- **絞り込み・名前の検索は変えない**。地図表示に切り替えて範囲を寄せるだけで、周りのほかの地域の場所も見える。
  一覧に戻ると、見出しの開閉もスクロールの位置もそのまま。
- **範囲は地域全域**。地名（「東京都府中市」「ホノルル アメリカ合衆国」）で地域に絞った Autocomplete を引き、
  段の合う先頭の候補（都道府県・国の見出しなら都道府県・国の候補、市区町村・都市なら国でない候補）の範囲（viewport）を
  Place Details で得る（引く項目は 0032 と同じく ID・位置・範囲だけ）。段で選ぶのは、「東京都」で探すと寄せた範囲の中の
  府中市が先に出たため。
  その地域の場所が範囲からはみ出すときは広げて入れる。候補はその地域の場所のあたりに寄せ（location bias）、
  どの場所も範囲に入らない（同じ名前の別の地域を引いた）ときは使わない。
- 引けた範囲はアプリを使っている間だけ覚え、同じ地域では引き直さない。
- オフライン・引けないときは、その地域の場所が全部入る範囲に寄せる（1 件ならその場所に寄る）。

## Alternatives（検討した没案）

- **見出しの長押し・⋮ のメニュー** … 長押しは見た目から分からず、⋮ は 1 手増える → 却下。
- **その地域を絞り込みの「地域」に入れる** … 地図にその地域の場所だけが出てチップで分かるが、一覧に戻っても絞り込みが効いたままで、
  一覧は先頭までスクロールし直す（見ていた位置を失う）。周りの場所が見えなくなる → 却下。
- **その地域の場所が全部入る範囲に寄せる（Places を使わない）** … 無料・オフラインでも動くが、場所が 1〜2 件だと
  地域のごく一部しか見えず、「その地域のどこにあるか」が分からない → オフラインの代わりとしてだけ使う。
- **地域の範囲をアプリに持つ（行政区域のデータを同梱）** … 料金もかからずオフラインでも引けるが、日本の市区町村だけで
  約 1,900、海外の国・都市は揃わない。データの更新も要る → 却下。

## Consequences（結果・トレードオフ）

- 都道府県でも市区町村でも、国でも都市でも、地域の広さに合わせて寄る。場所が少ない地域でも地域の中のどこかが分かる。
- 地図のボタンを押すたびに（覚えていない地域なら）Place Details の料金がかかる。ユーザーが明示的に押したときだけ叩き、
  引く項目を絞って安い区分に収める（0014 の「明示的に押したときは制限の外」と同じ扱い）。
- 範囲を引く間（ネットワークの往復）は前の範囲のまま待つ。
- 見出しの行の右端に押せる広さのボタンが入る。上下の余白を詰めて重ねるので、行の高さはほぼ変わらない（2 段目は少し高くなる）。
