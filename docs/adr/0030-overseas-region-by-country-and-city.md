# 0030. 海外の場所の地域は、国 → 都市で持ち、州は絞り込みに使わない

- Status: Accepted
- Date: 2026-11-11

関連: 地域の引き方・持ち方は [0029](0029-place-region-by-geocoder.md)。

## Context（背景）

0029 で、場所の地域を Geocoder で引いて `places.prefecture` / `city` に持つようにした。ただ国を見ていなかったので、
海外の場所は `adminArea`（州など）がそのまま「都道府県」に入り、47 都道府県の後ろに並んでいた（#146）。
海外の場所を登録することもあるので、国も含めて絞り込みたい。

国によって住所の作りが違う。英国は `adminArea` が England で州にあたるのは `subAdminArea`、シンガポールは州が無い、など。
場所のほとんどは日本にあり、海外は旅行先で数が少ない想定。

## Decision（決定）

- `places` に **国**（`countryCode`。`Address.countryCode` の ISO 3166-1 の 2 文字）を足す。名前は持たず、
  表示のときに国コードから日本語名（アメリカ合衆国 など）を作る。
- **日本は今のまま**: 一覧の 1 段目に 47 都道府県が並び、その中に市区町村。日本の場所を選ぶ手間は増やさない。
- **海外は国 → 都市**: 都道府県の後ろに国の行を出し、その中に都市（`locality`、無ければ `subAdminArea`、それも無ければ
  `adminArea`。ソウルのように市が `adminArea` にしか入らない所があるため）。
  **州は絞り込みに使わない**（国ごとに取り方が揃わないため）。ただし `prefecture` の列には `adminArea` を
  引いたまま残す（揃えるのは読むとき）。
- 並びは、日本の都道府県（北から）→ 海外の国（日本語名の順）→ 地域不明。
- 移行（DB v19）: `prefecture` が 47 都道府県のどれかの場所は日本にする。それ以外で引き済みの場所
  （海外の州が入った・分からなかった）は、国を取るために引き直す。

## Alternatives（検討した没案）

- **国をいちばん上に揃える（日本 → 都道府県 → 市区町村）** … 形は揃うが、ほとんどを占める日本の場所を選ぶのに
  1 段増える → **却下**。
- **国 → 州 → 都市の 3 段** … 広い国に場所が多いときは便利だが、国ごとに州の取り方を合わせる手間がかかり、
  メニューも深くなる。旅行先で場所が少ないなら国 → 都市で足りる → **却下**（要るようになったら、残してある
  `prefecture` の列から作れる）。
- **国の名前（`countryName`）を持つ** … 端末の言語や引いた時期で書き方が揺れうる。コードなら揃い、名前は作れる → **却下**。

## Consequences（結果・トレードオフ）

- 海外の場所も国と都市で絞れる。海外の場所が無ければ、見た目は今までと変わらない。
- 海外の都市の名前は Geocoder の返す名前に従う。日本語で引いても、エミュレータでは Honolulu・Paris のように英語などで返った
  （国の名前は国コードから作るので日本語になる）。
- 州で分けないので、別の州の同じ名前の都市（米国の Springfield など）は 1 つにまとまる。
- 移行の後、海外・地域不明だった場所はいったん「地域不明」に戻り、ネットワークに繋がると引き直されて移る。
