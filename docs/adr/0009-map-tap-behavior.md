# 0009. 地図タップの挙動を統一する（表示 ON=そのまま新規／OFF=近接確認、半径 50m）

- Status: Accepted
- Date: 2026-08-09

関連: 確定版マトリクスは [../specs/map.md](../specs/map.md)。前提は [ADR-0006](0006-place-identity-by-googleplaceid.md) / [ADR-0008](0008-registered-places-on-map.md)。

## Context（背景）

マップ画面が増え（記録画面・経路詳細・場所詳細・場所追加）、さらに**モード**（通常／手動追加）・
**登録済み表示 ON/OFF**・**タップ対象**（POI／空き／登録済みマーカー／立ち寄りピン）で、地図タップの意味が
バラバラになっていた。とくに問題は:

- **`ID` 無しの場所登録・立ち寄り追加が、無言の座標 30m 同定で既存にマージ**されてしまう
  （2 か所目を隣に登録しても一覧に増えず、しかも「登録しました」と出る）。
- 近接確認（③）が**立ち寄り追加にしか無く、場所登録には無い**。
- 立ち寄りピンのタップが記録画面（選び直し）と経路詳細（一覧強調のみ）で**不統一**。
- 記録画面には手動追加モードが無く、経路詳細は**記録中だと手動追加ボタンが非表示**。

## Decision（決定）

- **共通原則**: **表示 ON＝見えているので確認せずそのまま新規**（座標 30m 同定をバイパス）／
  **表示 OFF＝近接確認**（半径 50m ＝検出半径。既存があれば「紐付け／新規」、「新規」は同定バイパス）。
  これを**場所登録・立ち寄り追加の両方**に適用し、**無言の 30m 同定は廃止**する。
- **近接確認の半径は 50m に統一**（立ち寄り検出・②③と同じ）。
- **経路マップ（記録画面・経路詳細）を通常／手動追加モードで統一**する。通常＝場所登録、手動＝立ち寄り追加。
  **記録中でも手動追加を許可**（末尾が伸びる分は、その時点の軌跡で到着/出発を推定）。ボタン名は「立ち寄りを追加」。
- **タップ対象の意味を固定**: 登録済みマーカー＝通常モードでは**その場所の詳細を開く**／手動追加モードでは**紐付け**。
  （※ この一点は [ADR-0017](0017-single-place-editor.md) で置き換え。別画面へ移動するのではなく、
  詳細と同一の編集画面をその場のシートに出す。）
  立ち寄りピン＝**選び直し＋一覧で強調**（記録・経路詳細で統一）。POI＝場所登録（手動追加モードでは立ち寄り追加）。
- 記録画面と経路詳細（記録中）は当面**別画面のまま**、上記でタップ挙動だけ揃える（統合は将来）。

## Alternatives（検討した没案）

- **無言の 30m 同定を続ける** … 隣接登録が気づかずマージされ「登録しました」と食い違う → 却下（今回の不具合の原因）。
- **常に新規（同定しない）** … 表示 OFF で近くの既存に気づけず重複が増える → 却下。
- **表示 ON でも近接確認を出す** … 見えているのに毎回確認は冗長。ON は意図的とみなす → 却下。
- **記録画面と経路詳細を今すぐ 1 画面に統合** … 影響範囲が大きい。まずは挙動統一に留める → 後回し。
- **半径 30m のまま** … 検出半径 50m と食い違い、境界がユーザーに読めない → 却下（50m に統一）。

## Consequences（結果・トレードオフ）

- 画面・モードをまたいで一貫し、無言マージが無くなる（隣接登録の不具合が解消）。
- 記録画面と経路詳細（記録中）で同じ記録中トラックを扱えるが、当面は**二重の入口**が残る（将来統合の余地）。
- 変更が複数画面に波及するため**段階実装**する（詳細は設計書のマトリクス）。
