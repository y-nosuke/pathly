# 計画の仕様

これからのお出掛けを、場所とメモを日ごとに並べて計画する。日付を決めずに立てておき、後から日付を付けられる。
計画した場所に実際に行ったかは、立ち寄りの記録から分かる。

## 計画が持つもの

| 項目           | 説明                                                         |
| -------------- | ------------------------------------------------------------ |
| 名前           | 必須（新しく作ると「新しい計画」）                           |
| メモ           | 任意                                                         |
| 開始日         | 任意。**無ければ「日付なし」**。後から付けたり外したりできる |
| 日数           | 1 以上（1 は日帰り）。開始日が無くても持つ                   |
| 行             | 日ごとに並ぶ。**場所の行**か**メモの行**                     |
| 結び付いた経路 | 実際のお出掛け（下の「計画と実績」）                         |

### 行

| 行の種類 | 持つもの                                                             | 地図           |
| -------- | -------------------------------------------------------------------- | -------------- |
| 場所の行 | 場所（登録済みの場所を参照）・予定時刻・滞在の目安・メモ             | 番号付きで出す |
| メモの行 | 文言（「昼食（小町通りのどこか）」「新幹線で移動」）・予定時刻・メモ | 出さない       |

- 予定時刻（着く時刻）・滞在の目安・メモは、どれも付けなくてよい。並びは時刻ではなく手で決めた順。
- 場所の行には、着く時刻と滞在の目安から求めた**出発の時刻**も出す（「10:00 着 – 11:30 発・1時間30分」）。出発は持たず、毎回求める。日をまたぐ出発は何日後かを前に付ける（次の日は「翌1:00」、2 日後は「翌々1:00」、3 日後からは「3日後1:00」）。
- 同じ場所を同じ計画に 2 回入れてもよい（行き帰りに寄るなど）。
- 場所の名前は場所のもの（場所の名前を直せば計画にも出る）。

### 日付と日数

- 計画の日は「1日目・2日目…」で持つ。開始日を付けると、日の見出しに日付が添わる（`1日目 11/30(日)`）。
- 開始日を付け直しても、外しても、行は同じ日（何日目）のまま。
- **日数を減らすと、消える日の行は新しい最後の日の末尾へ移る**（消えない）。
- 日数が 1 なら「日帰り」と出し、日の見出しと日のチップは出さない。

### 計画と行きたい

- 計画と行きたいは**別のもの**。計画に入れても行きたいの旗は変わらず、旗を付け外ししても計画は変わらない。
- 計画の画面から新しく場所を登録するときだけ、登録のシートの「行きたい」で行きたいにも入れられる（**初期で入っている**。行きたくて計画に入れることが多いため。外せば行きたいには入らない。下の「場所を足す」）。

### 計画で使っている場所

- 自動の削除・自動の統合の対象にしない（自分で計画に入れた場所なので）。
- ほかの場所と手でまとめたら、計画の行は残す側の場所に付け替わる。
- 場所を手で消すときは「N 件の計画から外れます」と添える。消すと、その場所の行も計画から消える。

## 計画の一覧

計画のタブ（ボトムナビの 4 番目。記録・履歴・場所・**計画**・設定）。一覧の型（[designs/ui-direction.md](../designs/ui-direction.md)）に載せる。

```text
┌─────────────────────────────┐
│ 計画                    [🔍] │ ← 名前で探す
│ 日付なし ─────────────────── │
│ 京都の紅葉めぐり   2日・場所 6 │
│ これから ─────────────────── │
│ 鎌倉散歩 ●記録中              │ ← 記録中の経路が結び付いている
│ 11/30(日) 日帰り   行った 1/5 │
│ 終わった ─────────────────── │
│ 箱根                          │
│ 11/03(月)〜11/04(火) 行った 5/7│
│                        (＋) │ ← 新しい計画（主役）
├─────────────────────────────┤
│[記録][履歴][場所][計画][設定] │
└─────────────────────────────┘
```

- 「日付なし」「これから（最後の日が今日以降）」「終わった」に分ける。
  - 日付なしは新しく直した順、これからは近い順、終わったは新しい順。
  - 区分の見出しを押すと開閉する（件数を添える）。最初は「終わった」だけ閉じておく。開け閉めはアプリを使っている間だけ覚える。
  - 名前で探している間は、当たった計画が見えるようにすべての区分を開く。空の区分の見出しは出さない。
- 行は 2 行: 名前（1 行で省略）と、日付（日付なしの区分では日数）・「場所 N」。結び付いた経路があれば「場所 N」の代わりに「行った N/M」（場所の行の数のうち行った数）を出す。
- 記録中の経路が結び付いている計画には、名前の横に「● 記録中」を出す。
- （＋）を押すと「新しい計画」を作って、その詳細を開く。
- 削除は詳細の ⋮ から（一覧の行には出さない）。取り消しのスナックバーで戻せる。
- 下書きのある計画には名前の横に「✎下書き」を出す。名前・日付・場所の数は下書きのもの（開くと下書きの続きから始まるため）。
  一度も保存していない計画の下書きも、この印付きで並ぶ。

## 計画の詳細

地図の型（[designs/ui-direction.md](../designs/ui-direction.md)）に載せる。

```text
┌─────────────────────────────┐
│ (←) 鎌倉散歩    [保存][≋][⋮] │ ← 保存: 変更があるときだけ押せる。⋮: 名前・日付と日数・下書きを捨てる・削除
│ (すべて)(1日目 11/30(日))(2日目)│ ← 日のチップ（日帰りなら出さない）
│    ①───②                    │ ← 番号付きのマーカー。同じ日の中を順に直線で結ぶ
│          ╲                  │
│           ③✓           (◎) │ ← 行った場所は緑
│ ┌─────────────────────────┐ │
│ │ ───────────────     ▼ │ │
│ │ 11/30(日) 日帰り  行った 1/3 │ │ ← 要約
│ │ 場所を (＋)  (✎)            │ │ ← 場所を足す／メモの行を足す
│ │ 1日目 ─────────────── [×] │ │ ← 押すと地図にその日だけ。× でその日を消す
│ │⋮⋮① 鶴岡八幡宮 10:00 ✓  [⋮] │ │ ← 左端の取っ手で並べ替え
│ │⋮⋮・ 昼食（小町通りのどこか）[⋮]│ │ ← メモの行
│ │⋮⋮② 長谷寺     13:00    [⋮] │ │
│ └─────────────────────────┘ │
└─────────────────────────────┘
```

- **日の色**: 日ごとに色を 1 つ決め（8 色を順に使う）、地図のマーカーと線・シートの番号の丸・日の見出しの左端の帯・日のチップの点を
  同じ色にそろえる。地図と一覧の紐付けがひと目で分かるように。
- **地図**: 場所の行を、日ごとの番号（1 から。メモの行は数えない）のマーカーで出し、同じ日の中を順に**直線**で結ぶ。
  マーカーの座標は場所のアンカー。開いたとき・日を選び直したとき・行が増減したときに、出ているマーカーが全部入るよう寄せる（右下の［全体］でも）。
- **日のチップ・日の見出し**: 押した日だけを地図に出して寄せ、シートもその日の見出しへ寄せる（見出しをもう一度押すと「すべて」）。日が多ければチップは横にスクロールする。
- **日の見出しの ×**: その日を消す。その日の行は前の日の末尾へ移し（1 日目なら次の日の先頭）、後ろの日を 1 日ずつ詰める。日帰りには見出しが無いので出ない。
- **要約（「日付なし・日帰り」など）を押す**と「日付と日数」を開く。
- **名前が長いとき**: 見出し・行の名前・メモは 1 行で省略する。
- **日数**: 上限は付けない（長い旅行のため。入力は 3 桁まで）。日の見出しはシートの中に縦に並ぶ。行の無い日は「まだ何もありません」と出し、掴んだ行をそこへ落とせる。
- **行のタップ**: 場所の行は地図をその場所へ寄せる。メモの行は編集を開く。
- **行の ⋮**: 編集（着く時刻・滞在の目安・メモ。メモの行は文言も）・別の日へ移す・計画から外す（取り消しで戻せる）。場所の行は「場所の詳細を開く」も。
  - 滞在の目安は「1 時間 30 分」のように時間と分の 2 つの回転式の欄で選ぶ（真ん中を押せば数字で打てる）。着く時刻を決めると出発の時刻の欄が出て（決めていない間は出さない）、選ぶと滞在の目安がそれに合わせて変わる。
- **行を左へスワイプ**すると、確認なしで計画から外す（取り消しのスナックバーで戻せる）。
- **並べ替え**: 行の左端の取っ手（⋮⋮）に触れて縦に動かすと、長押しなしで掴む。掴むと端末が短く震えて行が浮き、
  ほかの行がよけて、離した所で順が決まる。日の見出しを越えれば別の日へ移る。行のほかの所を縦に動かすとスクロールする。
  読み上げ（TalkBack）では「上へ移す」「下へ移す」を出す。
- **⋮ の「日付と日数」**: 開始日（「日付なし」を選べる）と日数を変える。日付ありなら、開始・終了をそれぞれのカレンダーで選んでも、「期間で選ぶ」で始めと終わりを 1 つのカレンダーで選んでもよい（開始・終了・日数は連動する。開始を変えると日数はそのまま、終了を変えると日数が変わる。終了は開始より前を選べない）。
  日数は（−）（＋）のほか数字でも入れられる。
  減らすと消える日の行があれば「N日目より後の行 M 件は、N日目の末尾へ移ります」と添える。
  ほかの計画と日が重なる日付は決められない（→「計画の日付の重なり」）。
- 名前とメモ（見出しを押しても開く）・計画を消すのも ⋮ から。消すと一覧へ戻り、取り消しのスナックバーで戻せる。
- **新しく作ったとき**は「新しい計画」の名前・日付なし・日帰りで詳細を開く（名前のダイアログは自動では開かない）。「保存」するまで計画は作られない。

### 保存と下書き

詳細での変更（名前とメモ・日付と日数・行の追加・編集・並べ替え・別の日へ移す・外す・日を消す）は、**「保存」を押すまで計画に入らない**
（→ [ADR-0052](../adr/0052-plan-edits-saved-explicitly-with-drafts.md)）。

- 上のバーの「保存」は、保存済みの中身と違うとき（新しい計画は何か変えたとき・下書きから開いたとき）だけ押せる。
- 一度も保存していない計画には、上のバーに「下書き」も出す。押すと下書きに残し、画面は閉じない（保存済みの計画には出さない）。
- 変更してから戻ると「保存していない変更があります」と聞く: ［保存］［下書きに残す］［破棄］［編集を続ける］。
- **下書きに残す**と、編集の途中を端末に残す（アプリを閉じても消えない。書き出しにも入る）。計画ごとに下書きは 1 つ。
- 下書きのある計画を開くと下書きの続きから始まり、上に「下書きを編集中（いつ残したか）」の帯を出す。帯か ⋮ の「下書きを捨てる」で、
  保存済みの中身に戻す（一度も保存していない計画なら、計画ごと無くなる）。「保存」すると下書きは消える。
- 下書きの行は場所を指しているだけなので、その後に場所を消すと、下書きを開いたときにその行は無くなる。
- ⋮ の「この計画を削除」は今までどおりすぐ消える（下書きも一緒に消え、取り消しで戻る）。

### 場所を足す

シートの「場所を(＋)」を押すと、足し方の小さなメニューを出す: 「登録済みの場所から選ぶ」「検索して足す」「地図で選ぶ」。
足した場所は、今見ている日（「すべて」なら最後の日）の末尾に入り、シートはその日へ寄る。メモの行を足すときも同じ日に入る。

| 足し方                 | 何をするか                                                                       |
| ---------------------- | -------------------------------------------------------------------------------- |
| 登録済みの場所から選ぶ | 場所タブの一覧・地図を選ぶモードで開き、複数選ぶ                                 |
| 検索して足す           | 記録画面と同じ検索窓で施設を探し、場所として登録して足す（地域へ移動もできる）   |
| 地図で選ぶ             | シートを畳んで「地図をタップして足す場所を選ぶ」の帯を出す。タップで登録のシート |

- **登録済みの場所から選ぶ**: 場所タブの一覧を「選ぶモード」で全画面に開く。並べ替え・向き・分け方・絞り込み・名前の検索・地図表示が
  場所タブと同じに使える。行やマーカーを押すと選ぶ／外す（行の右はチェック、地図は選んだマーカーに緑の印）。下の「N 件を足す」で足す。「全解除」で選んだものを全部外せる。
  - 並べ替え・向き・絞り込みは**場所タブと共有する**（どちらで変えても同じになる。アプリを使っている間）。分け方・開閉はもとから共有。
    名前の検索語と一覧／地図の切り替えは別に持つ。
- **詳細の地図から**: レイヤー［≋］で「登録済みの場所」を出すと（計画に入っている場所は番号のマーカーなので出さない）、
  マーカーを押して「この場所を N日目 に足す」で足せる。
- **検索して足す**: 記録画面と同じ検索窓（「場所｜地域」の切り替えも同じ）を詳細の地図の上端に重ねる。
  - 場所を選ぶと、地図をその場所へ寄せて登録のシートを出す。
  - 地域を選ぶと、地図をその範囲へ移して地域の目印と境界を出す（記録画面と同じ。境界を出している間はダークモードでも地図を明るくする）。
    上のバーに地名のチップを出し、地名か目印を押すとその範囲へ寄せ直し、チップの × でその地域を外す。目印は保存せず、計画の画面を閉じれば消える。
- **地図のタップ**: 詳細の地図をタップする（POI を含む）と、**いつでも**登録のシートを出す（記録画面・経路詳細と同じ）。
  「地図で選ぶ」は、シートを畳んで案内の帯を出すだけ（タップすれば帯は消える。シートを戻しても消える）。
  この間に戻るを押すと、帯を消して計画のシートを戻す（計画の一覧へは戻らない）。

#### 登録のシート（計画から開いたとき）

場所タブ・記録画面と同じ登録のシート（行きたい／訪問済み・メモ・自分で付ける名前・カテゴリと住所）に、次を足す。

```text
│ 鶴岡八幡宮                     │
│ 足す日 (1日目)(2日目)(3日目)    │ ← 日帰りなら出さない
│ [⚑行きたい] [訪問済み]          │ ← 行きたいは初期で入っている
│ 優先度 …                       │
│ メモ（任意）                    │
│ ─────────────────────────── │
│          [キャンセル][登録して 2日目に足す] │
```

- **足す日**のチップ（1日目・2日目…）。初期は今見ている日（「すべて」なら最後の日）。日帰りなら出さない。
- **行きたいが初期で入っている**（行きたくて計画に入れることが多いため）。外して登録すれば行きたいには入らない。
- 登録のボタンは「登録して N日目に足す」（日帰りなら「登録して足す」）。登録すると、選んだ日の末尾に足し、シートはその日へ寄る。
- 近くに登録済みの場所があれば、その場所を使うか新しく登録するかを選ぶ（地図のタップの近接確認と同じ → [map.md](map.md)・ADR-0009）。
  その場所を使えば、その場所を足す（行きたい・メモはその場所に入る）。地図に見えている登録済みの場所（番号のマーカー・レイヤーで出した場所）は確かめない。
- POI・検索で選んだ施設は施設で同じ場所かを見分け、もう登録してあればその場所を足す。
- **場所の登録はすぐ入る**（計画の「保存」を待たない）。計画を保存せずに破棄しても、登録した場所（と行きたい）は残る。

## 計画と実績

### 結び付いた経路

計画には、実際のお出掛け（経路）が結び付く。**1 つの計画に経路はいくつも結び付くが、1 つの経路が結び付く計画は 1 つだけ**
（計画:経路 ＝ 1:多 → [ADR-0050](../adr/0050-plans-as-ordered-items-with-optional-dates.md)）。結び付きは保存する（`plan_tracks`）。

| 結び付き方       | いつ                                                                                       |
| ---------------- | ------------------------------------------------------------------------------------------ |
| 記録の開始で選ぶ | 記録を始めたとき、今日が日付に入る計画があれば、最初の計画に結び付けて、それでよいかを聞く |
| 手で結び付け     | 詳細の ⋮「経路を結び付ける」で選ぶ（日付なしの計画・記録の開始で選び忘れたとき）           |

- **一度も保存していない計画**（新しい計画の下書き）には結び付けない。記録の開始でも聞かない。
- 結び付け・外しは「保存」を待たずにすぐ入る（実績であって計画の中身ではないので、下書きにも入れない）。
- ほかの計画に結び付いている経路を結び付けると、そちらから**付け替える**。
- どちらの結び付きも ⋮ で外せる。経路を消すと結び付きも消える。計画を消しても経路は残る（取り消すと結び付きも戻る）。
- **保存済みの計画の日付を変えるとき、新しい日付の範囲の外になる結び付いた経路があれば聞く**（「日付と日数」の中）。
  「この日付の外になる経路が N 本あります（11/29 鎌倉さんぽ…）」と出し、「結び付きを外す」「結び付けたまま残す」を選ぶまで「決める」を押せない。
  - 記録の開始で選んだものも、手で結び付けたものも同じに聞く（前の晩に出発した経路などは残したいこともあるため）。
  - 外すのは「保存」のとき（日付の変更と同じ。保存せずに破棄すれば外れない）。「下書きに残す」と、外す選択も下書きに残り、下書きから保存したときに外れる。
  - 日付なしにするときは範囲が無いので聞かない。
  - 新しい範囲の経路を勝手に足すことはしない（同じ日に計画がいくつもありうるため。記録の開始で聞くか、手で結び付ける）。

#### 計画の日付の重なり

記録の開始でどの計画かを選べるよう、計画の日付の重なりを決める。

- **何日かの計画どうしは、日を重ねられない**。ただし、ある計画の最後の日と、別の計画の開始日が同じ日なのはよい（帰った日に次の旅に出る）。
- **日帰りの計画は、どの計画とも重なってよい**（同じ日に日帰りがいくつあってもよく、旅行の途中の日に「嵐山散策」を別に作ってもよい）。
- 日付なしの計画は関係しない。重なりを見る相手は保存済みの計画（下書きは見ない）。
- 「日付と日数」で重なる日付を選ぶと、「11/30〜12/1 は『京都旅行』と重なります」と出して決められない。

#### 記録の開始で聞く

記録を始めると（記録はすぐ始まり、聞くのはその後）、今日が日付に入る保存済みの計画があれば、**最初の計画にもう結び付けたうえで**聞く
（計画が 1 つでも聞く。並びは開始日の早い順）。

```text
┌ 今日の計画に結び付けました ──────┐
│ この記録を計画の実績にします。      │
│ 別の計画にするときは選び直してください │
│ ● 京都旅行 11/29〜12/1・2日目  │ ← 最初の計画を選んだ状態（もう結び付いている）
│ ○ 鎌倉散歩   11/30(日) 日帰り  │
│              [結び付けない] [OK] │
└─────────────────────────────┘
```

- 選び直して「OK」で付け替える。「結び付けない」で外す。外を押して閉じたときは、結び付けたまま。
- 後から詳細の「結び付ける」・⋮ でも変えられる。
- 中断した記録を続けるとき（再開）は聞かない（同じ経路なので）。

#### 経路を結び付ける

詳細の ⋮「経路を結び付ける」（またはシートの「実際のお出掛け」の「結び付ける」）で、詳細の上に全画面で開く。

```text
┌─────────────────────────────┐
│ (←) 経路を結び付ける    [🔍] │ ← 名前で探す
│ ⌄ 11月 ─────────────── 3 │ ← 月ごと・新しい順
│ ☑ 11/30(日) 鎌倉さんぽ       │
│   10:02〜・12.4 km          │
│ ☐ 11/23(月) 8:10〜          │ ← 名前の無い経路は日付と開始の時刻
│   3.1 km・「江ノ島」から付け替えます │ ← ほかの計画に結び付いている
└─────────────────────────────┘
```

- チェックを押すとすぐ結び付く・外れる（ほかの計画に付いていれば付け替える）。← で詳細へ戻る。検索中の戻るは検索を閉じる。

#### 実際のお出掛け（シートの末尾）

```text
│ 実際のお出掛け 2 本      [結び付ける] │
│ ≈ ●記録中 11/30(日) 10:02〜   [⋮] │ ← 記録中は橙の印。距離は今の距離
│   3.2 km・記録の開始で結び付け      │
│ ≈ 11/16(日) 江ノ島            [⋮] │ ← ⋮:「結び付きを外す」
│   9:30〜・8.0 km・手で結び付け      │
```

- 行の後ろに「実際のお出掛け N 本」の節を置き、結び付いた経路を新しい順に並べる。押すと経路詳細へ。
- 無いときは「記録を始めるときに選ぶか、経路を結び付けると出ます」（一度も保存していない計画なら「保存すると経路を結び付けられます」）。

### 行った

- 場所の行は、結び付いた経路のどれかに**その場所への立ち寄り**があれば「行った」になる。何日目の予定だったかは問わない。
- 行の名前の右に緑の ✓、地図のマーカーは緑（番号はそのまま）。要約の右と一覧の行に「行った N/M」（結び付いた経路があるときだけ）。
- メモの行は「行った」を持たない。
- 行きたいの旗とは関係しない（行きたいが立ち寄りで終わるのは、今までどおり → [places.md](places.md)）。

### 重ねて見る

- 詳細のレイヤー［≋］の「結び付いた経路（N本）」のスイッチで、結び付いた経路を地図に重ねる（この画面の間だけ。初めは重ねない）。
  計画の日の色（8 色）と混ざらないよう、**灰青の一色の線**にし、計画の直線・マーカーより奥に描く。立ち寄りの番号は出さない
  （行ったかは計画のマーカーの緑で分かる）。本数の上限は付けない。
- **記録中**: 記録中の経路が結び付いた計画の詳細を開くと、
  記録中の経路（記録画面の軌跡と同じ橙。少し太く）と現在地（地図の青い点）を、レイヤーのスイッチに関わらず重ねる。
  立ち寄りが記録されると、その場で「行った」が付く。一覧の行には「記録中」の印を出す。

## 記録画面に重ねる（#274）

- 記録画面の地図に、計画を詳細と同じ見た目（番号付きのマーカーと日ごとの直線）で重ねる。
- **今日が日付に入る計画は、今日の分を自動で重ねる**（いくつあってもすべて）。
- ほかの計画（日付なしも）は、レイヤー［≋］の「計画を重ねる」から選んで重ねる・外す。
- 計画のマーカーをタップすると、名前と予定時刻を吹き出しで出す。吹き出しから計画の詳細へ移れる。
- 重ねた計画は**保存しない**（アプリを使っている間だけ保つ）。自動で重なった計画を外したら、その日のうちは自動で戻さない。
