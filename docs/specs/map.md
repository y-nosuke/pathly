# 地図タップの仕様

地図はどの画面でも「場所を見つける面」として扱う。**どこをタップしたら何が起きるか**を一枚にまとめる。
画面 × モード × 「登録済みの場所」表示の ON/OFF で意味が変わるので、迷ったらこの表を見る。

> 用語は [glossary.md](glossary.md)。立ち寄りの扱いは [stops.md](stops.md)、場所は [places.md](places.md)。

---

## 前提

地図を持つ画面は 4 つ。

| 画面                                       | 状態                                               |
| ------------------------------------------ | -------------------------------------------------- |
| **記録画面**                               | 平常時（記録なし）／記録中                         |
| **経路詳細**                               | 記録中／記録済み。通常モード／立ち寄りの追加モード |
| **場所詳細**                               | 1 つの場所の閲覧・編集                             |
| **場所の追加**（地図で選ぶ・検索して追加） | 登録する地点を地図で確かめる                       |

「**登録済みの場所を表示**」はトグルで切り替える。ON/OFF は画面ごとに独立して覚える。
表示 ON のときは、出す場所を**絞り込める**（→「登録済みの場所の絞り込み」）。

## 基本の考え方

- **表示 ON のとき**は近くの場所が**見えている**。そこで登録するのは意図的とみなし、確認を出さず
  **そのまま新規**にする。ただし**絞り込みで隠れている場所**は見えていないので、それが近くにあれば
  表示 OFF のときと同じく近接確認を出す（同じ場所を重複して登録しないため）。
- **表示 OFF のとき**は近くに場所があることに**気づけない**。だから登録の確定時に**近接確認**を出し、
  既存があれば「紐付け／新規」を選ばせる。
- **施設（POI）をタップしたとき**は施設の同一性で同定できるので、近接確認は出さない。
- 近接確認の半径は**立ち寄りの検出半径と同じ**（→ [stops.md](stops.md)）。
- 登録済みのマーカーは画像の矩形でタップを拾うので、**すぐ近く**をタップしてもマーカーの編集が開く
  （→ [designs/ui.md](../designs/ui.md)）。登録済みの場所のすぐ隣に別の場所を登録したいときは、
  **表示を OFF にしてタップ**し、近接確認で「新規」を選ぶ。

## 登録済みの場所の絞り込み

表示 ON のとき、「登録済みの場所を表示」のボタンの隣（記録画面・場所詳細は下、経路詳細は右）に
**絞り込みボタン**が出る。押すと小さなパネルが開き、場所一覧と同じ 3 つのチップで絞り込める。

- 軸は**行きたい**（指定なし / 行きたい / 行きたい以外）・**訪問**（指定なし / 訪問済み / 未訪問）・
  **業種**（複数選べて OR・件数つき）。すべて AND。「すべて外す」でまとめて解除する。
  業種の分け方と件数の出し方は場所一覧と同じ（→ [places.md](places.md) の「一覧と詳細」）。
- **条件は地図ごとに独立して持つ**（記録画面・経路詳細・場所詳細で別々。表示の ON/OFF と同じ）。
  ある地図で絞っても、ほかの地図には効かない。
- **場所一覧の絞り込みとは別に持つ**（連動しない）。一覧は特定の場所を探すための一時的な絞り込み、
  地図はしばらく続けて使う見方なので。共有すると、一覧で絞ったあと地図を開いたときに、
  知らないうちに場所が消えて見えるため。
- **アプリを閉じても残す**（表示の ON/OFF と同じ）。残るぶん、絞り込み中は**ボタンを塗りつぶして**示す。
- まとまり・名前のラベルは、絞り込んだ後の場所で作る。
- 絞り込むのは登録済みの場所のマーカーだけ。場所詳細の主マーカー・立ち寄りのマーカーは今まで通り出す。
  これらで見えている場所は、絞り込みの条件に合わなくても**見えている**とみなし、近接確認の対象にしない。
- 表示 OFF のときはボタンを出さない（条件は覚えたまま、次に ON にしたときに効く）。

## 登録済みの場所のまとまり

登録済みの場所のマーカーは、**画面上で近いものどうしを 1 つの丸（まとまり）にまとめる**。
引いた地図でマーカーが重なって読めなくなるのを防ぐため。表示 ON のときの、記録画面・経路詳細・場所詳細で共通。

- **まとめるのは登録済みの場所のマーカーだけ。** 出発・到着・現在地・立ち寄り・場所詳細の主マーカー・
  地点を選ぶピンはまとめない。
- まとまりは**件数入りの濃い色の丸**。中に「行きたい」が 1 件でもあれば、1 件ずつのマーカーと同じ旗を右上に付ける。
- 画面上で約 44dp より近い場所どうしをまとめる。寄ると離れて 1 件ずつに戻る。
  **建物の単位（ズーム 18）まで寄ったらまとめない**（同じ座標の場所はどこまで寄っても離れないため）。
- **まとまりをタップすると、中の場所が全部入るまで地図が寄る。** 吹き出しもシートも出さない。
  通常モード・立ち寄りの追加モードのどちらでも同じ（まとまりのままでは 1 件を選べないため）。
  ただし、まとめなくなるズームでも離れないほど近いまとまり（同じ座標など）は、そのズームで止める
  （全部入るまで寄せると地図の最大ズームまで飛ぶため）。

## 登録済みの場所の名前のラベル

1 件ずつの登録済みの場所のマーカーには、**丸バッジの下に場所の名前を添える**。どれがどの場所か、
1 つずつタップしなくても分かるようにするため。表示 ON のときの、記録画面・経路詳細・場所詳細で共通。

- **ズームに依らずいつも出す。** 近すぎる場所はまとまりになるので、混み合いはまとまりで抑える。
  まとまりの丸には名前を出さない。
- 名前は場所一覧と同じ表示名（自分で付けた名前 → 施設名 → 住所 → 座標の順）。**1 行で、幅 120dp（全角 8 文字ほど）を超えたら「…」で省く。**
  ラベルの分だけマーカーの画像が広がり、そのまわりのタップもマーカーに取られるので、広げすぎない。
- 隣り合う 1 件どうしのラベルは、少し重なることがある（まとめる距離 44dp よりラベルが広いため）。
  重なりを避けて間引くことはしない。
- **マーカーが指す位置は変えない。** ラベルを足しても、丸バッジの下端が場所の座標に来る。
- 場所詳細の主マーカーにはラベルを付けない。吹き出しで名前を出し続けているため。
- 出発・到着・候補などのマーカーには付けない。立ち寄りのマーカーは次の節。

## 立ち寄りの名前のラベル

経路の地図（記録画面・経路詳細）の立ち寄りのマーカーにも、**バッジの下に場所の名前を添える**。
番号だけでは、どこに立ち寄ったかがタップしないと分からないため。見た目・省き方・指す位置は
登録済みの場所のラベルと同じ。

- **確定した立ち寄り（紫の番号）**: 場所一覧と同じ表示名（自分で付けた名前 → 施設名 → 住所 → 座標）を出す。
- **立ち寄り中（ティール。上に「滞在◯分」）**: 名前が分かるとき（自分で付けた名前・施設名・住所のどれか）だけ出す。
  滞在中はまだ名前を引けていないことが多く、座標だけを出しても読めないため（座標は吹き出しに出す）。
- 立ち寄った場所の登録済みのマーカーは、表示 ON でもこの 2 画面には出さないので、名前が二重には並ばない。

## 経路の地図（記録画面・経路詳細で共通）

### 通常モード

| タップ対象         | 表示 ON                        | 表示 OFF                |
| ------------------ | ------------------------------ | ----------------------- |
| 施設（POI）        | 場所を登録                     | 場所を登録              |
| 何もない地点       | 場所を登録（そのまま新規）※    | 近接確認 → 紐付け／新規 |
| 登録済みのマーカー | 編集（一覧から開く詳細と同じ） | （出ていない）          |
| まとまり           | 中の場所が全部入るまで寄る     | （出ていない）          |
| 立ち寄りのピン     | 選び直し ＋ 一覧で強調         | 選び直し ＋ 一覧で強調  |

### 立ち寄りの追加モード

| タップ対象         | 表示 ON                         | 表示 OFF                                  |
| ------------------ | ------------------------------- | ----------------------------------------- |
| 施設（POI）        | 立ち寄りを追加（施設名が入る）  | 立ち寄りを追加（施設名が入る）            |
| 何もない地点       | 立ち寄りを追加（そのまま新規）※ | 立ち寄りを追加（近接確認 → 紐付け／新規） |
| 登録済みのマーカー | その場所へこの立ち寄りを紐付け  | （出ていない）                            |
| まとまり           | 中の場所が全部入るまで寄る      | （出ていない）                            |
| 立ち寄りのピン     | 選び直し ＋ 一覧で強調          | 選び直し ＋ 一覧で強調                    |

- ※ 絞り込みで隠れた場所が近くにあれば、表示 OFF と同じく近接確認を出す（→「基本の考え方」）。
- **記録中でも追加モードを使える。**
- 記録画面の平常時（記録なし）は追加モードを持たない（立ち寄りを足す経路が無いため）。

## 場所詳細の地図

| タップ対象                     | 表示 ON                        | 表示 OFF                |
| ------------------------------ | ------------------------------ | ----------------------- |
| 施設（POI）                    | 別の場所として登録             | 別の場所として登録      |
| 何もない地点                   | 場所を登録（そのまま新規）※    | 近接確認 → 紐付け／新規 |
| 登録済みのマーカー（自分以外） | 編集（一覧から開く詳細と同じ） | （出ていない）          |
| まとまり                       | 中の場所が全部入るまで寄る     | （出ていない）          |
| 立ち寄りのピン                 | （出ていない）                 | （出ていない）          |

※ 絞り込みで隠れた場所が近くにあれば、表示 OFF と同じく近接確認を出す。

## 場所の追加の地図

トグルを持たないので、表示 OFF と同じ扱い。

| タップ対象   | 動作                                                          |
| ------------ | ------------------------------------------------------------- |
| 施設（POI）  | その施設として選ぶ（名前・カテゴリ・住所が付く）              |
| 何もない地点 | その座標だけを選ぶ                                            |
| 現在地ボタン | 現在地へ地図を寄せる                                          |
| 登録の確定時 | 施設なら同一性で同定。座標だけなら**近接確認** → 紐付け／新規 |

## タップしたあとに出るもの

対象が何であれ、**下部にシートが出る**。

| 対象           | 中身                                 | できること                                                                    |
| -------------- | ------------------------------------ | ----------------------------------------------------------------------------- |
| 何もない地点   | 名前（任意）・メモ・行きたい・優先度 | 登録                                                                          |
| 未登録の施設   | ＋カテゴリ／住所・地図で開く         | 登録                                                                          |
| 登録済みの場所 | **場所詳細とまったく同じ編集画面**   | 保存・Google 施設の紐付け・訪問履歴を見る・削除・立ち寄りに追加（記録中のみ） |

- **登録済みの場所で開くものは、場所一覧から開く詳細と同一**。入口（地図のマーカー／一覧の行）が
  違うだけで、中身とできることは変わらない。入口ごとに機能が違うと、どちらから開いたかを
  覚えていないと何ができるか分からなくなるため。実体も1つ（`presentation/places/PlaceEditorBody`）。

- シートは**背後が暗くならない**ので、出したまま地図を動かせる。下スワイプで畳めば全画面の地図を
  確かめられ、「▲ 入力に戻る」で戻せる。
- **タップした地点がシートに隠れない**よう、地図はシートの高さぶん寄る。
- 立ち寄りの追加モードだけは別のシート（滞在区間を調整するため）。場所の登録には滞在時間が要らないので、
  同じシートにはしない。

## 補足

- **登録済みマーカーのタップはモードで意味が変わる。**通常モード＝編集（場所一覧から開く詳細と同じもの）、追加モード＝この立ち寄りを紐付け。
- **近接確認で「新規」を選んだとき**は、座標での同定をせず必ず新しい場所を作る（気づかないまま
  他の場所に混ざるのを防ぐため）。「紐付け」は既存の場所を使う。
