# UI の方向性（構成・画面の型）

画面を組み立てるときの「どこに何を置くか」の決まり（画面の型）と、その元になった棚卸し・段分けを書く。
**今の画面で何が起きるかは [../specs/screens.md](../specs/screens.md) を正とする。** この文書は画面を組み直すときに
合わせる先で、画面ごとの見直しの Issue で 1 画面ずつこの型へ移す（移したら screens.md も今の姿に直す）。
決めた理由と採らなかった案は [ADR-0038](../adr/0038-screen-layouts-four-corners-and-tool-row.md)・[ADR-0039](../adr/0039-one-search-box-for-places-and-regions.md)・[ADR-0042](../adr/0042-primary-action-moves-with-sheet.md)・[ADR-0044](../adr/0044-record-start-stop-inside-sheet.md)。

UI を 4 つの層に分けて考える。窮屈さは主に上の 2 層から来ているので、先にそこを決めた。

| 層       | 決めること                                 | どこで決めるか                                                                                                                                                    |
| -------- | ------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 構成     | タブの分け方・機能をどの画面に置くか       | この文書                                                                                                                                                          |
| 画面の型 | 地図の画面・一覧の画面の区画（何をどこへ） | この文書                                                                                                                                                          |
| 部品     | ボタン・シート・チップ・行の形             | `presentation/common/`（→ [ui.md](ui.md)）。Material 3 Expressive を使う（→ [ADR-0041](../adr/0041-adopt-material3-expressive-after-stable.md)）                  |
| トークン | 色・文字・余白・角丸・影                   | `PathlyAndroidTheme`（正）と [Design System](https://claude.ai/artifact/T9PLHBYVuDhiRz7wtqHYRd)（→ [ADR-0040](../adr/0040-design-tokens-indigo-fixed-colors.md)） |

一度で決めきらず、繰り返し見直す。見直すときは、棚卸し（下）を撮り直して段分けを直し、型の案を
claude.ai の Design（[Pathly 画面の型の案](https://claude.ai/artifact/XJEhZtb6wWkKgY6uHKoEum)）に描いて比べ、
この文書と ADR を更新する。

## 段分けの決まり

画面の操作を 3 段に分け、段ごとに置き場所を決める。

| 段     | 意味                                                       | 数             | 置き場所                                                  |
| ------ | ---------------------------------------------------------- | -------------- | --------------------------------------------------------- |
| 主役   | いちばんよくやること。いつも見えているか、1 タップで戻せる | 画面に 1〜2 個 | 型が決めた 1 か所（地図はシートの中、一覧は行と右下の丸） |
| 脇役   | 見えているが控えめ                                         | 必要なだけ     | 型が決めた区画（上・右下・シートの先頭）                  |
| しまう | たまにしか使わない・消す・開発用                           | 制限なし       | メニュー（⋮・レイヤー・表示）やシート・詳細画面の中       |

- **削除はしまう**（一覧の行に出さない）。行に出すのは、その場で切り替えるもの（行きたい・お気に入り）だけ。
- **条件付きで出る「やること」**（場所を取得・同じ施設の確認待ち）は、出ているときだけ脇役として目立たせる。
- **ずっと出しておく案内は 1 行の帯にする**（地図や一覧の上を大きく占めない）。押すと詳しい画面へ。

## 地図の画面の型（四隅で役割を固定）

記録・経路詳細・場所詳細・履歴の地図・場所の地図・場所の追加（地図で選ぶ）を、すべてこの型に載せる。
どの地図の画面でも、同じ種類のものは同じ場所に来る。

```text
┌─────────────────────────────┐
│ (←) 見出し／検索窓     [≋][⋮] │ ← 上: 戻る＋見出し（タブの画面は検索窓）。右端にレイヤー[≋]・その他[⋮]
│ (状態のピル・チップ)          │ ← 上の下: 記録中のピル・地域の目印のチップなど「今の状態」
│ [1 行の案内の帯]           ›  │ ← 出ているときだけ（電池の最適化など）
│                             │
│         地図                 │
│                        (◎) │ ← 右下: 地図の操作（現在地・全体を見る）
│            (主役)            │ ← 下中央: 主役（記録の開始・停止）
│ ┌─────────────────────────┐ │
│ │ シート（情報・一覧・脇役の操作）│ │ ← 下: 非モーダルのシート（→ ui.md）
└─────────────────────────────┘
```

| 区画         | 置くもの                                                                                                                                                                                                                              |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 上           | 戻る（詳細）・見出し（詳細）または検索窓（タブの画面）・レイヤー・⋮                                                                                                                                                                   |
| 上の下       | 今の状態（記録中のピル・地域の目印のチップ）。1 行の案内の帯                                                                                                                                                                          |
| 右下         | 地図の操作（現在地・全体を見る）。シートの上端に沿って上下する                                                                                                                                                                        |
| 下中央       | 置かない。地図の画面の主役はシートの中（記録画面の開始・停止も記録のシートの中 → [ADR-0044](../adr/0044-record-start-stop-inside-sheet.md)。畳めば戻すボタンだけが残る → [ADR-0042](../adr/0042-primary-action-moves-with-sheet.md)） |
| 下           | シート: 主役（記録の開始・停止・立ち寄りの行）・情報（距離・立ち寄り中など）・一覧（立ち寄り・経路・この範囲の経路）・脇役の操作                                                                                                      |
| レイヤーの中 | 地図に重ねるもの: 登録済みの場所の表示・絞り込み、この範囲の経路（記録画面）                                                                                                                                                          |
| ⋮ の中       | その画面の対象への操作: 名前を編集・お気に入り・再解析、開発版の補正の調整・GPS 詳細、場所の Google 施設を選び直す・まとめる・削除                                                                                                    |

- **主役はシートと一緒に動く。** シートを下へ払うと主役も隠れ、戻すボタンが残る。シートはつまみの行のタップ（ハーフ⇔フル）と▼（畳む）でも開け閉めする。
- 区画ごとの部品は `presentation/common/` にある（上のバー `MapTopBar`・戻る＋見出し `MapBackTitle`・⋮ `MapOverflowMenuButton`・レイヤー `MapLayersButton`・右下 `MapControls`・1 行の帯 `MapNoticeBanner`・シートの脇役の操作 `MapSideActions` → [ui.md](ui.md)）。
- **地図の操作は全部の地図の画面にそろえる**（今は現在地が記録にしか無い、登録済みの場所が履歴の地図に無い）。
- 一覧のタブの地図表示（履歴・場所）は、上の区画に一覧の型の見出しとツール行を重ねる（今のたためる見出しのまま）。
- 検索窓は施設と地域を 1 つにまとめる（→ [ADR-0039](../adr/0039-one-search-box-for-places-and-regions.md)）。

## 一覧の画面の型（見出し＋ツール行）

履歴・場所の一覧をこの型に載せる。

```text
┌─────────────────────────────┐
│ 見出し                [🔍][🗺] │ ← 見出し: 名前・検索（押すと見出しの位置に窓）・地図への切り替え
│ [絞り込み 2]   [登録順 ↓・分ける ▾]│ ← ツール行: 絞り込み（左）・表示のメニュー（右）
│ (初期状態に戻す)(行きたい ×)   │ ← 効いている条件のチップ（あるときだけ）
│ [42/176][30][2/7]        ▾ │ ← 統計の帯（小さなタイル。押すとその場で統計のカードに広がる）
│ 行 …                   [🚩] │ ← 行: タップで詳細（主役）。右はその場で切り替えるものだけ
│ 行 …                   [🚩] │
│                        (＋) │ ← 右下: 追加（主役。追加の無い一覧では置かない）
└─────────────────────────────┘
```

| 区画         | 置くもの                                                                                                                        |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------- |
| 見出し       | 画面の名前・検索（アイコン。押すと窓が開く）・一覧／地図の切り替え                                                              |
| ツール行     | 絞り込み（左。欄を開く → [ADR-0031](../adr/0031-list-filters-in-a-panel.md)）・表示のメニュー（右。並べ替えの軸・向き・分け方） |
| 条件のチップ | 効いている条件・初期状態に戻す（今のまま）                                                                                      |
| 統計の帯     | 数字の小さなタイルを並べた要約。押すとその場で統計のカード（数字のタイル・絵 1 つ・読み物 1 つ）に広がる                        |
| 行           | タップで詳細。右に行きたい・お気に入りなど、その場で切り替えるもの                                                              |
| 右下         | 追加（主役）。先頭へ戻るはその上                                                                                                |
| しまう       | 行の ⋮（名前を付ける）・削除（詳細の中）                                                                                        |

## 構成

- **タブは 5 つにする**（記録・履歴・場所・**計画**・設定）。計画のタブを足し、場所タブは残す（→ [ADR-0051](../adr/0051-plan-tab-and-overlay-on-maps.md)）。
  計画の一覧は一覧の型、計画の詳細は地図の型に載せる（→ [../specs/plans.md](../specs/plans.md)）。
- **「この範囲の経路」は記録画面のレイヤーの中に残す**。履歴の地図とは入口が違う（記録画面は「今いるあたりで前に通った道」、
  履歴の地図は「絞り込んだ経路を見比べる」）ので、両方を残す。
- **「検索して登録」と「地域へ移動」は 1 つの検索窓にまとめる**（→ [ADR-0039](../adr/0039-one-search-box-for-places-and-regions.md)）。
- 経路の削除だけ確認ダイアログ、ほかは取り消し、のような流儀の違いは、画面ごとの見直しのときにそろえる
  （経路の削除は、経路詳細の ⋮ から取り消しのスナックバーで。確認ダイアログは使わない）。
- **スナックバーはどの画面でも横にスワイプして消す**（左右どちらへでも。× のボタンは置かない）。取り消しのように押すまで残るものも
  同じ消し方で片付けられる。実体は `presentation/common/SwipeDismissSnackbarHost`（画面は `SnackbarHost` の代わりにこれを置く）。

## 棚卸し（2026-11-16・v0.9.0）

エミュレータに実データの写し（経路 38・場所 176）を入れて撮った。各画面の「何のためか」「いちばんよくやること」と、
ボタン・操作をすべて書き出し、段分けの叩き台を添える。

- **段**: 主役＝いつも見えていて押しやすい（画面に 1〜2 個）／脇役＝見えているが控えめ／しまう＝メニューやシートの中
- 「今」は今の置き場所。「案」は段分け（2026-11-16 に叩き台どおりで合意。画面の型を描きながら直してよい）。

### 記録（地図）

- **何のため**: お出掛けをその場で記録する。地図で場所を見つけて登録する。
- **いちばんよくやること**: 記録の開始・停止。記録中に現在地と距離を見る。

| 操作・表示                     | 今                                 | 案     | メモ                                                    |
| ------------------------------ | ---------------------------------- | ------ | ------------------------------------------------------- |
| 記録の開始・停止               | 下中央の大きな丸（停止は確認あり） | 主役   |                                                         |
| 今ここを立ち寄り（記録中）     | 左上のピル                         | 脇役   | 主役は停止だけにする（決定）                            |
| 立ち寄りを追加（地図で指す）   | 左上のピル（切り替え）             | 脇役   |                                                         |
| 現在地へ戻す・追従             | 右上（右の縦列の 1 番目）          | 脇役   | 地図の操作                                              |
| 登録済みの場所の表示           | 右の縦列 2                         | 脇役   | 「表示するもの」にまとめる候補                          |
| 登録済みの場所の絞り込み       | 右の縦列 3（チップのパネル）       | しまう | 表示の中へ                                              |
| この範囲の経路                 | 右の縦列 4（下から一覧のシート）   | しまう | レイヤーの中に残す（決定）                              |
| 検索して登録                   | 右の縦列 5（上に検索窓）           | 脇役   | 地域へ移動と 1 つの検索窓にまとめる（決定）             |
| 地域へ移動                     | 右の縦列 6（上に検索窓）           | 脇役   | 同上                                                    |
| 地域の目印のチップ             | 左上                               | 表示   |                                                         |
| 記録中のピル（経過時間）       | 上中央                             | 表示   |                                                         |
| 距離・地点数のカード（記録中） | 下（丸の上）                       | 表示   |                                                         |
| 立ち寄り中のカード             | 下                                 | 表示   |                                                         |

| 登録済みのマーカーのタップ     | 場所の編集シート                   | —      |                                                         |

### 場所（地図）

- **何のため**: 登録した場所の散らばりを見る。
- **いちばんよくやること**: 地図を動かしてマーカーを開く。

| 操作・表示                         | 今               | 案   | メモ |
| ---------------------------------- | ---------------- | ---- | ---- |
| マーカーのタップ → 場所詳細        | 地図             | 主役 |      |
| 一覧／地図の切り替え・追加・たたむ | 重ねた見出しの右 | 脇役 |      |
| 名前の検索・絞り込み               | 重ねた見出しの下 | 脇役 |      |
| （無い）現在地                     | —                | —    |      |

### 場所詳細

- **何のため**: 1 つの場所を見て、名前・行きたい・メモを直す。
- **いちばんよくやること**: 行きたい・優先度・メモを直して保存。この場所に行ったお出掛けを開く。

| 操作・表示                                  | 今                           | 案     | メモ                       |
| ------------------------------------------- | ---------------------------- | ------ | -------------------------- |
| 戻る                                        | 左上の丸                     | 脇役   |                            |
| 登録済みの場所の表示・絞り込み              | 右の縦列                     | 脇役   | 経路詳細では上の横列       |
| 自分で付ける名前                            | 見出しを押してダイアログ     | 脇役   | 経路の名前と同じ           |
| Google マップで開く                         | シート（枠つきの全幅ボタン） | 脇役   |                            |
| メモ・行きたい・優先度・訪問済み            | シート                       | 主役   |                            |
| 保存                                        | シートの中ほど               | 主役   | スクロールしないと見えない |
| Google 施設を選び直す・ほかの場所とまとめる | シート                       | しまう |                            |
| この場所を削除                              | シートの下                   | しまう |                            |
| この場所を含むお出掛け                      | シートの下                   | 脇役   |                            |

### 設定

- **何のため**: 記録の設定・データの持ち出し・不具合の記録を見る。
- **いちばんよくやること**: めったに開かない（書き出しくらい）。

GPS 記録間隔・位置の取り方（ラジオ）、書き出す・読み込む・読み込む前の状態に戻す、版、異常終了の記録。
縦に並んだ設定画面として足りている（窮屈さの元ではない）。

### 棚卸しで見えたこと

1. **地図の操作の置き場所が画面ごとに違う**: 記録＝右の縦列（6 個）、経路詳細＝上の横列（4〜6 個）、場所詳細＝左上と右の縦列、
   履歴・場所の地図＝重ねた見出しの中。同じ「登録済みの場所の表示」が画面ごとに別の位置にある。
2. **地図の操作が画面ごとに欠けている**: 現在地は記録にしかない。登録済みの場所は履歴の地図に無い。
3. **常に場所を取るものが多い**: 一覧の検索欄（常に全幅）・統計カード（最初の画面の 1/4）・記録画面の電池の案内（地図の 1/4）・
   地図の上の重ねた見出し（地図の 1/4）。
4. **同じ重さで並んでいる**: 記録の右の縦列 6 個、経路詳細の操作チップ 3 個、一覧の並べ替え 2〜3 個がどれも同じ見た目。
5. **似た機能の入口が分かれている**: 「検索して登録」と「地域へ移動」、記録の「この範囲の経路」と履歴の地図。
6. **流儀が揃っていない**: 経路の削除だけ確認ダイアログ（ほかは取り消し）、追加が場所一覧では塗りの大きなボタンで記録画面ではアイコン、
   お気に入りは履歴の一覧にあって経路詳細に無い。
