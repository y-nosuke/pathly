# 0051. 計画のタブを足して 5 つにし、計画は番号と直線で地図に描き、記録画面と計画の詳細で記録中の経路と重ねて見る

- Status: Accepted
- Date: 2026-11-27

関連: データの持ち方は [0050](0050-plans-as-ordered-items-with-optional-dates.md)。
画面の型は [0038](0038-screen-layouts-four-corners-and-tool-row.md)（その「タブは 4 つのまま」をこの決定で変える）。
並べ替えの動きは [0047](0047-reorder-region-chips-by-drag.md)、保存しない目印は [0043](0043-multiple-region-markers-kept-in-memory.md)。
仕様は [specs/plans.md](../specs/plans.md)。検討は #270。

## Context（背景）

計画（0050）を置く画面が要る。ボトムナビは 記録・履歴・場所・設定 の 4 つで、0038 では「タブは 4 つのまま」とした。
場所タブは「計画タブの前身」として作ってきたが、場所タブは場所を眺める・探す・行きたいを管理する画面として育っている。

あわせて決めること:

- 計画の場所どうしを地図でどう結ぶか（道に沿った経路は有料の API が要る）。
- 計画の行の並べ替え（シートの一覧なので、縦に指を動かすとスクロールとぶつかる）。
- 出先で、計画と今の記録をどう見比べるか（計画の詳細と記録画面の両方で見たい）。

## Decision（決定）

- **計画のタブを足し、ボトムナビを 5 つにする**（記録・履歴・場所・**計画**・設定）。場所タブはそのまま残す。
  - 計画の一覧は一覧の型、計画の詳細は地図の型（0038）に載せる。
- **計画の場所は、日ごとの番号付きマーカーにし、同じ日の中を順に直線で結ぶ。** 道に沿った経路と所要時間は後で（#275）。
  メモの行は地図に出さない。番号は日ごとに 1 から振り、メモの行は数えない。
- **行の並べ替えは、行の左端の取っ手（⋮⋮）に触れて動かすと長押しなしで掴む。** 行のほかの所を縦に動かせばスクロール。
  掴んだ後の動き（震えて浮き、ほかの行がよけ、離した所で決まる）は地名のチップ（0047）に揃える。日をまたいで動かせる。
- **計画の詳細では、記録中の経路が結び付く計画なら、記録中の経路と現在地を自動で重ねる**（「行った」もその場で付く）。
  計画の一覧では、その計画の行に「記録中」の印を出す。結び付いた過去の経路は、レイヤー［≋］から重ねる。
- **記録画面の地図にも計画を重ねる。** 今日が日付に入る計画は、今日の分を自動で重ねる。ほかの計画（日付なしも）は
  レイヤー［≋］の「計画を重ねる」から選ぶ。重ねた計画は**保存しない**（アプリを使っている間だけ。0043 と同じ）。
  自動で重なった計画を外したら、その日のうちは自動で戻さない。

## Alternatives（検討した没案）

- **場所タブの中に「場所｜計画」の切り替えを置く** … タブは増えないが、場所タブの見出し・絞り込み・地図が計画と場所で別物になり、
  場所タブが重くなる → **却下**。
- **場所タブを計画タブに作り替える**（前身の構想どおり）… 場所を眺める・行きたいを管理する使い方が今も多く、変更が大きい → **却下**。
- **最初から Routes API で道に沿って結ぶ** … 現実の所要時間が分かるが、有料で、使う前に予算のアラート（#257）が要る → **後回し**（#275）。
- **線を引かずマーカーだけ** … 回る順が地図で分からない → **却下**。
- **行の長押しで掴む** … 地名のチップで一度作り、掴むまでの待ちが使いにくかった（0047）→ **却下**。
- **行のどこでも縦に動かせば掴む**（地名のチップと同じ）… チップと違い、シートの一覧はスクロールするのでぶつかる → **却下**。
- **並べ替えのモードに入る** … 紛れないが、1 つ動かすたびにモードを出入りする → **却下**。
- **記録画面に重ねる計画をいつも手で選ぶ** … 計画の日に毎回選ぶ手間がかかる → **却下**（今日の計画は自動）。
- **計画の詳細から「この計画で記録を始める」** … 記録の始め方が 2 つになり、記録画面から始めた記録は計画に重ならない → **却下**。
- **重ねた計画を保存して、アプリを開き直しても残す** … 終わった計画が残り続ける。今日の計画は自動で出るので、保存しなくても困らない → **却下**。

## Consequences（結果・トレードオフ）

- ボトムナビが 5 つになり、1 つの幅が狭くなる（ラベルは 2 文字なので収まる）。
- 計画は直線なので、実際の道のりや所要時間とはずれる。#275 で補う。
- 記録画面の地図に重なるものが増える（登録済みの場所・地域の目印・この範囲の経路・計画）。計画のマーカーは番号で見分ける。
- 0038 の「タブは 4 つのまま」と、screens.md の「計画タブの前身」という位置づけは、この決定で変わる（場所タブはそのまま）。
