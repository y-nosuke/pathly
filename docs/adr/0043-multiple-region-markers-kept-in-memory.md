# 0043. 地域の目印は 5 つまで並べて行き来でき、保存はせずアプリが動いている間だけ残す

- Status: Accepted
- Date: 2026-11-19

関連: 「地域へ移動」と目印は [0032](0032-jump-to-region-by-places-autocomplete.md)、置き場所（上の下）は
[0038](0038-screen-layouts-four-corners-and-tool-row.md)、Places の内容を保存しない考え方は [0029](0029-place-region-by-geocoder.md)。
仕様は specs/map.md の「地域へ移動」。

## Context（背景）

「地域へ移動」の目印は 1 つだけで、別の地域を選ぶと置き換わり、記録画面を離れると消えていた。旅行の計画などで、
いくつかの地域を行き来しながら地図を見たい（例: 福岡市と北九州市を見比べる。#203）。

決めることは、いくつまで置けるか・上限を超えたときの動き・いつまで残すか（保存するか）・目印のタップの意味。

## Decision（決定）

- **目印とチップは 5 つまで並べる。** チップは選んだ順に上の下に並べ、収まらなければ横にスクロールする。
  最後に地図を移した地域のチップは塗りつぶす。チップの地名・目印のタップでその地域へ寄せ直す。
- **上限で新しい地域を選んだら、出せない旨を検索窓に出して止める**（古い目印を勝手に外さない）。範囲の取得（Place Details）の前に止めるので、
  出せない地域で料金はかからない。もう出している地域を選び直したときは数を増やさず、覚えている範囲へ移す（取得もしない）。
- 外すのはチップの ×（1 つずつ）と「すべて外す」（2 つ以上のとき）。現在地ボタン・目印のタップでは消さない。
- **保存しない（DB にも SharedPreferences にも置かない）。** 記録画面の ViewModel に持ち、タブの行き来・画面の回転では残り、
  アプリが終わると消える。

## Alternatives（検討した没案）

- **上限を超えたらいちばん古い目印を外して足す** … 操作は止まらないが、知らないうちに見比べていた地域が消える → **却下**。
- **SharedPreferences か DB に保存して、アプリを閉じても残す** … 計画を何日かに分けて続けられるが、目印は地名（候補の文字）と
  範囲（viewport）で、どちらも Places の内容。規約で保存してよいと明記されているのは place ID と緯度・経度（30 日まで）だけで
  （[0029](0029-place-region-by-geocoder.md)）、合わない → **却下**。
- **place ID だけ保存し、開くたびに範囲を引き直す** … 規約には合うが、目印ごとに開くたび Place Details の料金がかかる → **却下**。
- **目印のタップで消す（今まで）** … 複数あると見比べている途中で誤って消しやすい。外すのはチップに寄せる → **却下**。

## Consequences（結果・トレードオフ）

- いくつかの地域をチップで行き来できる。記録画面を離れて戻っても残る。
- アプリが終わる（裏で OS に終了させられるのも含む）と消えるので、日をまたいだ計画には向かない。
  保存して残す形が要るなら、規約と費用を見直して別の決定にする。
- 上の下の行が混むので、記録中のピルと地域のチップが横にスクロールすることがある。
