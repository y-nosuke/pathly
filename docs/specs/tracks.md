# 経路（お出掛け）の仕様

1 回の記録＝**経路**を、名前で呼び、お気に入りで拾い、絞り込み・並べ替えて探せるようにする。

> 対応する要望: [../requirements.md](../requirements.md)（経路に名前を付けたい／お気に入り登録したい／
> 一覧を場所と同じように絞り込み・並べ替えしたい／立ち寄った件数を表示したい）。

---

## 経路が持つもの

| 項目                     | 説明                                                                                                 |
| ------------------------ | ---------------------------------------------------------------------------------------------------- |
| **名前**                 | 自分で付ける。付けなければ**未命名**で、一覧では日付が見出しになる                                   |
| **お気に入り**           | ON/OFF。一覧から片手で切り替えられる                                                                 |
| **立ち寄り件数**         | その経路で立ち寄った件数。**保存しておらず常に数え直す**ので、立ち寄りを足し引きすれば自動で追従する |
| 開始・終了時刻／移動距離 | 記録から決まる。移動距離は補正後の軌跡で測る                                                         |

名前は前後の空白を除いて扱う。空にして保存すると**未命名に戻る**。

## 一覧に出るもの

**完了した経路だけ**が一覧に並ぶ。記録中の経路は一覧に混ぜず、先頭に別枠で出す。

各カードに出るのは、見出し（名前が無ければ日付）・開始と終了の時刻・移動距離・立ち寄り件数。
名前を付けている場合は日付を副題に添える。右端にお気に入りのハートと、メニュー（名前を付ける／削除）。

## 絞り込み

**3 つの軸を独立に**指定できる（すべて AND）。それぞれ「指定なし」を含む 3 状態。

| 軸         | 状態                                   |
| ---------- | -------------------------------------- |
| お気に入り | 指定なし / お気に入り / お気に入り以外 |
| 命名       | 指定なし / 名前あり / 未命名           |
| 立ち寄り   | 指定なし / あり / なし                 |

- 「すべて」で 3 軸まとめて解除する。何も絞っていなければ「すべて」が選択状態になる。
- 記録が 1 件も無いときは絞り込みのバーを隠す。絞り込んだ結果 0 件なら「条件に合う記録がありません」。

## 並べ替え

軸を選び、昇順・降順を切り替える。

| 軸           | 既定の向き |
| ------------ | ---------- |
| 日付（既定） | 新しい順   |
| 立ち寄り数   | 多い順     |
| 距離         | 長い順     |
| 時間         | 長い順     |
| 名前         | 昇順       |

- **未命名は名前が無いものとして扱い**、昇順で先頭・降順で末尾に来る。
- 同じ値のものは元の並び（開始が新しい順）を保つ。

## 移動距離について

移動距離は**記録を終えた時点で確定**し、以降は変わらない。

- 補正のパラメータを変えても、**過去の経路の距離は計算し直さない**。
- 距離順の並べ替えも、この確定した値を見る。
