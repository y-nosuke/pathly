# 0043. 地域の目印は数を限らず並べ、チップは左上に縦に 5 つまで出して残りは 1 つにまとめる。保存はしない

- Status: Accepted
- Date: 2026-11-19

関連: 「地域へ移動」と目印は [0032](0032-jump-to-region-by-places-autocomplete.md)、置き場所（上の下）は
[0038](0038-screen-layouts-four-corners-and-tool-row.md)、Places の内容を保存しない考え方は [0029](0029-place-region-by-geocoder.md)。
仕様は specs/map.md の「地域へ移動」。

## Context（背景）

「地域へ移動」の目印は 1 つだけで、別の地域を選ぶと置き換わり、記録画面を離れると消えていた。旅行の計画などで、
いくつかの地域を行き来しながら地図を見たい（例: 福岡市と北九州市を見比べる。#203）。

決めることは、いくつまで置けるか・チップの並べ方・いつまで残すか（保存するか）・目印のタップの意味。

## Decision（決定）

- **目印の数は限らない。** 選んだ地域はすべて目印とチップにする。もう出している地域を選び直したときは数を増やさず、
  覚えている範囲へ移す（範囲の取得もし直さない）。
- **チップは上の下の左に縦に並べる。** 上から「すべて外す」（2 つ以上のとき）・選んだ順の地名のチップ 5 つまで・
  6 つ目からをまとめた「他 N 件」。まとめを押すとメニューで地名を出し、そこから移る・外す。
  最後に地図を移した地域のチップ（まとめの中ならまとめのチップ）を塗りつぶす。並び順は選んだ順のまま変えない。
- チップの地名・目印のタップでその地域へ寄せ直す。外すのはチップ（メニュー）の × と「すべて外す」。
  現在地ボタン・目印のタップでは消さない。
- **保存しない（DB にも SharedPreferences にも置かない）。** 記録画面の ViewModel に持ち、タブの行き来・画面の回転では残り、
  アプリが終わると消える。

## Alternatives（検討した没案）

- **5 つを上限にし、6 つ目は出せない旨を出して止める** … 一度作ったが、見比べたい地域が多いときに外してから選び直す手間がかかる。
  保存しないので数が増えても困らない → **却下**。
- **上限を超えたらいちばん古い目印を外して足す** … 知らないうちに見比べていた地域が消える → **却下**。
- **チップを横に並べて横にスクロール** … 一度作ったが、どの地域があるかを一目で見にくい → **却下**（縦に並べる）。
- **縦に並べ、高さを決めて縦にスクロール** … 作りは軽いが、地図の上の細い列を送る指が地図のドラッグと紛れ、
  隠れた地域があることにも気づきにくい → **却下**（数を決めてまとめる）。
- **押したチップを先頭に上げる** … 今見ている地域がいつも見えるが、2 つを行き来するたびに並びが入れ替わり、押す場所がずれる → **却下**。
- **SharedPreferences か DB に保存して、アプリを閉じても残す** … 計画を何日かに分けて続けられるが、目印は地名（候補の文字）と
  範囲（viewport）で、どちらも Places の内容。規約で保存してよいと明記されているのは place ID と緯度・経度（30 日まで）だけで
  （[0029](0029-place-region-by-geocoder.md)）、合わない → **却下**。
- **place ID だけ保存し、開くたびに範囲を引き直す** … 規約には合うが、目印ごとに開くたび Place Details の料金がかかる → **却下**。
- **目印のタップで消す（今まで）** … 複数あると見比べている途中で誤って消しやすい。外すのはチップに寄せる → **却下**。

## Consequences（結果・トレードオフ）

- いくつかの地域をチップで行き来できる。記録画面を離れて戻っても残る。
- 縦のチップが地図の左上を隠す（5 つと「すべて外す」「他 N 件」で 7 段ほど）。6 つ目からの地域へ移るのは 1 タップ増える。
- 地域を選ぶたびの料金（Place Details）は今までと同じ。選び直しは取得しないぶん減る。
- アプリが終わる（裏で OS に終了させられるのも含む）と消えるので、日をまたいだ計画には向かない。
  保存して残す形が要るなら、規約と費用を見直して別の決定にする。
