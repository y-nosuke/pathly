# 0038. 地図の画面は四隅で役割を固定し、一覧の画面は見出しとツール行にそろえる

- Status: Accepted（主役を「いつも見える」とした点は [0042](0042-primary-action-moves-with-sheet.md) で読み替え）
- Date: 2026-11-16

関連: 型の中身は [designs/ui-direction.md](../designs/ui-direction.md)。一覧の絞り込みの欄は [0031](0031-list-filters-in-a-panel.md)、
地図の上のシートは [0010](0010-non-modal-map-sheets.md)、検索窓のまとめ方は [0039](0039-one-search-box-for-places-and-regions.md)。

## Context（背景）

機能が増えて、記録・履歴・場所の地図のボタンや、一覧の検索・絞り込み・並べ替えが窮屈になった（#186）。
これまでは操作性を優先し、見た目は画面ごとに足してきた。

今の画面を棚卸しすると（エミュレータに実データの写しを入れて撮影）、窮屈さは色や部品ではなく、置き場所の決まりが無いことから来ていた。

- 地図の操作の置き場所が画面ごとに違う（記録＝右の縦列 6 個、経路詳細＝上の横列、場所詳細＝左上と右の縦列）。
  同じ「登録済みの場所の表示」が画面ごとに別の位置にあり、現在地は記録にしか無い。
- 一覧の上に、検索欄・絞り込み・並べ替え（2〜3 個）・統計のカードが積まれ、最初の画面の半分近くを使う。
- 主役（記録の停止・行のタップ）と、たまにしか使わないもの（再解析・削除・開発用）が同じ重さで並ぶ。

部品をまとめるリファクタリング（#185）と画面ごとの見直しの前に、どこに何を置くかの型を決めておく。
色・文字などの雰囲気は、後で作る Design System で決める（ここでは決めない）。

## Decision（決定）

- 操作を **主役（画面に 1〜2 個）・脇役・しまう** の 3 段に分け、段ごとに置き場所を決める。
- **地図の画面は「四隅で役割を固定」する。** 上＝戻る＋見出し（タブの画面は検索窓）と右端のレイヤー・⋮、
  右下＝地図の操作、下中央＝主役、下＝非モーダルのシート。地図に重ねるもの（登録済みの場所・絞り込み・この範囲の経路）は
  レイヤーの中、対象への操作（名前・お気に入り・再解析・開発用）は ⋮ の中にしまう。
  記録・経路詳細・場所詳細・履歴と場所の地図表示・場所の追加（地図で選ぶ）のすべてに当てる。
- **一覧の画面は「見出し＋ツール行」にそろえる。** 見出し＝名前・検索（アイコンから窓を開く）・地図への切り替え、
  ツール行＝絞り込み（左）と表示のメニュー（右。並べ替えの軸・向き・分け方）、統計は 1 行の帯、追加は右下の丸。
  削除は行から外して詳細の中へ。
- ずっと出しておく案内（電池の最適化など）は 1 行の帯にして、押すと設定へ。
- タブは 4 つのまま。記録画面の「この範囲の経路」はレイヤーの中に残す（履歴の地図とは用途が違う）。
- 今の画面は、画面ごとの見直しの Issue で 1 つずつこの型へ移す。

## Alternatives（検討した没案）

案は claude.ai の Design に、今のボタンを全部載せた状態で描いて比べた。

- **地図 B: 下のシートに集める** … 地図に浮かぶのは検索窓と現在地だけにし、操作はシートの先頭の「道具の列」に並べる →
  地図はいちばん広く親指も届くが、シートをたたむと操作も隠れ、道具の列が横にあふれやすい。却下。
- **地図 C: 上のツールバー** … 今の経路詳細の上の横列を全部の地図の画面に広げる → 今に近く移しやすいが、
  上の帯は片手で届きにくく、アイコンだけでは意味が分かりにくい。却下。
- **一覧 B: 検索バーが見出し** … 上端を検索窓にし、その下のチップの行に絞り込み・条件・並べ替え・分け方を並べる →
  探すのは早いが、1 つの行に種類の違うものが混ざる。却下。
- **一覧 C: 親指のツールバー** … 操作をタブの上に浮かぶ帯にまとめる → 片手で全部届くが、一覧の下が隠れ、
  地図の画面と流儀が分かれる。却下。
- **画面ごとに最適な置き方を選ぶ（型を決めない）** … 今のやり方。画面ごとの都合で置き場所が増え続け、窮屈さの元になった。却下。

## Consequences（結果・トレードオフ）

- どの地図の画面でも同じ場所に同じものが来るので、画面を足しても置き場所に迷わない。#185 で地図の部品をまとめるときの
  区画（上・右下・下中央・シート）がそのまま部品の単位になる。
- 記録中の「今ここを立ち寄り」「地図で指して追加」は主役から外れてシートの中に入る。今より 1 段下がる。
- 一覧の検索は 1 タップ遠くなる（アイコンから窓を開く）。
- 型を当てるまでは、今の画面（[specs/screens.md](../specs/screens.md)）と型（designs/ui-direction.md）が食い違う。
  画面ごとの見直しが終わるまで続く。
- 型は繰り返し見直す前提。見直すときは棚卸しを撮り直し、Design に案を描いて比べ、この ADR を置き換える。
