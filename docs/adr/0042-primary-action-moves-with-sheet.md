# 0042. 地図の画面の主役はシートと一緒に動き、シートを畳めば隠れる。シートはタップでも開け閉めする

- Status: Accepted
- Date: 2026-11-18

関連: 置き換える決定は [0038](0038-screen-layouts-four-corners-and-tool-row.md) の「主役はいつも見える」。
非モーダルのシートは [0010](0010-non-modal-map-sheets.md)。

## Context（背景）

記録画面を画面の型（0038）に移すとき（#193）、下中央の開始・停止の丸と、記録中の情報・脇役の操作を載せた下のシートが
地図の下の 1/4 ほどを常に使うことになった。地図を広く見たいときに丸を隠したい、という要望が出た。

0038 では主役を「いつも見えていて押しやすい」ものと決めていた。ただ、ほかの地図の画面の主役（経路詳細の立ち寄りの行・
履歴の地図の経路を選ぶ行）はもともと下のシートの中にあり、シートを下へ払えば隠れて「▲ 詳細を表示」で戻せる。
記録画面の丸だけが地図に固定されていた。

また、シートの段を変えるのはつまみのドラッグだけで、ドラッグが手間だという声があった。

## Decision（決定）

- **地図の画面の主役は、いつも見えているか、1 タップで戻せる**（0038 の段分けの「主役」を読み替える）。
  - 記録画面の開始・停止の丸は、下の記録のシートのすぐ上に置き、シートと一緒に動く。シートを畳むと丸も隠れ、
    戻すボタン（記録中は「▲ 記録中・1.82km」）だけが残る。停止中も小さなシート（「記録していません」）を出す。
  - 開いたとき・記録を始めたときは、シートと丸が出ている。自分で畳まない限り隠れない。
- **シートはタップでも開け閉めする。** つまみの行のタップでハーフ⇔フル、右端の畳むボタン（▼）で畳む。
  畳むボタンは戻すボタンのあるシートだけに出す（戻せないシートを畳ませない）。ドラッグもこれまでどおり使える。

## Alternatives（検討した没案）

- **地図を動かしている間だけ丸を隠す** … 操作は増えないが、自分で隠したままにはできない。却下。
- **丸を小さなピルに畳める** … 隠れはしないので見失わないが、地図はあまり広がらない。却下。
- **主役はいつも見えるのまま（0038）** … 記録画面の下が常に埋まり、地図を広く見られない。却下。
- **つまみのタップで 3 段を順に回す** … ボタンが 1 つで済むが、畳みたいときに 2 回押すことがあり、どの段へ行くか
  分かりにくい。却下。

## Consequences（結果・トレードオフ）

- どの地図の画面でも「主役はシートと一緒。払えば隠れ、戻すボタンが残る」にそろう。
- 丸が隠れているときに記録を始める・止めるには、戻すボタンを押してから丸を押す（1 タップ増える）。
- 右下の地図の操作は、シートの上端（畳んだときは戻すボタンの上）に沿って動く。
- シートのつまみの行が、畳むボタンのあるシートでは少し高くなる（押せる大きさを取るため）。
