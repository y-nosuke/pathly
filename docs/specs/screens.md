# 画面仕様（UI/UX仕様）

Jetpack Compose による Android アプリの画面仕様。**マップを主役にした map-first 構成**を基本方針とする。

> 対応する要望: [requirements.md](../requirements.md) の「地図で確認したい」「リアルタイムに記録したい」「操作をシンプルにしたい」。

## 設計方針

- **map-first**: 記録画面・詳細画面はどちらも全画面マップを土台にし、操作や情報はその上に重ねる（オーバーレイ／ボトムシート）。マップを小さなカードに埋めない。
- **ワンタップ記録**: 記録の開始/停止は大きな丸い FAB 一つ。
- **将来の拡張を地図とシートに載せる**: 写真・評価・タグはマップ上のピンとボトムシートの行として足せる形にしておく。

## ナビゲーション構成

ボトムナビの4タブ（記録・履歴・場所・設定）。詳細画面（経路詳細）は全画面で開き、その間はボトムナビを隠す。「場所」タブの配下（一覧・追加・検索・詳細）は行き来しても入力途中の状態を保つ。

```text
┌─────────────────────────────┐
│                             │
│      各画面（全画面）         │
│                             │
├─────────────────────────────┤
│ [記録] [履歴] [場所] [設定]  │ ← BottomNavigationBar（詳細表示中は非表示）
└─────────────────────────────┘
```

| タブ | 機能                               | アイコン         |
| ---- | ---------------------------------- | ---------------- |
| 記録 | 全画面マップ＋GPS記録              | `ic_location_on` |
| 履歴 | 過去記録の一覧・統計               | `ic_list`        |
| 場所 | 登録済みの場所一覧・登録・行きたい | `ic_place`       |
| 設定 | GPS記録間隔などの設定              | `ic_settings`    |

> 「場所」はマイルストーンを前倒しして追加。全ての場所（places）を一覧し、各場所に「行きたい」を付け外しできる。将来の計画タブ（Phase 3）の前身。

## 画面設計詳細

### 1. 記録画面（ホーム / map-first）

全画面のライブマップ。自分の現在地（青ドット）を表示し、記録中は経路（補正後）をリアルタイムに描画する。

```text
┌─────────────────────────────┐
│        ● 記録中 00:12:34  ◎ │ ← 上部中央:経過時間ピル／右上:現在地ボタン◎
│ [立ち寄りを追加]          🚩 │ ← 左上(記録中のみ):モード切替・今ここ／右:登録済み表示
│         [全画面 Google Map]  │ ← 現在地追従・青ドット・経路polyline
│         ～～～ 経路 ～～～      │
│                             │
│  ┌───────────────────────┐  │
│  │ ● 立ち寄り中  ◯◯ 滞在3分 │  │ ← 立ち寄り検出中のみ
│  └───────────────────────┘  │
│  ┌───────────────────────┐  │
│  │ 1.8km        42        │  │ ← 記録中のみ：距離・地点数カード
│  │ 移動距離     地点数       │  │
│  └───────────────────────┘  │
│            ( ▶ / ■ )        │ ← 記録開始/停止 FAB（丸）
├─────────────────────────────┤
│ [記録] [履歴] [場所] [設定]  │
└─────────────────────────────┘
```

- **FAB**: 停止中は ▶（`ic_play_arrow`・primary色）、記録中は ■（`ic_stop`・error色）。
- **現在地ボタン**（右上・`ic_my_location`）: 追従中は色付き、手動で地図を動かすとグレー（固定）。タップで現在地へ再センター＆追従再開。取得中は「現在地を取得中…」を上部に表示。
- **記録中の表示**: 上部に経過時間ピル（● 記録中）、下部に距離・地点数の統計カード。立ち寄りを検出中は「● 立ち寄り中」カード（場所名・滞在時間）を表示。
- **電池最適化の案内**: 電池の最適化が有効なままだとバックグラウンド記録が止まりやすいため、無効化を促すカードを表示。
- **権限がない場合**: マップ中央に権限リクエストのカードをオーバーレイ表示（「位置情報を許可」ボタン）。
- **中断記録の復帰**: アプリ更新などで前回記録が中断されていた場合、起動時に「再開する／完了にする」ダイアログを表示。
- **エラー**: 下部にエラーカードを表示。
- **場所の登録（POIタップ）**: マップ上の施設アイコン（POI）をタップすると**場所シート**（自分で付ける名前・メモ・行きたいトグル・優先度）を表示。シートはモーダルでないので、出したまま地図を動かせる。登録した場所は「場所」タブに現れる。登録直後は上部に確認ピルを一時表示。何もない地点のタップでも同じシートで登録できる（挙動の一覧は「地図タップの意味」）。
- **立ち寄りを追加（記録中のみ）**: 左上のトグルで**追加モード**に入る。ON の間は地図タップが立ち寄り追加、OFF なら場所登録。同じく左上の**「今ここ」**は現在地をそのまま立ち寄りにするショートカット。滞在区間の調整は下部の立ち寄りシートで行う。
- **登録済みの場所の表示**: トグルで既存の場所をマーカー表示できる（訪問済み/未訪問で色、業種でアイコン、行きたいは右上の旗）。業種が分からない場所は場所ピンのまま。ON/OFF は画面ごとに独立して保存される。
- **立ち寄りマーカーのタップ**: 誤検知だったとき、その訪問だけ正しい場所へ**選び直せる**。

### 2. 履歴画面

日付順の記録一覧。先頭に統計サマリー、記録中があればアクティブカードを表示。項目タップで詳細画面へ。

```text
┌─────────────────────────────┐
│ 外出履歴                      │
│ [すべて][♥][名前あり][立寄り]│ ← 絞り込みチップ（横スクロール）
│ 並べ替え: [日付順 ▾] [↓]     │ ← 軸ドロップダウン＋昇降トグル
│ ┌─────────────────────────┐ │
│ │ 📊 お出掛け統計           │ │ ← 記録数 / 総距離 / 総時間
│ └─────────────────────────┘ │
│ ┌─────────────────────────┐ │
│ │ 🟢 記録中 …               │ │ ← 記録中があれば先頭に
│ └─────────────────────────┘ │
│ ┌─────────────────────────┐ │
│ │ 秋の鎌倉さんぽ      ♥  ⋮ │ │ ← 名前（無ければ日付）／お気に入り／メニュー
│ │ 2026/07/19 10:00–15:20   │ │
│ │ 1.8km ・ 立ち寄り: 3件    │ │
│ └─────────────────────────┘ │
├─────────────────────────────┤
│ [記録] [履歴] [場所] [設定]  │
└─────────────────────────────┘
```

- **統計サマリー**: 記録数・総距離・総時間。
- **記録項目**: 見出しは**名前があれば名前**（無ければ日付。名前ありのときは日付を副題に）。開始/終了時刻・移動距離・**立ち寄り件数**を表示。右に**お気に入りハート**と**オーバーフローメニュー**（名前を付ける/編集・削除）。
- **絞り込み**（3軸独立・AND）: お気に入り／命名／立ち寄りの有無。「すべて」チップでまとめて解除。
- **並べ替え**: 日付・立ち寄り数・距離・時間・名前（軸＋昇降）。
- 記録が無いときは「記録がありません」。絞り込みで 0 件なら「条件に合う記録がありません」。
- 一覧に載るのは**完了済み**だけ。記録中は先頭に別枠で出す。

### 3. 詳細画面（map-first）

全画面マップに軌跡と立ち寄りを表示し、情報はドラッグ可能なボトムシートに畳む。

```text
┌─────────────────────────────┐
│ (←)  (⚙)                    │ ← 戻る／補正調整（⚙はデバッグビルドのみ）
│         [全画面 Google Map]  │
│      ～～ 軌跡 ～～  📍立ち寄り │ ← 開始(緑)・終了/現在地(赤/青)・立ち寄り(紫)
│ ┌─────────────────────────┐ │
│ │ ═══                     │ │ ← ドラッグハンドル
│ │ 2026年07月19日    ●記録中 │ │
│ │ 14:30 – 15:50 ・1時間20分 ・立ち寄り2件│
│ │ [再解析] [立ち寄りを追加] [場所を取得(未取得1件)]│ ← 操作チップ
│ │ ┌────────┐ ┌────────┐   │ │
│ │ │ 3.2km  │ │  128   │   │ │ ← 移動距離 / 地点数
│ │ └────────┘ └────────┘   │ │
│ │ ◯◯店  14:40–15:10 滞在30分  [編集][削除]│
│ │ △△公園 …                  [編集][削除]│
│ └─────────────────────────┘ │ ← ボトムシート（引き上げで詳細）
└─────────────────────────────┘
```

- **マーカー**: 形が「確定か、これから決めるものか」を表す。**丸**＝確定（開始＝緑、終了＝赤、記録中の現在地＝青、立ち寄り＝紫の番号、立ち寄り中＝ティール、登録済みの場所＝訪問状態の色＋業種アイコン）。**ピン**＝これから決めるもの（再解析の候補＝橙、手動追加で指した地点・登録前に選んだ地点＝青）。軌跡は橙色の線（補正後）。**各立ち寄りの滞在区間（到着〜出発の軌跡）を、濃い青の帯で軌跡の下に常時ハイライト**し、経路のどこで滞在したかが分かる（補正調整・候補選択・手動追加中は干渉を避けて非表示）。手動追加中は選んだ滞在区間を青い太線でハイライトする。
- **ボトムシート**: 日付・記録中バッジ・時刻範囲・所要時間・立ち寄り件数・移動距離・地点数。**3段階**で使う：既定は**ハーフ**（ピーク＝画面の約45%、地図が上・一覧が下で同時に見え、立ち寄りを連続タップして地図で確認できる）、上までドラッグで**全画面一覧**（Expanded）、下スワイプで**全画面地図**（Hidden、「▲ 詳細を表示」で復帰）。スナップ式なので途中位置では止まらない。**背後が暗くならず、シートを出したまま地図を操作できる**（モーダルではない）。
- **立ち寄り一覧**: 各行に場所名（未命名は座標）・到着–出発・滞在時間、**メモがあれば本文をインライン表示**（最大2行・省略）。行タップで地図をその場所へフォーカス（シートは畳まず地図だけが動くので、続けてタップして確認できる）。「メモ」で**訪問メモの編集ダイアログ**（stop 単位・複数行・空で保存すると消える。場所名 place 単位とは別物）。「編集」で名前編集ダイアログ。「削除」で1件、**行を長押しすると複数選択して一括削除**（記録中に拾った誤検知の掃除を想定。誤って消しても**再解析**で戻せる）。削除は単体・複数とも「訪問を消す」動作で、消した結果どこからも参照されなくなった場所だけ自動で場所ごと消える。**他の履歴や行きたいリストで使われている場所は残る**（その履歴の訪問だけ消える）。場所ごと明示的に消したいときは場所タブから。
- **削除の取り消し**: 削除は確認ダイアログを出さず**即時実行**し、**スナックバーの「取り消す」**でしばらくの間だけ元に戻せる（消した訪問と回収された場所を元のまま復元）。画面を離れると削除は確定する。
- **操作チップ**:
  - 「再解析」（終了済みの経路で表示）: 検出し直して**一覧に無い立ち寄り候補**を**地図に橙のピン**で出し（確定済みは紫の丸なので、色と形の両方で見分けられる）、**地図の下の固定オーバーレイ**（地図は常に表示・リストはその中で独立スクロール）で選ぶ（**非破壊・opt-in**）。各候補には**場所名**を添える（近くの命名済み place を再利用＝無料、無ければオンライン時のみ Places で1回）。行タップで地図がその候補へ寄るので、**名前と位置で「本当に立ち寄ったか」を確かめてから**チェックして**追加**できる。記録中の取りこぼしや、**誤って削除した立ち寄りの復旧**に使う。候補ゼロなら「見つかりませんでした」。既存の立ち寄りには触れない。
  - 「立ち寄りを追加」: 検出に頼らず**手で立ち寄りを足す**（完全手動・非破壊）。**記録中も使える**。押すと**追加モード**に入り、地図を**通常タップ**で地点を指す（**POI はタップで施設名も入る**）。指した地点は**青いピン**で示し、最寄り軌跡点から到着/出発を仮置き。下部の立ち寄りシートで滞在区間（到着〜出発）を調整でき、その区間は**地図に青くハイライト**されて経路のどこに当たるかが見える。調整は**スライダー（粗）＋ ＋/−（到着・出発を1点ずつ微調整）**の2段構えで、経路が長くても精密に合わせられる。名前は任意（POI 名で初期化）。地点確定後のキャンセル/バックは地点選択（マップ）に戻すだけ・地点選択中のキャンセル/バックで追加モードを抜ける（2段階）。検出しきい値に満たない短い滞在など、**再解析でも救えない立ち寄り**を足すのに使う。
  - 「場所を取得（未取得 N 件）」（`googlePlaceId` が無い場所を Google で命名する。オフラインで解決できなかった分の手動再実行・非破壊）。未取得が無ければ非表示。
- **補正の調整（デバッグビルドのみ）**: `ic_tune` ボタンで調整モードに入り、生データ（灰）を重ねつつスライダー（速度上限・平滑窓）で補正を試せる。
- **場所の登録（POIタップ）**: 地図の施設アイコン（POI）をタップすると**場所シート**（名前・メモ・行きたい）。振り返り中に見かけた場所を保存できる（記録画面・場所詳細と共通のシート）。タップした地点がシートに隠れないよう、地図はシートの高さぶん寄る。
- **将来**: このシートに写真・評価・コメント・タグの枠を追加（Phase 2）。

### 4. 設定画面

アプリの動作設定。現状は GPS 記録間隔のみ。

```text
┌─────────────────────────────┐
│ 設定                          │
│ GPS記録間隔                   │
│ 短いほど滑らか／長いほど省電力 │
│   ◉ 5秒（高精度・電池大）      │
│   ○ 10秒（標準）              │
│   ○ 30秒（省電力）            │
│   ○ 60秒（最省電力）          │
│ ※ 変更は次に記録を開始した時から│
├─────────────────────────────┤
│ [記録] [履歴] [場所] [設定]  │
└─────────────────────────────┘
```

- **GPS記録間隔**: 5 / 10 / 30 / 60 秒からラジオ選択（既定は 10 秒＝標準）。短いほど軌跡が滑らかだが電池を多く使う。
- 変更は次に記録を開始したときから反映される。

### 5. 場所画面

登録済みの**全ての場所**（places）を一覧し、各場所に「行きたい」を付け外しできる。

```text
┌─────────────────────────────┐
│ 場所                    (＋) │ ← 右上:追加
│ [すべて][行きたい][訪問済み] │ ← 絞り込みチップ（行きたい/訪問の2軸）
│ 並べ替え: [登録順 ▾] [↓]     │ ← 軸ドロップダウン＋昇降トグル
│ ┌─────────────────────────┐ │
│ │ ◯◯カフェ            [🚩] │ │ ← 名前・行きたいフラグ(タップでON/OFF)
│ │ 行きたい ★★★ / メモ抜粋… │ │
│ └─────────────────────────┘ │
├─────────────────────────────┤
│ [記録] [履歴] [場所] [設定]  │
└─────────────────────────────┘
```

- **一覧**: 既定は登録の新しい順（安定・トグルで並びが動かない）。**絞り込みの切り替え時は先頭までスクロール**（変化を分かりやすく）。絞り込みは**行きたい**（指定なし/行きたい/行きたい以外）と**訪問**（指定なし/訪問済み/未訪問）の**2軸独立**、並べ替えは**登録順・訪問順・訪問回数順・優先度順・名前順・更新順**の軸＋昇降（履歴タブと同じ流儀）。各行は **名前 → バッジ（行きたい優先度／訪問回数）→ 住所1行** の階層で表示（詰め込みすぎない）。行きたいフラグ（右・タップで付け外し／ON=塗り・OFF=輪郭で判別）・削除アイコンを右に。**立ち寄り検出で自動生成された場所も含む**。
- **訪問済みの判定**: その場所に**立ち寄り（stops）記録が1件以上あれば訪問済み**（回数も表示）。手動トグル（行きたい登録時・立ち寄り記録が無い場合のみ）でも設定可。
- **追加（＋）**: メニューで「検索して追加」「地図で選ぶ」を選ぶ。
  - **検索して追加**: 店名などを入力 → 候補（Autocomplete）から選ぶ → 名前・住所・座標を取得して登録（行きたいトグル・優先度・メモ）。**オンライン限定・要 Places API(New)＋課金**。
  - **地図で選ぶ**: 全画面マップ。**マップをタップして初めて場所シートを出す**（マップを広く使う）。**アイコン(POI)をタップすると施設名が見出しに出る**（名前欄には入れない＝名前欄は自分で付ける名前専用）。保存＝**まず場所を登録**し、「行きたい」トグルがONのときだけ wishlist にも入れる（優先度はON時に表示・メモは常時）。
- **詳細**: map-first。左上に戻るボタン。下部は他の地図画面と同じ**非モーダルのシート**で、その高さぶんマップに余白を入れ、ピンが隠れないようにする（畳めば全画面地図・「▲ 詳細に戻る」で復帰）。見出しに表示名を出し、名前欄は**自分で付ける名前**専用（空で未命名に戻る。空のときだけ「この名前から書き換える」で Google 名を流し込める）。行きたいの付け外し、ON時は優先度・訪問済みを編集（メモは行きたいに関わらず編集可・**保存は変更があるときのみ活性**）。訪問済みは回数も表示。**この場所を含むお出掛け（N件）**を一覧（日付＋その場所の滞在、**その訪問のメモがあれば表示**）、タップで経路詳細（振り返り）を開く。訪問メモの**編集は履歴詳細**で（ここは表示のみ）。**削除**（即時・一覧へ戻って取り消し可能）。マップの別のPOIをタップすると、その場所も登録できる（共通の場所シート）。
- **削除**: 一覧の各行と詳細から。**立ち寄り記録（stops）がある場所は削除不可＝ボタン非活性**（記録を残すため）。行きたい・座標だけが紐づく場所のみ削除でき、place・wishlist・解決ログを消す（stops は消さない）。**確認ダイアログは出さず即時削除**し、**一覧のスナックバー「取り消す」**でしばらくの間だけ元に戻せる（place・wishlist・解決ログを元のまま復元）。詳細から消した場合も一覧へ戻って取り消せる。
- **後段（未実装）**: 立ち寄りからの「また行きたい」ワンタップ追加、タグ（複数）。

## デザイントークン

### カラー（暖色系・Material3）

Material3 のダイナミックカラーに対応（Android 12+）。非対応端末では以下の暖色系スキームを使う。ダークモード対応済み。

| 役割             | 色                       |
| ---------------- | ------------------------ |
| primary          | `PathlyOrange` (#FF6B35) |
| secondary        | `PathlyGreen` (#2ECC71)  |
| error            | `ErrorRed`               |
| 軌跡 polyline    | `TrackLineOrange`        |
| 開始マーカー     | 緑（HUE_GREEN）          |
| 終了マーカー     | 赤（HUE_RED）            |
| 現在地マーカー   | 青（HUE_BLUE）           |
| 立ち寄りマーカー | 紫（HUE_VIOLET）         |

### アイコン

画面で使うアイコン（`ic_location_on` / `ic_list` / `ic_place` / `ic_flag` / `ic_flag_filled` / `ic_favorite` / `ic_favorite_filled` / `ic_more_vert` / `ic_settings` / `ic_play_arrow` / `ic_stop` / `ic_arrow_back` / `ic_my_location` / `ic_tune` / `ic_delete`）。`ic_place` は場所タブ、行きたいフラグは **OFF=`ic_flag`（輪郭）/ ON=`ic_flag_filled`（塗り・primary色）** で区別する。
