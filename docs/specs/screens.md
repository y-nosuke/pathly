# 画面仕様（UI/UX仕様）

Jetpack Compose による Android アプリの画面仕様。**マップを主役にした map-first 構成**を基本方針とする。

> 対応する要望: [requirements.md](../requirements.md) の「地図で確認したい」「リアルタイムに記録したい」「操作をシンプルにしたい」。

## 設計方針

- **map-first**: 記録画面・詳細画面はどちらも全画面マップを土台にし、操作や情報はその上に重ねる（オーバーレイ／ボトムシート）。マップを小さなカードに埋めない。
- **ワンタップ記録**: 記録の開始/停止は大きな丸い FAB 一つ。
- **将来の拡張を地図とシートに載せる**: 写真・評価・タグはマップ上のピンとボトムシートの行として足せる形にしておく。

## ナビゲーション構成

ボトムナビの4タブ（記録・履歴・場所・設定）。詳細画面（経路詳細）は全画面で開き、その間はボトムナビを隠す。実装は Jetpack Navigation-Compose（`presentation/navigation/PathlyNavHost.kt`）。「場所」タブはネストグラフで、配下の目的地（一覧・追加・検索・詳細）はグラフスコープの `PlacesViewModel` を共有する。

```text
┌─────────────────────────────┐
│                             │
│      各画面（全画面）         │
│                             │
├─────────────────────────────┤
│ [記録] [履歴] [場所] [設定]  │ ← BottomNavigationBar（詳細表示中は非表示）
└─────────────────────────────┘
```

| タブ | 機能                               | アイコン         |
| ---- | ---------------------------------- | ---------------- |
| 記録 | 全画面マップ＋GPS記録              | `ic_location_on` |
| 履歴 | 過去記録の一覧・統計               | `ic_list`        |
| 場所 | 登録済みの場所一覧・登録・行きたい | `ic_place`       |
| 設定 | GPS記録間隔などの設定              | `ic_settings`    |

> 「場所」はマイルストーンを前倒しして追加（[../designs/wishlist.md](../designs/wishlist.md)）。全ての場所（places）を一覧し、各場所に「行きたい」を付け外しできる。将来の計画タブ（Phase 3）の前身。

## 画面設計詳細

### 1. 記録画面（ホーム / map-first）

全画面のライブマップ。自分の現在地（青ドット）を表示し、記録中は経路（補正後）をリアルタイムに描画する。

```text
┌─────────────────────────────┐
│        ● 記録中 00:12:34  ◎ │ ← 上部中央:経過時間ピル／右上:現在地ボタン◎
│                             │
│         [全画面 Google Map]  │ ← 現在地追従・青ドット・経路polyline
│         ～～～ 経路 ～～～      │
│                             │
│  ┌───────────────────────┐  │
│  │ ● 立ち寄り中  ◯◯ 滞在3分 │  │ ← 立ち寄り検出中のみ
│  └───────────────────────┘  │
│  ┌───────────────────────┐  │
│  │ 1.8km        42        │  │ ← 記録中のみ：距離・地点数カード
│  │ 移動距離     地点数       │  │
│  └───────────────────────┘  │
│            ( ▶ / ■ )        │ ← 記録開始/停止 FAB（丸）
├─────────────────────────────┤
│ [記録] [履歴] [場所] [設定]  │
└─────────────────────────────┘
```

- **FAB**: 停止中は ▶（`ic_play_arrow`・primary色）、記録中は ■（`ic_stop`・error色）。
- **現在地ボタン**（右上・`ic_my_location`）: 追従中は色付き、手動で地図を動かすとグレー（固定）。タップで現在地へ再センター＆追従再開。取得中は「現在地を取得中…」を上部に表示。
- **記録中の表示**: 上部に経過時間ピル（● 記録中）、下部に距離・地点数の統計カード。立ち寄りを検出中は「● 立ち寄り中」カード（場所名・滞在時間）を表示。
- **電池最適化の案内**: 電池の最適化が有効なままだとバックグラウンド記録が止まりやすいため、無効化を促すカードを表示。
- **権限がない場合**: マップ中央に権限リクエストのカードをオーバーレイ表示（「位置情報を許可」ボタン）。
- **中断記録の復帰**: アプリ更新などで前回記録が中断されていた場合、起動時に「再開する／完了にする」ダイアログを表示。
- **エラー**: 下部にエラーカードを表示。
- **場所の登録（POIタップ）**: マップ上の施設アイコン（POI）をタップすると登録ダイアログ（名前・行きたいトグル）を表示。登録した場所は「場所」タブに現れる。登録直後は上部に確認ピルを一時表示。

対応実装: `presentation/tracking/TrackingScreen.kt`, `TrackingViewModel`（`currentTrack` をリアルタイム購読）。

### 2. 履歴画面

日付順の記録一覧。先頭に統計サマリー、記録中があればアクティブカードを表示。項目タップで詳細画面へ。

```text
┌─────────────────────────────┐
│ 外出履歴                      │
│ ┌─────────────────────────┐ │
│ │ 📊 お出掛け統計           │ │ ← 記録数 / 総距離 / 総時間
│ └─────────────────────────┘ │
│ ┌─────────────────────────┐ │
│ │ 🟢 記録中 …               │ │ ← 記録中があれば先頭に
│ └─────────────────────────┘ │
│ ┌─────────────────────────┐ │
│ │ 2026/07/19  1.8km …   🗑 │ │ ← 各記録（タップで詳細／削除）
│ └─────────────────────────┘ │
├─────────────────────────────┤
│ [記録] [履歴] [場所] [設定]  │
└─────────────────────────────┘
```

- **統計サマリー**: 記録数・総距離・総時間。
- **記録項目**: 日付・開始/終了時刻・移動距離（地点数）。ゴミ箱アイコンで削除。
- 記録が無いときは「記録がありません」。

対応実装: `presentation/history/HistoryScreen.kt`, `HistoryViewModel`。

### 3. 詳細画面（map-first）

全画面マップに軌跡と立ち寄りを表示し、情報はドラッグ可能なボトムシートに畳む。

```text
┌─────────────────────────────┐
│ (←)  (⚙)                    │ ← 戻る／補正調整（⚙はデバッグビルドのみ）
│         [全画面 Google Map]  │
│      ～～ 軌跡 ～～  📍立ち寄り │ ← 開始(緑)・終了/現在地(赤/青)・立ち寄り(紫)
│ ┌─────────────────────────┐ │
│ │ ═══                     │ │ ← ドラッグハンドル
│ │ 2026年07月19日    ●記録中 │ │
│ │ 14:30 – 15:50 ・1時間20分 ・立ち寄り2件│
│ │ [再解析] [場所を取得(未取得1件)]│ │ ← 操作チップ
│ │ ┌────────┐ ┌────────┐   │ │
│ │ │ 3.2km  │ │  128   │   │ │ ← 移動距離 / 地点数
│ │ └────────┘ └────────┘   │ │
│ │ ◯◯店  14:40–15:10 滞在30分  [編集][削除]│
│ │ △△公園 …                  [編集][削除]│
│ └─────────────────────────┘ │ ← ボトムシート（引き上げで詳細）
└─────────────────────────────┘
```

- **マーカー**: 開始＝緑、終了＝赤、記録中の現在地＝青、立ち寄り＝紫。軌跡は `TrackLineOrange` の polyline（補正後）。
- **ボトムシート**: 日付・記録中バッジ・時刻範囲・所要時間・立ち寄り件数・移動距離・地点数。下スワイプでシートを隠して地図を全画面化でき、「▲ 詳細を表示」で復帰。
- **立ち寄り一覧**: 各行に場所名（未命名は座標）・到着–出発・滞在時間。行タップで地図をその場所へフォーカス。「編集」で名前編集ダイアログ。「削除」で1件、**行を長押しすると複数選択して一括削除**（再解析後の誤検知の掃除を想定）。削除は単体・複数とも「訪問を消す」動作で、消した結果どこからも参照されなくなった場所だけ自動で場所ごと消える。**他の履歴や行きたいリストで使われている場所は残る**（その履歴の訪問だけ消える）。場所ごと明示的に消したいときは場所タブから。
- **削除の取り消し**: 削除は確認ダイアログを出さず**即時実行**し、**スナックバーの「取り消す」**でしばらくの間だけ元に戻せる（消した訪問と回収された場所を元のまま復元）。画面を離れると削除は確定する。
- **操作チップ**: 「再解析」（補正・立ち寄りを再計算）、「場所を取得（未取得 N 件）」（未命名の場所名を Google で解決）。
- **補正の調整（デバッグビルドのみ）**: `ic_tune` ボタンで調整モードに入り、生データ（灰）を重ねつつスライダー（速度上限・平滑窓）で補正を試せる。
- **場所の登録（POIタップ）**: 地図の施設アイコン（POI）をタップすると登録ダイアログ（名前・行きたい）。振り返り中に見かけた場所を保存できる（共通 `RegisterPlaceFromPoiDialog`）。
- **将来**: このシートに写真・評価・コメント・タグの枠を追加（Phase 2）。

対応実装: `presentation/history/TrackDetailScreen.kt`（`BottomSheetScaffold`）。

### 4. 設定画面

アプリの動作設定。現状は GPS 記録間隔のみ。

```text
┌─────────────────────────────┐
│ 設定                          │
│ GPS記録間隔                   │
│ 短いほど滑らか／長いほど省電力 │
│   ◉ 5秒（高精度・電池大）      │
│   ○ 10秒（標準）              │
│   ○ 30秒（省電力）            │
│   ○ 60秒（最省電力）          │
│ ※ 変更は次に記録を開始した時から│
├─────────────────────────────┤
│ [記録] [履歴] [場所] [設定]  │
└─────────────────────────────┘
```

- **GPS記録間隔**: 5 / 10 / 30 / 60 秒からラジオ選択（既定は 10 秒＝標準）。短いほど軌跡が滑らかだが電池を多く使う。
- 変更は次に記録を開始したときから反映される。

対応実装: `presentation/settings/SettingsScreen.kt`, `SettingsViewModel`。

### 5. 場所画面

登録済みの**全ての場所**（places）を一覧し、各場所に「行きたい」を付け外しできる。
詳細な仕様は [../designs/wishlist.md](../designs/wishlist.md) を参照（本節は要点のみ）。

```text
┌─────────────────────────────┐
│ 場所                    (＋) │ ← 右上:追加（地図タップ）
│ [すべて] [行きたい] [訪問済み]│ ← フィルタ
│ ┌─────────────────────────┐ │
│ │ ◯◯カフェ            [🚩] │ │ ← 名前・行きたいフラグ(タップでON/OFF)
│ │ 行きたい ★★★ / メモ抜粋… │ │
│ └─────────────────────────┘ │
├─────────────────────────────┤
│ [記録] [履歴] [場所] [設定]  │
└─────────────────────────────┘
```

- **一覧**: 登録の新しい順（安定・トグルで並びが動かない）。**フィルタ切り替え時は先頭までスクロール**（変化を分かりやすく）。フィルタ（すべて/行きたい/訪問済み）。各行は **名前 → バッジ（行きたい優先度／訪問回数）→ 住所1行** の階層で表示（詰め込みすぎない）。行きたいフラグ（右・タップで付け外し／ON=塗り・OFF=輪郭で判別）・削除アイコンを右に。**立ち寄り検出で自動生成された場所も含む**。
- **訪問済みの判定**: その場所に**立ち寄り（stops）記録が1件以上あれば訪問済み**（回数も表示）。手動トグル（行きたい登録時・立ち寄り記録が無い場合のみ）でも設定可。
- **追加（＋）**: メニューで「検索して追加」「地図で選ぶ」を選ぶ。
  - **検索して追加**: 店名などを入力 → 候補（Autocomplete）から選ぶ → 名前・住所・座標を取得して登録（行きたいトグル・優先度・メモ）。**オンライン限定・要 Places API(New)＋課金**。
  - **地図で選ぶ**: 全画面マップ。**マップをタップして初めて入力欄を表示**（マップを広く使う）。**アイコン(POI)をタップすると名前を自動入力**、何もない場所は空欄。保存＝**まず場所を登録**し、「行きたい」トグルがONのときだけ wishlist にも入れる（優先度・メモはON時に表示）。
- **詳細**: map-first。左上に戻るボタン。下部カード（スクロール可）の高さぶんマップに余白を入れ、ピンがカードに隠れないようにする。**名前を手動で編集**（空で未命名に戻る）、行きたいの付け外し、ON時は優先度・メモ・訪問済みを編集（**保存は変更があるときのみ活性**）。訪問済みは回数も表示。**この場所を含むお出掛け（N件）**を一覧（日付＋その場所の滞在）、タップで経路詳細（振り返り）を開く。**削除**（確認ダイアログ）。マップの別のPOIをタップすると、その場所も登録できる（共通ダイアログ）。
- **削除**: 一覧の各行と詳細から。**立ち寄り記録（stops）がある場所は削除不可＝ボタン非活性**（記録を残すため）。行きたい・座標だけが紐づく場所のみ削除でき、place・wishlist・解決ログを消す（stops は消さない）。
- **後段**: キーワード検索登録（Google・オンライン）、立ち寄りからの「また行きたい」、タグ（複数）。

対応実装: `presentation/places/PlacesScreen.kt`, `PlacesViewModel`。

## デザイントークン

### カラー（暖色系・Material3）

`PathlyAndroidTheme` は Material3 ダイナミックカラー対応（Android 12+）。非対応端末では以下の暖色系スキームを使用。ダークモード対応済み。

| 役割             | 色                       |
| ---------------- | ------------------------ |
| primary          | `PathlyOrange` (#FF6B35) |
| secondary        | `PathlyGreen` (#2ECC71)  |
| error            | `ErrorRed`               |
| 軌跡 polyline    | `TrackLineOrange`        |
| 開始マーカー     | 緑（HUE_GREEN）          |
| 終了マーカー     | 赤（HUE_RED）            |
| 現在地マーカー   | 青（HUE_BLUE）           |
| 立ち寄りマーカー | 紫（HUE_VIOLET）         |

定義: `ui/theme/Color.kt`, `ui/theme/Theme.kt`。

### アイコン

Material Icons は不使用。`res/drawable` のベクター＋`painterResource` を使う（`ic_location_on` / `ic_list` / `ic_place` / `ic_flag` / `ic_flag_filled` / `ic_settings` / `ic_play_arrow` / `ic_stop` / `ic_arrow_back` / `ic_my_location` / `ic_tune` / `ic_delete`）。`ic_place` は場所タブ、行きたいフラグは **OFF=`ic_flag`（輪郭）/ ON=`ic_flag_filled`（塗り・primary色）** で区別する。

map-first 構成を土台に、[roadmap.md](../roadmap.md) の各フェーズを載せていく。

- **先行**: 「場所」タブ（[../designs/wishlist.md](../designs/wishlist.md)）。全ての場所を一覧し行きたいを付け外し。計画タブの前身。
- **Phase 2**: 写真・評価・コメント・タグを詳細シートに追加。手動での場所記録。
- **Phase 3**: 計画タブへ発展（お出掛けの計画・ルート・予算）。計画ルートをマップに重ねる。複数人でのリアルタイム共有。
