# 画面仕様（UI/UX仕様）

Jetpack Compose による Android アプリの画面仕様。**マップを主役にした map-first 構成**を基本方針とする。

> 対応する要望: [requirements.md](../requirements.md) の「地図で確認したい」「リアルタイムに記録したい」「操作をシンプルにしたい」。

## 設計方針

- **map-first**: 記録画面・詳細画面はどちらも全画面マップを土台にし、操作や情報はその上に重ねる（オーバーレイ／ボトムシート）。マップを小さなカードに埋めない。
- **ワンタップ記録**: 記録の開始/停止は大きな丸い FAB 一つ。
- **将来の拡張を地図とシートに載せる**: 写真・評価・タグはマップ上のピンとボトムシートの行として足せる形にしておく。

## ナビゲーション構成

ボトムナビの4タブ（記録・履歴・行きたい・設定）。詳細画面は全画面オーバーレイで開き、その間はボトムナビを隠す。実装は Jetpack Navigation を使わず、`MainActivity` の単純な State 管理（`selectedTab` / `selectedTrack`）。

```text
┌─────────────────────────────┐
│                             │
│      各画面（全画面）         │
│                             │
├─────────────────────────────┤
│ [記録] [履歴] [行きたい] [設定]│ ← BottomNavigationBar（詳細表示中は非表示）
└─────────────────────────────┘
```

| タブ     | 機能                     | アイコン         |
| -------- | ------------------------ | ---------------- |
| 記録     | 全画面マップ＋GPS記録    | `ic_location_on` |
| 履歴     | 過去記録の一覧・統計     | `ic_list`        |
| 行きたい | 行きたい場所の一覧・登録 | `ic_flag`        |
| 設定     | GPS記録間隔などの設定    | `ic_settings`    |

> 「行きたい」はマイルストーンを前倒しして追加（[../designs/wishlist.md](../designs/wishlist.md)）。将来の計画タブ（Phase 3）の前身。

## 画面設計詳細

### 1. 記録画面（ホーム / map-first）

全画面のライブマップ。自分の現在地（青ドット）を表示し、記録中は経路（補正後）をリアルタイムに描画する。

```text
┌─────────────────────────────┐
│        ● 記録中 00:12:34  ◎ │ ← 上部中央:経過時間ピル／右上:現在地ボタン◎
│                             │
│         [全画面 Google Map]  │ ← 現在地追従・青ドット・経路polyline
│         ～～～ 経路 ～～～      │
│                             │
│  ┌───────────────────────┐  │
│  │ ● 立ち寄り中  ◯◯ 滞在3分 │  │ ← 立ち寄り検出中のみ
│  └───────────────────────┘  │
│  ┌───────────────────────┐  │
│  │ 1.8km        42        │  │ ← 記録中のみ：距離・地点数カード
│  │ 移動距離     地点数       │  │
│  └───────────────────────┘  │
│            ( ▶ / ■ )        │ ← 記録開始/停止 FAB（丸）
├─────────────────────────────┤
│   [ 記録 ] [ 履歴 ] [ 設定 ] │
└─────────────────────────────┘
```

- **FAB**: 停止中は ▶（`ic_play_arrow`・primary色）、記録中は ■（`ic_stop`・error色）。
- **現在地ボタン**（右上・`ic_my_location`）: 追従中は色付き、手動で地図を動かすとグレー（固定）。タップで現在地へ再センター＆追従再開。取得中は「現在地を取得中…」を上部に表示。
- **記録中の表示**: 上部に経過時間ピル（● 記録中）、下部に距離・地点数の統計カード。立ち寄りを検出中は「● 立ち寄り中」カード（場所名・滞在時間）を表示。
- **電池最適化の案内**: 電池の最適化が有効なままだとバックグラウンド記録が止まりやすいため、無効化を促すカードを表示。
- **権限がない場合**: マップ中央に権限リクエストのカードをオーバーレイ表示（「位置情報を許可」ボタン）。
- **中断記録の復帰**: アプリ更新などで前回記録が中断されていた場合、起動時に「再開する／完了にする」ダイアログを表示。
- **エラー**: 下部にエラーカードを表示。

対応実装: `presentation/tracking/TrackingScreen.kt`, `TrackingViewModel`（`currentTrack` をリアルタイム購読）。

### 2. 履歴画面

日付順の記録一覧。先頭に統計サマリー、記録中があればアクティブカードを表示。項目タップで詳細画面へ。

```text
┌─────────────────────────────┐
│ 外出履歴                      │
│ ┌─────────────────────────┐ │
│ │ 📊 お出掛け統計           │ │ ← 記録数 / 総距離 / 総時間
│ └─────────────────────────┘ │
│ ┌─────────────────────────┐ │
│ │ 🟢 記録中 …               │ │ ← 記録中があれば先頭に
│ └─────────────────────────┘ │
│ ┌─────────────────────────┐ │
│ │ 2026/07/19  1.8km …   🗑 │ │ ← 各記録（タップで詳細／削除）
│ └─────────────────────────┘ │
├─────────────────────────────┤
│   [ 記録 ] [ 履歴 ] [ 設定 ] │
└─────────────────────────────┘
```

- **統計サマリー**: 記録数・総距離・総時間。
- **記録項目**: 日付・開始/終了時刻・移動距離（地点数）。ゴミ箱アイコンで削除。
- 記録が無いときは「記録がありません」。

対応実装: `presentation/history/HistoryScreen.kt`, `HistoryViewModel`。

### 3. 詳細画面（map-first）

全画面マップに軌跡と立ち寄りを表示し、情報はドラッグ可能なボトムシートに畳む。

```text
┌─────────────────────────────┐
│ (←)  (⚙)                    │ ← 戻る／補正調整（⚙はデバッグビルドのみ）
│         [全画面 Google Map]  │
│      ～～ 軌跡 ～～  📍立ち寄り │ ← 開始(緑)・終了/現在地(赤/青)・立ち寄り(紫)
│ ┌─────────────────────────┐ │
│ │ ═══                     │ │ ← ドラッグハンドル
│ │ 2026年07月19日    ●記録中 │ │
│ │ 14:30 – 15:50 ・1時間20分 ・立ち寄り2件│
│ │ [再解析] [場所を取得(未取得1件)]│ │ ← 操作チップ
│ │ ┌────────┐ ┌────────┐   │ │
│ │ │ 3.2km  │ │  128   │   │ │ ← 移動距離 / 地点数
│ │ └────────┘ └────────┘   │ │
│ │ ◯◯店  14:40–15:10 滞在30分  [編集][削除]│
│ │ △△公園 …                  [編集][削除]│
│ └─────────────────────────┘ │ ← ボトムシート（引き上げで詳細）
└─────────────────────────────┘
```

- **マーカー**: 開始＝緑、終了＝赤、記録中の現在地＝青、立ち寄り＝紫。軌跡は `TrackLineOrange` の polyline（補正後）。
- **ボトムシート**: 日付・記録中バッジ・時刻範囲・所要時間・立ち寄り件数・移動距離・地点数。下スワイプでシートを隠して地図を全画面化でき、「▲ 詳細を表示」で復帰。
- **立ち寄り一覧**: 各行に場所名（未命名は座標）・到着–出発・滞在時間。行タップで地図をその場所へフォーカス。「編集」で名前編集ダイアログ、「削除」で「この訪問だけ削除／場所ごと削除」を選択。
- **操作チップ**: 「再解析」（補正・立ち寄りを再計算）、「場所を取得（未取得 N 件）」（未命名の場所名を Google で解決）。
- **補正の調整（デバッグビルドのみ）**: `ic_tune` ボタンで調整モードに入り、生データ（灰）を重ねつつスライダー（速度上限・平滑窓）で補正を試せる。
- **将来**: このシートに写真・評価・コメント・タグの枠を追加（Phase 2）。

対応実装: `presentation/history/TrackDetailScreen.kt`（`BottomSheetScaffold`）。

### 4. 設定画面

アプリの動作設定。現状は GPS 記録間隔のみ。

```text
┌─────────────────────────────┐
│ 設定                          │
│ GPS記録間隔                   │
│ 短いほど滑らか／長いほど省電力 │
│   ◉ 5秒（高精度・電池大）      │
│   ○ 10秒（標準）              │
│   ○ 30秒（省電力）            │
│   ○ 60秒（最省電力）          │
│ ※ 変更は次に記録を開始した時から│
├─────────────────────────────┤
│   [ 記録 ] [ 履歴 ] [ 設定 ] │
└─────────────────────────────┘
```

- **GPS記録間隔**: 5 / 10 / 30 / 60 秒からラジオ選択（既定は 10 秒＝標準）。短いほど軌跡が滑らかだが電池を多く使う。
- 変更は次に記録を開始したときから反映される。

対応実装: `presentation/settings/SettingsScreen.kt`, `SettingsViewModel`。

### 5. 行きたい画面

行きたい場所の一覧・登録。詳細な仕様は [../designs/wishlist.md](../designs/wishlist.md) を参照（本節は要点のみ）。

```text
┌─────────────────────────────┐
│ 行きたい場所            (＋) │ ← 右上:追加（検索/地図で選ぶ/手入力）
│ [未訪問] [訪問済み]          │ ← 状態フィルタ
│ ┌─────────────────────────┐ │
│ │ ★★★ ◯◯カフェ            │ │ ← 優先度・名前
│ │ 東京都… / メモ抜粋…       │ │
│ └─────────────────────────┘ │
├─────────────────────────────┤
│ [記録] [履歴] [行きたい] [設定]│
└─────────────────────────────┘
```

- **一覧**: 優先度順／登録日順。状態（未訪問/訪問済み）でフィルタ。各行に優先度・場所名（未命名は住所→座標）・メモ抜粋・訪問済みバッジ。
- **登録3経路**: キーワード検索（Google・オンライン）／地図タップ（オフライン可）／手入力。立ち寄りからの「また行きたい」は後段。
- **詳細**: map-first。優先度・メモ・訪問済みを編集、削除は wishlist 行のみ（place は残す）。未命名は「場所を取得」で命名（既存 Nearby 解決を再利用）。
- **初回スコープ**: 優先度・メモ・訪問済み状態のみ。**タグは後段**（複数タグを `tags` 共有で実装）。

対応実装（予定）: `presentation/wishlist/WishlistScreen.kt`, `WishlistViewModel`。

## デザイントークン

### カラー（暖色系・Material3）

`PathlyAndroidTheme` は Material3 ダイナミックカラー対応（Android 12+）。非対応端末では以下の暖色系スキームを使用。ダークモード対応済み。

| 役割             | 色                       |
| ---------------- | ------------------------ |
| primary          | `PathlyOrange` (#FF6B35) |
| secondary        | `PathlyGreen` (#2ECC71)  |
| error            | `ErrorRed`               |
| 軌跡 polyline    | `TrackLineOrange`        |
| 開始マーカー     | 緑（HUE_GREEN）          |
| 終了マーカー     | 赤（HUE_RED）            |
| 現在地マーカー   | 青（HUE_BLUE）           |
| 立ち寄りマーカー | 紫（HUE_VIOLET）         |

定義: `ui/theme/Color.kt`, `ui/theme/Theme.kt`。

### アイコン

Material Icons は不使用。`res/drawable` のベクター＋`painterResource` を使う（`ic_location_on` / `ic_list` / `ic_flag` / `ic_settings` / `ic_play_arrow` / `ic_stop` / `ic_arrow_back` / `ic_my_location` / `ic_tune` / `ic_delete`）。
