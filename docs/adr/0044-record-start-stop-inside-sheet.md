# 0044. 記録画面の開始・停止は記録のシートの中に置き、地図の上には出さない

- Status: Accepted
- Date: 2026-11-21

関連: 置き換える決定は [0042](0042-primary-action-moves-with-sheet.md) の「記録画面の開始・停止の丸は、下の記録のシートの
すぐ上に置き、シートと一緒に動く」。0042 の「シートはタップでも開け閉めする」と「主役はいつも見えているか、1 タップで戻せる」は
そのまま残る。画面の型は [0038](0038-screen-layouts-four-corners-and-tool-row.md)。

## Context（背景）

0042 で、記録画面の開始・停止の丸（72dp）を記録のシートのすぐ上に乗せ、シートと一緒に動くようにした。
#225 で記録のシートに立ち寄りの一覧を出してスマホで確かめたところ、シートの上に乗った丸が地図の真ん中下を隠し、
地図を見るときに邪魔だという声が出た（#236）。シートを広げると丸も上がるので、上の案内の帯と重ならないように
フルの高さを画面の 45% に抑える必要もあった。

ほかの地図の画面（経路詳細・履歴の地図）の主役は、もともとシートの中にある。

## Decision（決定）

- **記録画面の開始・停止は記録のシートの中に置く。** 地図の上に丸は出さない。
  - 停止中: シートに幅いっぱいの「▶ 記録を始める」（塗りのボタン）。これまでの「記録していません」の代わり。
  - 記録中: 情報の段（移動距離・地点数・立ち寄り中）の右端に停止。誤って押しにくいよう**塗らずに赤い枠の丸**（48dp）にし、
    下に「停止」と添えて見つけやすくする。押すと確認ダイアログ（今までどおり）。
- シートを畳むと戻すボタン（「▲ 記録中・1.82km」「▲ 記録していません」）だけが残り、そこから開いて始める・止める
  （0042 と同じく 1 タップ増える）。記録を始めた直後・止めた直後は、シートをハーフで開く。
- 丸がシートの上に乗らなくなったので、記録中のシートのフルの高さは画面の 60% まで広げる。

## Alternatives（検討した没案）

- **丸をシートの上に乗せたまま（0042）** … 地図の下の真ん中がいつも隠れる。却下。
- **停止も塗りの赤いボタンにする** … 見つけやすいが、記録中のシートでいちばん目立つ操作が「止める」になり、立ち寄りを
  足す操作より先に目に入る。誤って押しやすくもなる。却下。
- **停止をシートの下端に幅いっぱいで置く** … 押しやすいが、立ち寄りの一覧が伸びたときにスクロールの先へ行くか、
  一覧の場所を削ることになる。却下。

## Consequences（結果・トレードオフ）

- 地図の上は四隅の操作とシートだけになり、下中央の区画は空く（記録画面に地図の上の主役は無い）。
- 停止の丸は 72dp から 48dp に小さくなる。確認ダイアログがあるので、押し間違えても記録は切れない。
- 停止中のシートは「記録を始める」の分だけ高くなる。
