# 0041. Material 3 Expressive を使い、Compose Material 3 の 1.5.0 安定版が来てから入れる

- Status: Accepted
- Date: 2026-11-18

関連: トークンは [0040](0040-design-tokens-indigo-fixed-colors.md)、画面の型は [0038](0038-screen-layouts-four-corners-and-tool-row.md)。
入れる作業は #201。

## Context（背景）

Material 3 の拡張として Material 3 Expressive が出ている。動き（ばねの動き）、形の種類と形の変化、
浮かぶツールバー・ボタンのグループ・FAB のメニュー・読み込みの表示などの部品を足すもので、Compose では
`MaterialExpressiveTheme` と追加の部品として入る。

#193〜#197 で画面を型（0038）に移すときに、新しい部品を作る。地図の画面では脇役の操作（今ここを立ち寄り・
地図で指して追加・レイヤー）が丸ボタンの縦の列になっていて、Expressive の浮かぶツールバーや FAB のメニューで
まとめられる見込みがある。部品を作る前に、使うかを決めておきたい。

決めた時点（2026-11-18）の版:

- Pathly が使う Compose Material 3 は 1.4.0（Compose BOM 2026.09.00）。安定版で、Expressive の部品
  （浮かぶツールバー・ボタンのグループ・FAB のメニュー・読み込みの表示・`MaterialExpressiveTheme`）は入っていない。
  入っているのは `MotionScheme` と新しいナビゲーションの部品くらい。
- Expressive の部品を安定版にする 1.5.0 は、1.5.0-rc01（2026-11-04）まで出ている。安定版の日付は告知されていない。

## Decision（決定）

- **Material 3 Expressive を使う。** 使うもの:
  - **浮かぶツールバー**: 地図の画面の脇役の操作をまとめる
  - **FAB のメニュー**: 右下の追加の入口（場所の追加の手段など）を 1 つの丸ボタンから開く
  - **動き**: テーマで Expressive の `MotionScheme`（ばねの動き）を全体にかける
  - **ボタンのグループ・読み込みの表示**: 一覧のツール行と、読み込み中の表示
- **1.5.0 の安定版が来てから入れる。** rc は入れない。material3 の版は Compose BOM で決まるので、1.5.0 を含む BOM が
  Dependabot の更新 PR で来てマージしたら、#201 で入れる。
- **それまでの #192〜#197 は今の部品で作る。** ただし、あとで置き換えやすいよう、地図の画面の脇役の操作は
  1 つの Composable にまとめて置き、右下の追加の入口も 1 か所にする（中身を浮かぶツールバー・FAB のメニューに差し替えるだけで済むように）。
- **トークン（0040）は変えない。** `MaterialExpressiveTheme` にも同じ色・文字・角丸を渡す。動きのトークンは、入れるときに
  Expressive の既定を使い、Design System と screens.md に足す。

## Alternatives（検討した没案）

- **今 1.5.0-rc01 を入れる** … #192 から Expressive の部品で作れて、置き換えが要らない。ただ、安定版までに API が変わる
  ことがあり、Compose BOM から material3 だけ外して版を固定することになる（Dependabot の月 1 回の更新とずれる）。
  置き換えは「1 つにまとめた Composable の中身を差し替える」で済むようにしておけば小さいので、却下。
- **使わない** … 今の Material 3 のままで足りる。ただ、地図の画面の丸ボタンの縦の列は、型（0038）の「四隅を少しずつ使う」
  の弱みそのもので、浮かぶツールバーでまとめられると地図が広くなる。Material の標準の部品として保守されるものを使える利点も大きい。却下。
- **動きだけ今入れる** … 1.4.0 にも `MotionScheme` はあるが、部品の多くは 1.5.0 で動きに対応する。部品と一緒に入れないと、
  一部の部品だけ動きが変わって揃わない。#201 でまとめて入れる。

## Consequences（結果・トレードオフ）

- #192〜#197 で作る部品のうち、地図の脇役の操作・追加の入口・一覧のツール行・読み込みの表示は、#201 で置き換える前提になる。
  置き換えやすいよう、それぞれ 1 か所にまとめて作る。
- 1.5.0 の安定版がいつ来るかは決められない。来るまでは今の部品のまま使い続ける。
- 1.5.0 で API や見た目が rc から変わっても、入れるときに合わせればよい。
