# 0033. 履歴の地図表示は、絞り込んだ経路のうち選んだものだけを重ね、選び方は「この範囲の経路」と揃える

- Status: Accepted
- Date: 2026-11-13

関連: 場所タブの一覧／地図の切り替えは #134・#140、「この範囲の経路」は #137（specs/map.md）、絞り込みの欄は [0031](0031-list-filters-in-a-panel.md)。

## Context（背景）

場所タブは一覧と地図を切り替えて見られる。履歴（経路一覧）でも、絞り込んだ経路を地図で見比べたい（#152）。
ただ経路は線なので、場所のマーカーと違い、絞り込んだものを全部重ねると見分けがつかない。線の点も経路ごとに数千あり、
全部を読むと重い。

記録画面にはすでに「この範囲の経路」（範囲に入る経路をチェックで選び、8 色・8 本まで重ねる）がある。

## Decision（決定）

- 履歴に一覧／地図の切り替えを付ける。地図表示の形（地図をタブいっぱいに広げ、見出し・検索・絞り込みを上に重ねてたためる・
  システムバックで一覧へ）は場所タブと揃え、絞り込みは一覧と共有する。
- 地図表示の下のシートに**絞り込んだ経路の一覧**を出し、**チェックで選んだものだけ**を重ねる。選び方・色・上限（8 本）・
  立ち寄りのバッジ・「絞り込みの外」の扱いは「この範囲の経路」と同じにし、選ぶ仕組みとシートの部品を共有する。
  行のタップは経路詳細へ（選ぶのはチェック）。
- 選んだ経路は絞り込みを変えても外すまで残し、経路詳細へ行って戻っても・タブを切り替えても保つ（アプリを閉じると消える）。
- 経路を選んでも地図は**勝手に動かさない**。寄せるのは、行の「全体を見る」とシートの「選んだ経路をすべて見る」を押したときだけ。
- 線の点は選んだ経路のぶんだけ読む。

## Alternatives（検討した没案）

- **絞り込んだ経路を全部重ねる** … 場所の地図表示と同じ考え方だが、線が重なって見分けられず、点も全部読むので重い → 却下。
- **一覧表示の行にチェックを付けて選び、地図に切り替えて見る** … 選ぶ画面と見る画面が分かれ、選び直すたびに切り替えることになる。
  一覧表示の行のタップ（経路詳細へ）とも紛れる → 却下。地図表示の中のシートで選ぶ。
- **選ぶたびに、選んだ経路がすべて入るまで地図を寄せる** … 1 本目には便利だが、2 本目以降は見ていた範囲が勝手に変わり、
  見比べにくい → 却下。寄せるのはボタンを押したときだけ。
- **絞り込みから外れた経路は選びも外す** … 線だけが地図に残るよりは分かりやすいが、絞り込みを試すたびに選び直しになる → 却下。
  「この範囲の経路」と同じく残し、一覧の下から外せるようにする。

## Consequences（結果・トレードオフ）

- 記録画面と履歴で、経路を選んで重ねる操作と見え方が同じになる。選ぶ仕組み（`TrackOverlaySelection`）とシート（`TrackPickerSheet`）は
  共有なので、片方を変えると両方に効く。
- 一度に見比べられるのは 8 本まで。
- 地図表示の間は一覧のシートが画面の下 1/3 ほどを使う。
