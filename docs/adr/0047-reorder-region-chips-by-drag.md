# 0047. 地名のチップは縦のドラッグで並べ替え、「他 N 件」とも出し入れできる。並べた順も保存しない

- Status: Accepted
- Date: 2026-11-26

関連: チップの並べ方と保存しない考え方は [0043](0043-multiple-region-markers-kept-in-memory.md)（その「並び順は選んだ順のまま変えない」をこの決定で変える）。
仕様は specs/map.md の「地域へ移動」。

## Context（背景）

記録画面の「地域へ移動」で出した地名のチップは、選んだ順のまま縦に並ぶ（5 つまで。6 つ目からは「他 N 件」にまとめる）。
見比べたい地域を近くに置いたり、よく見る地域を上にしたりしたいが、外して選び直すしかなかった（#255）。

決めることは、掴み方と見せ方・「他 N 件」との出し入れ・地図のドラッグやチップのタップと紛れないか。
あわせて、チップが白い札で押せるものに見えにくいので見た目を決める。

## Decision（決定）

- **チップのどこでも、触れて縦に動かすと掴む（長押しは要らない）。** 掴むと端末が短く震え、チップは影を濃くして少し大きくなり、
  指に付いて縦にだけ動く。ほかのチップに重ねると（掴んだチップの端がそのチップの中心を越えると）そのチップが上下にずれて空きを作り、
  **離した所で順が決まる**。いちばん下のチップに重ねればいちばん下になる（中心どうしで比べると、端で止まったときに
  いちばん下まで行けなかった）。
  - 軽いタップは今までどおり地名（寄せ直し）・×。動かし始めた指では、離しても地名・× は働かない。
  - チップの上から横に動かしても何もしない。チップの上の指は地図には行かない（今までと同じ）。
- 動かせるのは地名のチップの間だけ。**「すべて外す」はいつも先頭**で、その上へは行かない。
- **「他 N 件」と出し入れできる。**
  - 掴んだチップを「他 N 件」に重ねて離すと、まとめの先頭に入り、まとめの先頭が 5 つ目に上がる（重ねている間はまとめの枠を太くする）。
  - まとめのメニューの行に**「上に出す」**（× の左）を置く。押すとその地域が 5 つ目に出て、5 つ目だった地域はまとめの先頭に入る。
  - メニューの中では並べ替えない（メニューの行は短い間しか出ず、掴んで動かすには狭い）。
- 読み上げ（TalkBack）では、地名の操作に「上へ移す」「下へ移す」（5 つ目では「まとめに入れる」）を出す。
- **見た目**: 地名のチップは目印・境界と同じ藍の枠と藍の字で、薄い藍に塗る。今見ている地域は藍で塗りつぶして白い字。
  「すべて外す」「他 N 件」は白地に藍の枠と藍の字。目印がある間は地図が明るい配色なので（[0046](0046-region-boundaries-by-data-driven-styling.md)）、
  テーマの明暗によらず同じ色にする。
- 検索窓を開いている間は、チップを窓の下の「場所｜地域」の切り替えの下から並べる（重ねない）。
- **並べた順も保存しない**（0043 と同じ。アプリが終わると消える）。場所一覧の地図の境界のチップ（1 つだけ）は並べ替えの対象外
  （見た目は同じ）。

## Alternatives（検討した没案）

- **長押しで掴んでから動かす** … 一度作ったが、スマホで使うと掴むまでの待ちがあって使いにくかった。
  チップは地図の上で指を受けて地図を動かさないので、縦の動きをすぐ並べ替えにしても地図のドラッグとは紛れない → **却下**。
- **チップの端に掴むための取っ手（⋮⋮）を出す** … 紛れにくいが、地図の左上を隠す幅が増える → **却下**。
- **見えている 5 つの中だけで入れ替え、まとめはそのまま** … 作りは小さいが、まとめに入った地域を上に出すには外して選び直すしかない
  → **却下**（よく見る地域を上にしたいという動機に合わない）。
- **掴んでいる間、差し込む位置に線を出す（ほかのチップは動かさない）** … 動きは少ないが、離した後の並びを思い描きにくく、
  Android でよくある並べ替え（ほかがよける）とも違う → **却下**。
- **押したチップを先頭に上げる** … 0043 で没にしたとおり、2 つを行き来するたびに並びが入れ替わる → **却下**（並べ替えは手で決める）。
- **見た目を白地のまま、地球だけ藍の丸に入れる・白地に藍の枠だけ** … 控えめだが、押せる札に見えるという狙いには弱い → **却下**。
- **検索中はチップを隠す** … すっきりするが、探しながら出している地域が見えなくなる → **却下**（切り替えの下へずらす）。

## Consequences（結果・トレードオフ）

- 見比べたい地域を近くに・よく見る地域を上に置ける。まとめの地域も 1 タップで上に出せる。
- チップの上から地図を縦にドラッグしようとすると、地図ではなくチップが動く（チップの上の指が地図に行かないのは今までと同じ）。
- まとめのメニューの行は操作が 3 つ（寄せ直し・上に出す・×）になる。
- 並べた順はアプリが終わると消える。残したくなったら、0043 の保存の考え方と一緒に見直す。
