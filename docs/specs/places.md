# 場所の仕様

「場所」は経路から独立して存在する。立ち寄りで見つかった場所も、地図で登録した場所も、
まだ行っていない「行きたい場所」も、**すべて同じ 1 つの入れ物**に入る。

> 対応する要望: [../requirements.md](../requirements.md)（場所名を自分に分かりやすく変えたい／
> 行きたい場所をリストアップしたい／優先度を設定したい／詳細情報を登録したい）。

---

## 場所が持つもの

| 項目                 | 説明                                                         |
| -------------------- | ------------------------------------------------------------ |
| 座標                 | 必須                                                         |
| **自分で付けた名前** | 任意。付けなければ未命名                                     |
| **メモ**             | 任意。行きたいに入れていなくても書ける                       |
| Google の施設情報    | 施設として同定できたときだけ。施設名・住所・カテゴリ         |
| 行きたい             | 任意。いま行きたいかどうかと優先度（下記）                   |
| 訪問済み             | 立ち寄りの記録か手動の印で決まる。行きたいとは別の軸（下記） |
| 行きたいの履歴       | 行きたいに入れて、実際に行った記録（下記）                   |

**同じ場所に何度行っても、場所は 1 件のまま**で立ち寄りだけが増える。だから名前を直せば、
その場所の**すべての訪問に反映される**。

## 名前

名前の入れ物は **2 つあり、混ぜない**。

| 呼び名               | 誰が入れるか                                      |
| -------------------- | ------------------------------------------------- |
| **自分で付けた名前** | ユーザーだけ。Google が付けた名前は絶対に入らない |
| **Google の名前**    | 自動命名・施設のタップ・キーワード検索            |

画面に出る**表示名**は、次の順で最初に見つかったもの。

```text
自分で付けた名前 → Google の名前 → 住所 → 座標
```

### 名前を入力するとき

- 入力欄は**自分で付ける名前だけ**のもの。Google の名前は初期値に入らない。
  **欄が空かどうかが、そのまま「自分で名前を付けたかどうか」を表す。**
- Google の名前はシートの**見出し**に出る。少し変えたいときは、欄が空のときだけ出る
  「この名前から書き換える」で流し込める。
- **名前を変えても施設との紐付けは外れない。**「スタバだけど自分は休憩と呼ぶ」がそのまま成立し、
  カテゴリ・住所も残る。施設ごと取り違えたときは「Google施設を選び直す」で付け替える。
- 名前を空にして保存すると未命名に戻り、表示は Google の名前へ落ちる。

### あとから Google の情報を付ける

- 施設と紐付いていない場所には「**Googleで情報を取得**」、紐付いている場所には
  「**Google施設を選び直す**」が出る。近くの候補から選び、周辺に出ない施設は名前でも検索できる。
- 選んだ施設は**すぐには保存されず**、「保存」で確定する。
- 選び直すと**地図のピンがその施設の位置へ動く**（表示に使う座標が施設のものに切り替わるため）。

## 座標の出どころ

座標には**出どころが 2 つ**あり、同じ施設でも値が違うことがある。

| 呼び名             | どこから来るか                                                          |
| ------------------ | ----------------------------------------------------------------------- |
| **施設の座標**     | Google が持つその施設の代表点。自動命名・選び直し・キーワード検索で使う |
| **アイコンの座標** | 地図がラベルを描くために選んだ点。地図の施設タップで使う                |

敷地のある施設（神社・寺・公園・学校など）では**数十 m 離れる**ことがある。
正としているのは**施設の座標**で、地図のアイコンには合わせない。ピンがずれて見えるのは仕様。

## 登録のしかた

| 経路                       | 名前の付き方                        | オフライン                         |
| -------------------------- | ----------------------------------- | ---------------------------------- |
| 地図で何もない地点をタップ | 付かない（あとで手入力）            | 使える                             |
| 地図で施設をタップ         | Google の名前が付く                 | 使える（施設名はタップ時に分かる） |
| キーワードで検索して追加   | Google の名前・住所・カテゴリが付く | **使えない**                       |
| 立ち寄りの自動検出         | オンラインなら自動で付く            | 通信が戻ってから付く               |

キーワードでの検索は、場所タブの追加（＋）の「検索して追加」のほか、記録画面の地図の「検索して登録」からも使える（探す欄と候補は共通。記録画面では選んだ場所を地図の上の場所シートで登録する）。

どの経路でも、まず**場所を登録**する。「行きたい」は任意の属性なので、トグルが ON のときだけ足される。

## 同じ場所を二重に作らない

| 状況                       | どう同定するか                                                               |
| -------------------------- | ---------------------------------------------------------------------------- |
| 施設として分かっている     | **施設の同一性**で同定する。隣の別の店と混ざらず、同じ施設の再登録はまとまる |
| 座標しか分からない         | **30m 以内の既存**を再利用する                                               |
| 近接確認で「新規」を選んだ | 同定せず**必ず新しい場所**を作る                                             |

- 施設をタップして既に登録済みだったときは「**この場所は登録済みです**」と軽く知らせるだけで、
  **何も変更しない**（座標も上書きしない）。
- 地図に登録済みの場所を出していないとき（または絞り込みで隠れた場所が近くにあるとき）は、
  確定の直前に**近接確認**が出る → [map.md](map.md)。
- 空き地点から作るときは、**施設を問い合わせない**。同じ施設を持つ場所が離れたところにあっても確認は出ない
  （地点を指すこと自体を「別の場所にしたい」意思表示とみなす → [ADR-0034](../adr/0034-no-same-facility-check-on-empty-tap.md)）。
  施設の場所に寄せたいときは、地図の施設のアイコンを押す。

## 行きたい

行きたいは「**これから行きたい**」という今の気持ち。**行ったら終わり、また行きたくなったら入れ直す**、を繰り返す。
入れ直すたびに履歴が残るので、「行くたびにまた行きたいと思う場所」が分かる。

- 1 つの場所につき、**いま行きたいのは最大 1 件**。同じ場所を二重に登録しない。
- 持つのは**優先度**（低 / 中 / 高）だけ。メモは場所そのものが持つ。
- 行きたいから外しても、**場所そのものは残る**。

### 行ったら行きたいは終わる

- 行きたいに入れた**後に**、その場所への**立ち寄りが記録された**ら、その回の行きたいは**「行った」として終わり**、
  旗が外れる。終わった行きたいは**行きたいの履歴**に残る（入れた日時・行った日時・そのときの優先度）。
  - 立ち寄りの記録には、記録中の自動検出のほか、再解析で見つかったもの・別の場所から付け替えたものも含む。
  - 「行った日時」は、その立ち寄りの到着時刻。
  - 入れる前の立ち寄りでは終わらない。過去の経路の立ち寄りの旗から入れたときや、その場所に居る間に入れたときに、
    すぐ終わってしまわないように。
- **手動の訪問済みの印では終わらない。** 印は記録の無い訪問を残すためのもので、二度目以降の訪問を表せないため
  （登録と同時に「行きたい」と「訪問済み」を付けたとき、すぐ終わってしまうのも避ける）。
  記録の無い訪問で行きたいを終えたいときは、旗を外す（この場合は履歴に残らない）。
- 自分で旗を外したときは、行かずにやめたものとして**履歴に残さない**。
- 履歴は、元になった立ち寄りをあとで消しても**残る**（行ったことは事実として扱う）。場所を消すと一緒に消える。
- 「行って満足（もう行かなくていい）」は記録しない（→ [ADR-0036](../adr/0036-wishlist-ends-on-visit-and-keeps-history.md)）。

### 入れ直す

- 終わった後は、旗を押せば**いつでも行きたいに入れ直せる**。入れ直すと新しい 1 回として数える。
- 行った場所を気に入ったら、経路詳細の**立ち寄りの行の旗からワンタップで**行きたいに入れられる（もう一度押すと外す）。
  入れるときの優先度は「中」（場所タブの一覧の旗と同じ）。訪問済みには触らない（立ち寄りがあるので訪問済みのまま）。

### かつて行きたいだったことを見せる

**「行きたいで行った回数」**＝その場所の行きたいの履歴の件数。行きたいに入れて実際に行った回数で、
立ち寄りの回数（訪問回数）とは別に数える。

旗は 3 通りの見た目にする（場所タブの一覧の行・経路詳細の立ち寄りの行で同じ）。

| 状態                                     | 旗                             | 押すと           |
| ---------------------------------------- | ------------------------------ | ---------------- |
| いま行きたい                             | 塗りの旗                       | 行きたいから外す |
| いまは行きたいでないが、行きたいで行った | 輪郭の旗にチェック（行った印） | 行きたいに入れる |
| 一度も行きたいで行っていない             | 輪郭の旗                       | 行きたいに入れる |

- 場所の詳細（編集画面）では、行きたいの切り替えの下に「**行きたいで 3 回行った**（最後は 2026/10/02）」のように
  回数と最後に行った日を出す。0 回なら出さない。
- 場所タブの一覧の行には、1 回以上なら「行きたいで行った 3 回」のバッジを添える（訪問回数のバッジとは別）。
- 地図のマーカーは変えない（形は「いま行きたい」だけを表す）。

## 訪問済み

- **立ち寄り記録が 1 件でもあれば自動で訪問済み**になる。記録が無い場所は手で訪問済みにできる。
- 行きたいとは**独立した別の軸**。行きたいに入れずに訪問済みにでき、行きたいが終わっても外しても訪問済みは残る
  （→ [ADR-0020](../adr/0020-visited-independent-from-wishlist.md)）。

## 一覧と詳細

**登録済みのすべての場所**が並ぶ（立ち寄りで自動生成された場所も含む）。

- 絞り込みは **4 軸独立**（すべて AND）。絞り込みのボタンで開く欄で選ぶ（→ [screens.md](screens.md) の「絞り込みの欄」）。行きたい（指定なし / 行きたい / 行きたい以外）と
  訪問（指定なし / 訪問済み / 未訪問）と、**業種**と、**地域**。
- 業種は Google の業種を地図のアイコンと同じ粒度に束ねたもので、**複数選べて、選んだどれかに当たれば残す**
  （1 つの場所の業種は 1 つなので OR）。選択肢は 飲食 / カフェ / 買い物 / 公園 / 観光 / 遊び / 交通 /
  宿泊 / 用事 / その他 / 未分類。
  - **未分類**は Google の施設情報が無い場所（座標だけ・未取得）。**その他**は施設情報はあるが、
    業種が分からないか、どの分類にも当たらない場所。
  - 選択肢には**件数**を添える。件数は**業種以外の絞り込み**（行きたい・訪問・名前の検索）に合う場所の数で、
    絞り込みを変えると件数も変わる。業種そのものの選択は件数に効かせない（選んでいない業種が 0 にならないように）。
  - 選択肢に出すのは、全体に 1 件でもある業種。ほかの絞り込みで 0 件になっても「カフェ（0）」と出したまま残し、
    絞り込みのたびに選択肢が出たり消えたりしないようにする。全体で 0 件の業種は出さない（選択中のものは外せるように残す）。
  - 業種だけを外すときは、一覧の上の業種のチップの × で外す（欄の「すべて外す」はほかの軸も外す）。
- **地域**は、日本の場所は**都道府県**と**市区町村**、海外の場所は**国**と**都市**。場所の座標から住所を引いて付ける
  （Google の施設情報の住所は使わない → [ADR-0029](../adr/0029-place-region-by-geocoder.md)・
  [ADR-0030](../adr/0030-overseas-region-by-country-and-city.md)）。座標だけの場所にも付く。
  - 絞り込みの欄の「地域」に、地域の一覧（件数つき）を出す。並びは、日本の都道府県（北から）→ 海外の国（日本語名の順）→ 地域不明。
    横の▼で、その中の市区町村・都市（件数つき）を開ける。海外は州を挟まず、国の中にそのまま都市が並ぶ。
    どの段も**複数選べて、選んだどれかに当たれば残す**（OR）。都道府県・国を選ぶとその中の場所すべて、
    市区町村・都市を選ぶとそこの場所だけ。
  - 効いている条件のチップには選んだ地域の名前を出す。市区町村・都市は「東京都 府中市」「アメリカ合衆国 ホノルル」のように 1 段目を添える。
  - 住所を引けていない場所（作ったばかりでまだ引いていない・オフライン・海の上など）は**地域不明**に入る。
    ネットワークに繋がると裏で引き、引けたら所在の都道府県・市区町村に移る。
  - 件数・選択肢の出し方・外し方は業種と同じ（件数は地域以外の絞り込みに合う数。全体に 1 件でもある地域を出す）。
  - 市区町村の粒度は住所の引き先に従う（政令指定都市は「横浜市」のように市の単位）。
- **名前で検索**できる。一覧の上の欄に入れた文字を**表示名に含む**場所だけが残る（部分一致）。
  英字の大文字・小文字、全角・半角、ひらがな・カタカナの違いは無視する（「かふぇ」で「カフェ」も当たる）。
  漢字の読みでは探さない（「かまくら」で「鎌倉」は当たらない）。
  端末の中のデータだけで探す（Google の検索ではない。「検索して追加」とは別物）。
  ほかの絞り込みとは AND。検索語は欄の × で消す（欄の「すべて外す」では消えない）。
- 絞り込んだ結果 0 件なら「条件に合う場所がありません」。
- 絞り込みの「行きたい」は**いま行きたいか**で見る（行きたいで行き終えた場所は「行きたい以外」に入る）。
- 並べ替えは 登録順（既定）/ 訪問順 / 訪問回数順 / **行きたいで行った回数順** / 優先度順 / 名前順 / 更新順、それぞれ昇降。
  行きたいで行った回数が同じ場所の並びは、登録順（新しい順）。
- 各行に 表示名・行きたいの旗（3 通りの見た目）・優先度・訪問回数・行きたいで行った回数（1 回以上のとき）・メモの抜粋。
- 見出しの横のボタンで**一覧表示と地図表示を切り替えられる**。絞り込み（行きたい・訪問・業種・地域・名前の検索）は
  両方で共有し、切り替えてもそのまま。地図表示では絞り込んだ後の場所だけをマーカーで出す
  （見た目・まとまり・名前のラベルはほかの地図の登録済みの場所と同じ）。並べ替えは地図では意味が無いので出さない。
  - 地図の範囲は、開いたときと絞り込みの結果が変わったときに、絞り込んだ場所が全部入るように合わせる。
    1 件ならその場所を中心に寄る。0 件なら「条件に合う場所がありません」を地図に重ね、範囲は今のまま
    （開いたときに 0 件なら現在地あたり）。詳細から戻ったときや、一覧表示を挟んで地図に戻ったときは前に見ていた範囲のまま（その間に絞り込みの結果が変わっていれば合わせ直す）。
  - マーカーをタップすると、一覧の行と同じくその場所の詳細へ進む。
  - 地図表示でシステムバックを押すと一覧表示に戻る（場所タブは離れない。吹き出しが出ていれば先にそれを閉じる）。
  - 地図表示では地図をタブいっぱいに広げ（下のタブは残す）、見出し・名前の検索・絞り込みは地図の上に重ねる。
    重ねたものは**たためる**。たたむと地図の上端に小さな帯だけが残り、帯には一覧への切り替えと、
    絞り込みの様子（絞り込んでいなければ「場所 12 件」、絞り込んでいれば「絞り込み 2・3 / 12 件」）を出す。
    絞り込んでいることを忘れて「場所が足りない」と思わないため。帯を押すとひろがる。
    地図を動かしただけで隠れることはしない（マーカーのタップと重なり、出し方も見た目から分からないため）。
  - 範囲を合わせるとき・0 件の文言は、重ねたものの下の見えている部分に収める。
  - どちらで見ているか・たたんでいるかは、絞り込みと同じくアプリを使っている間は保つ。
- 詳細では、その場所を含む**お出掛けの一覧**（日付とその場所での滞在）を見られ、タップで経路詳細へ移る。
  訪問メモはここでは**表示だけ**で、編集は経路詳細から。

登録済みの場所は**地図にも出せる**（記録・経路詳細・場所詳細のトグル）。訪問済みかどうかで色、
行きたいかどうかで形が変わる。ON/OFF は画面ごとに独立して覚える。
地図でも行きたい・訪問・業種で絞り込めるが、**条件は一覧とは別**に持つ（→ [map.md](map.md) の「登録済みの場所の絞り込み」）。
一覧と同じ条件で地図に出したいときは、場所タブの地図表示を使う。

## 消す

- **立ち寄り記録がある場所は消せない**（ボタンが押せない）。記録を壊さないため。
- 消せるのは、行きたいと座標だけが紐づく場所。**確認は出さず即時に消え**、
  一覧のスナックバー「取り消す」で戻せる。
- 立ち寄りを消した結果どこからも参照されなくなった場所は、**自動検出で作られた場所だけ**が
  一緒に消える。自分で登録した場所は、訪問も行きたいも無くなっても残る。
  自動検出で作られた場所でも、**行きたいの履歴があれば残す**（行きたいと思ったことは本人の意思なので）。

## 現状しないこと

- **タグ**（複数・目的別の整理）は未実装。
- **「行って満足（もう行かなくていい）」の記録**はしない。「また行きたい」は行きたいに入れ直すことで表す
  （→ [ADR-0036](../adr/0036-wishlist-ends-on-visit-and-keeps-history.md)）。
- 行きたいの履歴を 1 件ずつ見る・消す画面は無い（回数と最後に行った日だけを出す）。
- 一覧は全件を出すので、未命名の場所が増えると並びが賑やかになる。現状は許容している。
